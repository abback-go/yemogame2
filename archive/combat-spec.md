# 전투 코어 스펙 v0.1 — 아카이브 (Godot 얼음·창 슬라이스)

> **상태: 구판 아카이브 (2026-07-19 작성).** 기본 공격 설계가 두 차례 교체되어(마력 칼날 → 속성 투척체) 이 문서의 창 무브셋은 폐기됨. **현행 전투 정본 = 기획서 §6 + `game/combat.html` 샌드박스.**
> 보존 이유: Godot에서 구현·플레이 검증된 수치와 원칙(주스 레이어, 텔레그래프 문법, 캔슬 구조)은 엔진 무관 이월 자산. 전문이 필요하면 git 이력 참조.

## 살아남은 원칙 (현행 설계로 승계됨)

1. **마법 가시성** — 무기·스킬이 물리 타격이 아니라 마법으로 읽혀야 한다: 반투명·발광 형상, 매개체(마도구)가 출처로 보이게, 시전 텔(마법진·룬). → 기획서 §6.2의 "빚는 2박자"로 승계.
2. **손은 단순** — 버튼 3개 고정. 복잡성은 리듬·거리 판단에. → §6.1 버튼 고정 원칙.
3. **데미지 스펀지 금지** — 적은 2~4타에 죽는다. 읽히는 예비동작 필수. → §4.3·§6.7.
4. **캔슬 구조** — 판정 프레임 이후 대시·점프·스킬로 캔슬 가능(치고 빠지는 리듬). 콤보 입력 버퍼 0.25s. → 게임필 체크리스트(§6.9).
