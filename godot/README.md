# Godot 파이프라인 실험 (사지방 실행 안내)

## 준비 (1회)
1. **Godot 4.7 Windows 표준판**(".NET" 아닌 것) — 유저 사용 버전으로 확정 (2026-07-15). 프로젝트도 4.7 기준.
2. exe 하나가 전부 — 설치 불필요. 앞으로 모든 곳(사지방/집)에서 4.7로 통일할 것.

## 실행 (매번)
1. 저장소 ZIP 다운로드 (GitHub → Code → Download ZIP) → 압축 해제
2. Godot 실행 → 프로젝트 매니저에서 **Import** → 이 폴더의 `project.godot` 선택 → Import & Edit
3. 에디터가 열리면 **F5** (우상단 ▶)

## 시작 메뉴 (F5 하면 나오는 것)
- **[1] 조작감 테스트 방** — 달리기/점프/질풍보 (Esc로 메뉴 복귀)
- **[2] 월드맵 뷰어** — 17개 지역 · 295방 설계도. 화살표·WASD 이동, 휠 줌, 방 클릭=상세, **Q/E = 진행 단계**(이동술 습득 순서대로 세계가 열리는 것을 볼 수 있음), Esc=메뉴
- 월드맵 데이터: `godot/data/world_map.json` (원본: `docs/world/regions/*.json` → `tools/worldmap_build.py`)

## 성공 기준 (테스트 방)
- 흰 사각형+지팡이 캐릭터가 나오고 ←→ 이동 / Z·Space 점프 / C·Shift 질풍보가 됨
- 왼쪽 계단 발판(상승 110px)이 점프로 올라가짐 / 오른쪽 240px 갭이 질풍보로 건너짐

## 문제 발생 시
- 빨간 에러, 빈 화면, 글자 깨짐 등 **화면에 보이는 그대로**(가능하면 스크린샷 문구) Claude에게 전달
- 그다음 "점프가 낮다/높다" 같은 조작감 피드백 1개 → 수정 커밋 → 재다운로드로 반영 확인 (④단계)
