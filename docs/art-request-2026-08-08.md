# 스프라이트 추가 의뢰 — 이미지 생성 AI에게 넘길 설명서

> **용도:** 형님이 「스프라이트 시트 프롬프트를 짜주는 AI」에게 이 문서를 그대로 붙여넣으면,
> 그 AI가 이걸 근거로 이미지 생성 프롬프트를 만든다.
> **이 문서는 프롬프트가 아니라 「사양서」다.** 사양을 어기면 기존 시트와 안 맞아 못 쓴다.

기준 파일: `art/temple_maiden_sheet.png` (648×696) — **이미 완성돼 게임에 들어가 있다.**
새로 만드는 것은 **여기에 없는 동작**이고, 반드시 **같은 캐릭터·같은 화풍·같은 팔레트**여야 한다.

---

## 0. 왜 추가가 필요한가 (실측으로 확인된 결손)

기존 시트 6행을 전부 실측·육안 대조한 결과:

| 행 | 동작 | 상태 |
|---|---|---|
| 1 | 대기 | ✅ 있음 |
| 2 | 달리기 | ✅ 있음 |
| 3 | 점프/공중 | ✅ 있음 |
| 4 | 공격(창 찌르기) | ✅ 있음 |
| 5 | 대시(지상) | ✅ 있음 |
| 6 | 무릎 꿇기 → 기상 | ✅ 있음 |

⇒ **없는 것: 피격, 그리고 신규 이동기 「창대쉬」.** 이 둘을 의뢰한다.

## 1. 절대 규격 — 어기면 사용 불가

| 항목 | 값 | 이유 |
|---|---|---|
| 셀(프레임) 크기 | **108 × 116 px** | 기존 시트와 동일. 다르면 코드가 못 자른다 |
| 시트 배치 | **6열 고정**, 행은 아래 지정 | 좌→우, 위→아래 순서 |
| 배경 | **완전 투명(알파 0)** | 체크무늬·단색 배경 금지 |
| 알파 | **0 아니면 255. 중간값 금지** | 기존 시트가 그렇다. 반투명 픽셀이 섞이면 도트가 흐려진다 |
| 안티에일리어싱 | **금지** | 기존 시트는 경계가 전부 하드 엣지다 |
| 확대·축소 | **금지** | 108×116 원본 해상도로 직접 그릴 것. 큰 그림을 줄이면 색이 번진다 |
| 캐릭터 방향 | **오른쪽을 향한다** | 왼쪽은 코드가 좌우 반전으로 만든다 |
| **상하 반전 금지** | 위·아래 방향도 각각 그린다 | 사람을 상하 반전하면 거꾸로 매달린 그림이 된다 |

### 팔레트 — 이 24색만 사용 (기존 시트 전수 추출)

```
금·머리카락·금세공 (10)
#FDE370  #FBD033  #F7D26E  #F1BA3D  #DF9C2E
#C7862B  #C3994D  #BF7220  #A05919  #783E17

흰옷·대리석·금속 (8)
#FEFFFD  #FCFCFB  #F3F1F1  #EDE6DA
#D6D2D3  #D0C6B5  #C8B184  #9D9791

그림자·윤곽 (6)
#251714  #3E3028  #4B4644  #6F593C  #886D49  #928168
```

> **새 색을 만들지 마라.** 특히 창대쉬의 빛 이펙트를 파랑·보라로 칠하고 싶어지는데,
> 이 캐릭터의 신성력은 **금색 계열**이다. 빛은 `#FDE370`·`#FEFFFD`로 표현할 것.

### 캐릭터 정렬 — 가장 자주 틀리는 부분

기존 시트의 캐릭터는 **셀 한가운데가 아니라 왼쪽으로 치우쳐** 있다.
오른쪽 여백은 **창이 뻗을 자리**다(공격 프레임에서 창끝이 x103까지 간다).

| 기준점 | 셀 좌표 | 적용 대상 |
|---|---|---|
| **발바닥 선** | **y = 111** (몸 픽셀 마지막 행이 y110) | **땅에 서 있는 프레임** |
| **좌우 중심** | **x = 35** | 모든 프레임 |
| **몸 무게중심** | **(35, 70)** | **공중에 뜬 프레임** (아래 설명) |

**공중 프레임의 (35, 70)이 뭔가** — 게임 속 캐릭터의 충돌 상자는 **발바닥 y111에서 위로 82px**다.
그 상자의 한가운데가 y70이다. 공중 동작은 발이 땅에 없으므로 「발바닥 y111」을 쓸 수 없고,
대신 **몸통 무게중심을 y70에 놓아야** 점프·낙하와 이어졌을 때 캐릭터가 튀지 않는다.

> ⚠ 기존 5행(지상 대시)이 이 규칙을 안 지켰다. 3·4프레임의 몸이 y60~98에 있어
> **발이 지면에서 17px 떠 보인다.** 새로 그리는 것은 이 실수를 반복하지 말 것.

## 2. 의뢰 A — 창대쉬 (Spear Dash) 【최우선】

### 이게 무슨 동작인가

레퍼런스는 **「오리와 도깨비불」의 충전 점프**다.

1. 공중에서 버튼을 누르면 캐릭터가 **그 자리에 0.2초 멈춰 선다.** 중력도 안 받고 수평 이동도 없다.
   창을 몸 앞으로 모으며 **힘을 응축**한다. — **이 정지가 연출의 핵심이다.**
2. 그다음 **8방향 중 하나로** 창을 앞세우고 **0.15초간 강하게 돌진**한다.
3. 착지하거나 벽에 붙어야 다시 쓸 수 있다.

**「창을 던지지 않는다.」** 창은 끝까지 손에 있다. 몸과 창이 하나의 화살이 되어 날아가는 그림이다.

### 시트 구성 — 별도 파일 `temple_maiden_sdash.png` (648 × 696, 6열 × 6행)

기존 시트를 다시 내보내지 않도록 **새 파일로 분리**한다. 크기는 기존과 동일하다.

| 행 | 프레임 | 내용 | 정렬 |
|---|---|---|---|
| **1** | **3** | **체공(응축)** — 아래 상세 | 공중 (35, 70) |
| **2** | **2** | **→ 수평 돌진** | 공중 (35, 70) |
| **3** | **2** | **↗ 대각 상승 돌진** (45°) | 공중 (35, 70) |
| **4** | **2** | **↘ 대각 하강 돌진** (45°) | 공중 (35, 70) |
| **5** | **2** | **↑ 수직 상승 돌진** | 공중 (35, 70) |
| **6** | **2** | **↓ 수직 하강 돌진** | 공중 (35, 70) |

남는 열은 **완전 투명**으로 비운다.

**8방향을 6종으로 만드는 법** — `←`는 `→`의 좌우 반전, `↖`는 `↗`의 반전, `↙`는 `↘`의 반전.
그래서 **오른쪽 방향만** 그리면 된다. `↑`·`↓`는 반전해도 같으므로 1종씩.

### 1행 체공(응축) 3프레임 — 여기가 제일 중요하다

| 프레임 | 그림 |
|---|---|
| c1 | 돌진 직전 자세. 몸이 살짝 **웅크리고** 창을 몸 앞으로 당긴다. 빛 없음 |
| c2 | 창날 주위에 **금색 빛이 맺히기 시작**. 머리카락·옷자락이 **위로 떠오른다**(무중력 표현) |
| c3 | 빛이 가장 강하다. 창을 정면으로 겨눈 **화살 같은 실루엣**. 발끝까지 일직선 |

> 방향에 상관없이 이 3프레임을 **공용으로 쓴다.** 그러니 특정 방향으로 기울이지 말고
> **똑바로 선 채 힘을 모으는 자세**로 그릴 것.

### 2~6행 돌진 2프레임 — 공통 원칙

| 프레임 | 그림 |
|---|---|
| c1 | 돌진 시작. 몸이 진행 방향으로 **완전히 일직선**, 창끝이 맨 앞 |
| c2 | 돌진 중. c1과 거의 같되 **잔상·속도선**을 더한다. 옷자락이 뒤로 길게 끌린다 |

- **몸이 진행 방향과 정확히 평행**해야 한다. ↗ 돌진이면 몸도 45° 기울어야 한다.
- 창끝이 진행 방향의 **가장 앞**에 온다. 셀 밖으로 나가지 않게 108×116 안에 맞출 것.
- 속도선은 **`#FEFFFD` 1px 선 2~3가닥**으로 절제할 것. 기본 이동기라 이펙트가 과하면 눈이 피로하다.
- ↓ 하강 돌진은 **창을 아래로 겨누고 머리가 위**다. 상하 반전이 아니라 **새로 그린 자세**여야 한다.

## 3. 의뢰 B — 피격 (Hurt) 【함께 요청】

기존 시트에 **없다.** 6행을 「피격·쓰러짐」으로 알고 있었으나 실제로는 **무릎 꿇기**였다.

### 시트 구성 — `temple_maiden_hurt.png` (648 × 232, 6열 × 2행)

| 행 | 프레임 | 내용 | 정렬 |
|---|---|---|---|
| **1** | **3** | **피격 리액션** | 지상 y111 |
| **2** | **4** | **쓰러짐 → 기상** | 지상 y111 |

**1행 피격 3프레임** — 캐릭터가 **오른쪽을 보는 채로 왼쪽(뒤)에서 맞은** 것으로 그린다.

| 프레임 | 그림 |
|---|---|
| c1 | 충격. 상체가 **뒤로 젖혀지고** 머리카락이 앞으로 쏠린다. 창을 든 팔이 벌어진다 |
| c2 | 비틀거림. 한 발 물러선 자세. 창끝이 아래로 처진다 |
| c3 | 회복. 자세를 다시 세우는 중간 단계 (대기 자세로 이어짐) |

**2행 쓰러짐 4프레임** — 무릎 꿇기(6행)와 **확실히 달라야 한다.**
무릎 꿇기는 **통제된 예(禮)**이고 창이 수직으로 유지된다. 쓰러짐은 **통제를 잃은 상태**다:
**창을 놓치거나 땅에 끌리고**, 몸이 옆으로 무너지고, 마지막 프레임은 **바닥에 누운 자세**다.

| 프레임 | 그림 |
|---|---|
| c1 | 다리가 꺾인다. 창을 짚으려다 실패 |
| c2 | 무릎이 땅에 닿고 상체가 앞으로 무너진다. 창이 손에서 미끄러진다 |
| c3 | 옆으로 쓰러지는 중. 창이 바닥에 떨어져 있다 |
| c4 | **완전히 누운 자세.** 이 프레임은 **몸이 바닥선 y110에 닿아야** 한다(떠 있으면 안 됨) |

## 4. 우선순위 — 나눠 받아도 된다

| 순위 | 항목 | 없으면 |
|---|---|---|
| 1 | **창대쉬 1행(체공 3프레임)** | 창대쉬의 정체성인 "0.2초 정지"가 안 보인다 |
| 2 | **창대쉬 2행(수평 돌진 2프레임)** | 가장 많이 쓰는 방향 |
| 3 | 창대쉬 3~6행(대각·수직) | 임시로 수평 프레임을 회전시켜 대용 가능 |
| 4 | 피격 1행(리액션 3프레임) | 맞아도 반응이 없어 보인다 |
| 5 | 피격 2행(쓰러짐 4프레임) | 사망 연출을 페이드로 대체 가능 |

## 5. 납품 시 확인 요청

받은 뒤 이쪽에서 자동 검사할 항목이다. 미리 맞춰 오면 재작업이 없다.

- [ ] 시트 크기가 지정값과 정확히 일치
- [ ] 셀 격자 108×116으로 나누어떨어짐
- [ ] 알파 중간값(1~254) 픽셀 **0개**
- [ ] 팔레트 24색 밖의 색 **0개**
- [ ] 지상 프레임의 몸 픽셀 마지막 행 = **y110**
- [ ] 공중 프레임의 몸 무게중심 = **(35, 70) ± 3px**
- [ ] 캐릭터가 **오른쪽**을 향함
- [ ] 빈 셀은 완전 투명
