## 1. 현재 살아있는 방향 — "부랑아 × 명문 마법학교" (2026-07-20 채택)

### 1.1 한 줄
> **훔치려다 걸린 부랑아가, 명문 마법학교에 귀족 소녀의 시종으로 굴러들어온다.
> 제대로 된 마법은 못 배워 투박한 마력 덩어리뿐이라 비웃음당하지만,
> 길에서 익힌 체술로 그걸 휘둘러 동급생을 압도한다 — 다만 사거리도 속성도 없는, 딱 그만큼.**

### 1.2 주인공 · 마법 정체성 (시스템 직결 — "시스템=서사"의 핵)
- **무속성 마력 덩어리 = 못 배운 흔적.** 숨겨진 재능·혈통 아님 — 골목에서 혼자 벼린 생존 마법. 근접 전용.
- **체술 = 이동기.** 대시·이단점프·벽달리기로 거리를 지우고 후려침 = 이미 구현된 이동 중심 스타일리시 전투의 서사적 근거. 엘리트 눈엔 "천박한 길거리 싸움"으로 무시당함(실제로 통해도).
- **"더 강하다"가 아니라 "다르게 강하다."** 기동·깡은 압도 / 사거리·속성·정면 물량은 진짜 열세. 동급생 상대 스크래피한 승리까지만 — **커브스톰프·먼치킨 금지.** 강자 앙상블은 까마득.
- **마나 총량 결핍(잠정 — 유저 제안+원인 변형, 명시 승인 대기)**: 원인 = **계급**(굶으며 자라 그릇이 작음), 타고난 재능 부족 아님('재능 로또' 회피). 타격=마나 수급 시스템과 시너지 — **결핍이 파고드는 공격성을 강제**, 난사는 마나 부자 엘리트의 특권.
- **성장 = 정제**: 덩어리 → 칼날 → 속성 칼날(정수 장착) = **무기 모양의 정제가 곧 계급 상승 게이지.** 현 스프라이트의 칼 = 중간 단계.
- **스타일 = 스트리트식 화려함 (혼합형 채택)**: 후반에도 우아해지지 않는다 — 정식 마법을 훔쳐다 **'틀리게' 씀**(불을 움켜쥐고 채찍처럼 휘두르고, 폭발을 타고 이동). 화려함의 출처 = 정교함이 아니라 **스케일+곡예+규칙파괴**(DMC/스컬 결). **엘리트는 더 예쁘고, 그는 더 멋지다.** 학교의 "세련화 압박" = 계급 동화의 은유 — 컨셉 훼손이 아니라 테마 자산.

### 1.3 튜토리얼 = 입학 계기 = 조작 학습 = 마법의 근거 (한 장면 삼중 결합)
- **"마법 리빌 스카우트"(길바닥 애가 마법 뿜자 발탁) 클리셰 금지** — 캐릭터 충돌로 연다.
- **채택 셋업**: 귀족 소녀의 것을 **훔치다 걸림 → 처벌/빚으로 그녀의 시종이 되어 입학.** 입학 = 축복이 아니라 형벌·거래 → 능동 드라이브·원한 자동 확보.
- **첫 대면 대사 훅**: 시종 주제에 눈을 안 깔고 — **"내가 너처럼 배웠으면 너보다 강했어!"** (라이벌 씨앗 + 계급 선전포고 + 성격 제시를 한 컷에)
- 마력 덩어리는 몸싸움 중 **자연 발현** = A 기본공격 학습(드라마 트리거 아님). 거리 파트에서 이동·점프·대시 학습(허슬 코미디 톤).
- ※ 현재 구현된 튜토리얼(오브 습득 5방/연속 월드 오프닝)은 **기계 검증용** — 스토리 확정 후 이 비트로 재작성 대상.

### 1.4 귀족 소녀 (상세 미정)
- **엔딩 관여 확정 방향** (유저 지시).
- **츤데레 로맨스 히로인으로 납작화 금지** — 우아함↔투박함 대비쌍의 진짜 상대(경멸·흥미·복잡함 가능). 로맨스는 생겨도 클리셰 회피가 우선.

### 1.5 중심 갈등 — 후보 2안 (미정, "나중에 정하자")
- **A. 소녀의 짐**: 시종으로 곁에 붙으며 그녀가 짊어진 것(운명·가문·비밀)에 끌려들어감. 그의 길거리 힘+체제 밖 위치가 그 문제를 건드릴 수 있는 유일한 것. "왜 시종으로 넣었나" = 그걸 아는 누군가의 선택.
- **B. 둘 다 갇힌 자**: 그는 가난·시종 신분에, 그녀는 귀족·기대라는 금박 감옥에 — 정반대 감방의 두 사람이 서로를 알아보고, 서로의 자유가 얽힘.
- **"왜 시종으로 넣었나" = 플롯 척추 후보.** 단 **개인 사연 크기** — 사악한 학교 음모 금지(외부 기관 중력 쏠림 기각 이력).

### 1.6 중간 에피소드 자산 (엔딩 아님 — 유저 지시로 강등)
- **길거리 친구들 ↔ 학교 친구들 정체성 갈등, 멀어지는 사건.** 세계구원이 아닌 개인 사연 크기의 상실. 크리퍼스큘 순서 — 초반에 안 깔고 중반 어느 날 조용히.
- 정식 마법을 "그들 방식대로 고쳐 쓰라"는 학교 압박 ↔ 거부 = 정체성 사수 = 스타일(1.2)과 같은 축.

### 1.7 강자 앙상블 (구 "일곱 영웅"의 계승 — 신화만 버림)
- 앙상블 **기법**(§2.5-5)은 유지. 이제 정체 = **계급 사다리 꼭대기의 강자들.** 학교 이벤트(특강·승급 심사·실습 인솔)로 자연 조우 — **닿는 것 자체가 계급 상승.**
- 후보 훅: **하나는 밑바닥 출신으로 '동화'해 올라간 자** = 주인공이 될 수도 있는 미래의 거울/경고.
- 숫자·명칭 미정 ('일곱'은 구 설정 잔재 — 유지 여부 유저 결정 대기).

### 1.8 엔딩 (미정 — 갈등 확정 후 도출)
- **확정된 조건**: 여운 필수 + **소녀 관여.**
- **기각**: 정체성 선택형("소속이냐 나냐"), 출신·거리 회귀형, 관계 여운 3안(빈자리·뒤늦게 안 진심·못 돌아가는 자리 — 제시 형태로는 "별로").
- **절차**: 중심 갈등(1.5 A/B) 확정 → 엔딩은 그 논리적 귀결로 후보 도출.

### 1.9 톤 계약 (유저 명시)
- **메인 척추 = 여운 / 서브·로컬 = 발랄한 마법학교.** §2.5 그라디언트·격리 그대로.
- 발랄 = 주인공이 갖고 싶은 것(=잃을 것)이라, **서브가 밝을수록 메인이 아프다** — 두 톤이 서로를 강화.
- 매체 경계: 웹소설/웹툰化 주의 — §2.5-7 게임-네이티브 전달 원칙으로 통제.

## 2. 유저 취향 프로필 (기각 이력 — 새 세션 필독)

### 기각된 방향들 (이유와 함께)
- **[2026-07-20] "신적 존재(그것)+일곱 영웅" 골격 전체** — "뼈대 자체가 마음에 안 듦". 파생 동기 3안(《기다리는 것》《끝을 찾는 것》《약속을 지키는 것》), 능동 변형 A(재앙을 죽이러 온 학생)·B(재앙을 부르는 아이) 동반 기각. **앙상블 기법·톤 원칙만 생존**(§1.7·§2.5).
- **[2026-07-20] 시한부(빌린 삶)·정체 위장(가짜 학생)·침입 목적(단 하나를 훔치러) 3안** — "다 별로".
- **[2026-07-20] 이세계-소원 안**(유저 제안: 소원을 잘못 빌어 떨어짐→귀환 목표) — 부랑아 안과 비교 후 **대체**. 사유: 이세계 프레임=최대 포화 양산형·"싼마이" 옆동네, 전복 비용 상시 부담. 엔진(능동 목표·이방인 다름)은 부랑아 안이 흡수.
- **[2026-07-20] 수동적 미스터리-박스 구조**(당한 뒤 진실 캐기) — 유저는 능동 훅("나는 X를 한다") 선호.
- **[2026-07-20] 마법 리빌 스카우트 입학**("재능을 보이자 발탁") — 식상, 숨은 재능 클리셰.
- **[2026-07-20] 엔딩 후보 기각**: 정체성 선택형, 출신 회귀형, 관계 여운 3안(§1.8).
- **[2026-07-20] 마나 결핍=타고난 재능 부족** — '재능 로또'로 안티클리셰 훼손. 원인은 계급으로(§1.2 잠정).
- 가족 복수, 유언/상속, 대체자 친구 구조 → **"짜침"**
- 신전+축성+순례 스토리 전체 (한때 확정까지 갔다가 폐기) → 학교가 아닌 외부 기관에 스토리 중력이 쏠림
- 지워진 친구(나만 기억), 학교를 되살리기, 어머니의 일곱 동료, 일곱 봉인 해제, 대회/자격, 밤의 집행자(이나리와 겹침), 닫힌 고향(귀향), 일곱 축복 반납, 일곱 예언 격파, 조용한 가장자리 종말 → 각각 "직관성 부족 / 별로 / 기시감"
- 참이름·매개 분과 등 추상 마법 체계, 일곱 영웅+봉인핵 같은 설정 스택 → **"설정 과다"**
- 시스템창·회귀·"SSS급 헌터" 어휘 → **"싼마이"**
- "일곱을 쓰러뜨리고 조각을 수집한다" 전개 → 명시 금지

### 선호가 확인된 것들
- **크리퍼스큘 순서**: 무거운 서사를 앞에 깔지 않음 — 흥미로운 상황으로 끌고 진실은 뒤에서 조금씩, 개인 사연 크기로
- **다름 서사**: 주인공이 근본부터 다른 존재 (크리퍼스큘 라크, 신의 탑 밤) — 부랑아 안에선 '출신+방식의 다름'으로 구현
- **딱 꽂히는 훅**: 이나리("일곱 공주를 처단하는 신의 대리자"), 산나비 급의 한 문장 — **능동형**("나는 X를 한다")
- **학교 중심**, **밝은 시작**, **개인적 동기** (수집·사명·세계구원 아님), **여운 엔딩 + 발랄 서브**(1.9)
- 히어로 킬러식 강자 앙상블 (능력=성격, 대비쌍, 반전 회상)
- **[2026-07-20] 안티클리셰 반전 선호 확인**: 시종=처벌 입학 / 마법=못 배운 흔적 / 강함=체술(재능 아님) / 결핍=계급 — "흔한 전제 + 안 흔한 실행"

### 가드레일 (누적)
- 아르피아/HN/히어로킬러/퀘지주/용돌/이나리/산나비/원신 + **[추가] 스컬/크리퍼스큘/신의 탑/DMC/기생충**: **원리만, 표면 금지** — 상세는 기획서 §11
- 이전 스토리(신전 버전·그것 버전)에서 했던 검증 결과는 폐기된 구조 기준이므로 무효. 새 스토리 확정 시 재검증 필수.

## 2.5 서사 운영 공통 원칙 (어떤 스토리를 채택하든 적용)
1. **크리퍼스큘 순서**: 무거운 서사를 앞에 깔지 않는다 — 흥미로운 일상/상황으로 끌고, 진실은 뒤에서 조금씩.
2. **설정 총량 규칙**: 시작에 필요한 설정은 한 문장. 세계 규칙 강의 금지. 진실도 '개인 사연' 크기.
3. **톤 그라디언트 + 격리**: 1막 밝음 90/10 → 2막 70/30 → 3막 반전. 어둠은 특정 공간·스레드에 격리하고 학교는 끝까지 피난처 — 후반에도 일상 루프는 살아 있고, 코미디 담당은 끝까지 코미디를 친다.
4. **지역 콘텐츠 60/20/20**: 지역당 로컬 스토리/탐험 60 + 학교 연계 20 + 메인 척추 20. 각 지역은 메인 플롯 없이도 성립하는 자기 이야기를 가진다.
5. **앙상블 기법 (히어로 킬러에서 '기법만')**: 능력=성격 / 대비쌍 배치 / 과거사는 반전으로 / 지형·조건부 우위 / 초반 강자 동행 → 후반 그들을 넘어서는 카타르시스.
6. **작중 세계에 시스템창·퀘스트창·레벨업 알림 없음.** 감정은 어디까지나 마법(주문). 회귀·헌터·"SSS급" 서술 어휘 금지 — 랭크 표기는 게임 UI 레이어에만 존재.
7. **[2026-07-20 추가] 게임-네이티브 전달**: 컷씬·텍스트 벽·VN 대화창으로 말하지 않는다 — **공간·시스템·희소한 대사·한 컷의 순간**으로 보여준다(산나비/HN 방식). 모든 서사 아이디어는 **"이거 플레이로 어떻게 보여주지?"**를 통과해야 한다. 시스템=서사(덩어리=계급, 이동기=체술, 정수=상승)가 기본기. 1인 개발 물량 통제와도 같은 방향 — 웹소설/웹툰化 방지 장치.

## 3. 스토리와 이미 연결된 시스템 훅 (2026-07-20 갱신)
- **무속성 마력 덩어리/칼날 (기획서 §6.2)** = 못 배운 자의 생존 마법 — 시작 무기이자 계급 표식. 슬롯 면제라는 기계적 특권 = "몸에 밴 것"이라는 서사와 일치.
- **속성 정수 (§3.5)** = 정제된 힘 = 지역 클리어 보상 = **신분 상승의 가시화.**
