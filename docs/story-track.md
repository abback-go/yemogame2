# 스토리 트랙 (논의 중 — 미확정)

> **원칙: 스토리는 확정 전까지 기획서(game-design.md)에 반영하지 않는다.**
> 이 문서는 논의 상태의 스냅샷 — 새 세션이 이어받기 위한 기록이다.
> 확정 시: 전용 표절 검증(필수) → 기획서 반영.

---

## 1. 현재 살아있는 방향 (2026-07 기준)

### 골격: "신적 존재 + 일곱 영웅 앙상블"
- **일곱 영웅**: 쓰러뜨릴 표적도, 통과할 관문도, 수집 조각도 아니다. **세계에 사는 강자들** — 학교 이벤트(특강·승급 심사·실습 인솔), 필요(정보·가르침), 사건 연루로 **자연스럽게 조우**하며, 때로 대립하고 때로 돕는 앙상블. "쓰러뜨리고 조각 수집" 전개는 명시적으로 금지됨.
- **신적 존재 ("그것", 작명 미정)**: 세상에 단 하나뿐인 비인간 존재. 재앙이자 전설. 수십 년에 한 번 목격. **세계 시스템 바깥** — 감정(鑑定) 마법이 실패가 아니라 아예 발동하지 않음 (일곱 영웅=측정 실패, 그것=측정 거부라는 위계).
- **세상이 밝은 이유 (톤 방어)**: 그것의 목표가 파괴·정복이 아니므로 — 군대도 확전도 없고, 출현은 드물고 국지적. 세상은 지진처럼 분류해두고 살아감. 공포는 사회가 아니라 **주인공 개인의 것**.
- **김민수(용사가 돌아왔다) 정수 계승**: "논리가 이해되는 괴물" — 연민과 공포가 같은 컷에. 표면(귀환 용사·세상 복수·청구서 심리·도시 증발)은 전부 금지.

### 주인공 동기 — 검토 중인 패키지 3안 (다음 결정 사항)
1. **《기다리는 것》 (Claude 추천)** — 그것은 아주 오래전 잃은 단 한 사람을 찾아 수백 년 헤맨다. 출현 = 확인. 어린 시절 그것이 주인공을 들여다보고 **내 것이 아닌 이름으로 부르고, 울고, 떠났다.** 주인공 = 선택받은 자가 아니라 **오인당한 자**. 동기 = 그 이름의 추적 ("그것이 내게서 본 사람은 누구인가. 착각을 깨달았을 때 그것은 어떻게 하는가"). 일곱 영웅은 **지난 세대에 그것이 '누군가를 찾았다고 믿었던' 사건**과 저마다 다르게 얽힘 (라쇼몽 + 주인공이 그 이름을 말하는 순간 굳는 노영웅들).
2. **《끝을 찾는 것》** — 죽을 수 없는 존재가 자신의 끝을 찾아 헤맨다. 전설상 멈추는 법이 없는 그것이, 그날 밤 어린 주인공 앞에서 처음으로 멈췄다. (셋 중 가장 어두움)
3. **《약속을 지키는 것》** — 아무도 기억하지 않는 오래된 의무를 수행 중 — 세상이 재앙이라 부르는 것은 그것이 막고 있는 더 나쁜 것의 그림자. 그날 밤 어린 주인공이 우연히 그 의무를 도왔다/방해했다. (기시감 리스크 — 신형 고질라류)

### 확정 시 다음 작업 순서
패키지 선택 → "그 이름의 주인"/"그날 밤" 설계 → 일곱 영웅 관계도(각자의 그것과의 역사 = 일곱 가지 다른 증언) → **전용 표절 검증** (히어로 킬러 '철의 마녀' 실제 설정과의 거리 확인 포함 — 유저가 직접 예시로 든 캐릭터) → 기획서 반영.

## 2. 유저 취향 프로필 (기각 이력 — 새 세션 필독)

### 기각된 방향들 (이유와 함께)
- 가족 복수, 유언/상속, 대체자 친구 구조 → **"짜침"**
- 신전+축성+순례 스토리 전체 (한때 확정까지 갔다가 폐기) → 학교가 아닌 외부 기관에 스토리 중력이 쏠림
- 지워진 친구(나만 기억), 학교를 되살리기, 어머니의 일곱 동료, 일곱 봉인 해제, 대회/자격, 밤의 집행자(이나리와 겹침), 닫힌 고향(귀향), 일곱 축복 반납, 일곱 예언 격파, 조용한 가장자리 종말 → 각각 "직관성 부족 / 별로 / 기시감"
- 참이름·매개 분과 등 추상 마법 체계, 일곱 영웅+봉인핵 같은 설정 스택 → **"설정 과다"**
- 시스템창·회귀·"SSS급 헌터" 어휘 → **"싼마이"**
- "일곱을 쓰러뜨리고 조각을 수집한다" 전개 → 명시 금지

### 선호가 확인된 것들
- **크리퍼스큘 순서**: 무거운 서사를 앞에 깔지 않음 — 흥미로운 상황으로 끌고 진실은 뒤에서 조금씩, 개인 사연 크기로
- **다름 서사**: 주인공이 근본부터 다른 존재 (크리퍼스큘 라크, 신의 탑 밤)
- **딱 꽂히는 훅**: 이나리("일곱 공주를 처단하는 신의 대리자"), 산나비("정체불명의 산나비에게 딸의 복수") 급의 한 문장
- **일곱 구조** (앙상블로서 — 표적 아님), **학교 중심**, **밝은 시작**, **개인적 동기** (수집·사명·세계구원 아님)
- 히어로 킬러식 강자 앙상블 (능력=성격, 대비쌍, 반전 회상), 용사가 돌아왔다 정서 (과하지 않게)
- 신적 존재 중심 구도 (유저 본인이 '철의 마녀'를 예로 들며 채택)

### 가드레일 (누적)
- 아르피아/HN/히어로킬러/퀘지주/용돌/이나리/산나비/원신: **원리만, 표면 금지** — 상세는 기획서 §11
- 이전 스토리(신전 버전)에서 했던 검증 결과는 폐기된 구조 기준이므로 무효. 새 스토리 확정 시 재검증 필수.

## 2.5 서사 운영 공통 원칙 (기획서 §9에서 이관 — 어떤 스토리를 채택하든 적용)
1. **크리퍼스큘 순서**: 무거운 서사를 앞에 깔지 않는다 — 흥미로운 일상/상황으로 끌고, 진실은 뒤에서 조금씩.
2. **설정 총량 규칙**: 시작에 필요한 설정은 한 문장. 세계 규칙 강의 금지. 진실도 '개인 사연' 크기. 신적·근원적 존재는 끝까지 설명하지 않는다.
3. **톤 그라디언트 + 격리**: 1막 밝음 90/10 → 2막 70/30 → 3막 반전. 어둠은 특정 공간·스레드에 격리하고 학교는 끝까지 피난처 — 후반에도 일상 루프는 살아 있고, 코미디 담당은 끝까지 코미디를 친다.
4. **지역 콘텐츠 60/20/20**: 지역당 로컬 스토리/탐험 60 + 학교 연계 20 + 메인 척추 20. 각 지역은 메인 플롯 없이도 성립하는 자기 이야기를 가진다.
5. **앙상블 기법 (히어로 킬러에서 '기법만')**: 능력=성격 / 대비쌍 배치 / 과거사는 반전으로 / 지형·조건부 우위 / 초반 강자 동행 → 후반 그들을 넘어서는 카타르시스.
6. **작중 세계에 시스템창·퀘스트창·레벨업 알림 없음.** 감정은 어디까지나 마법(주문). 회귀·헌터·"SSS급" 서술 어휘 금지 — 랭크 표기는 게임 UI 레이어에만 존재.

## 3. 스토리와 이미 연결된 시스템 훅 (기획서에 있는 것들)
- NPC·특수 속성 (§3.2) — 강자 연출용, 스토리 결부 속성(신성 등)의 배치는 스토리 확정 후
- 첫 학교(폐교) — 협곡 건너편에 첫날부터 보이는 랜드마크 (떡밥 창고, world-map.md)
- 서사 운영 공통 원칙 (§2.5) — 어떤 스토리든 적용
- ※감정 실패/측정 거부 위계는 폐기됨(2026-07-17) — 감정은 누구에게나 성공하는 작은 요소. 강자의 '읽히지 않음' 연출을 쓰려면 감정과 무관한 별도 장치 필요.
