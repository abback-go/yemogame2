# 이동 마법 스펙 v2.1 — 플레이어 컨트롤러 구현 사양

> 2026-07-17 개정 (v2 → 유저 2차 손맛 테스트 피드백 4건 반영: 부유 지속·쿨 / 얼음 발판 1개·쿨 / 물잠 산소 시스템 / 벽 재부착 금지). 기획서 §3.2-③의 구현 사양.
> 수치는 시작값 — 유저 F5 손 튜닝으로 확정. **공통 원칙: 모든 이동 마법은 마나를 소모한다** (지상 회복이 평지 이동을 상쇄 — 걷기는 공짜처럼, 공중 곡예는 마나만큼).

## 1. 조작 키 배치

| 키 | 동작 |
|---|---|
| ←→ | 이동 |
| ↓ (공중 홀드) | **활공** (v2 변경 — 이단점프와 키 충돌 해소) |
| Z / Space | 점프 / 공중: 이단점프 |
| C / Shift | **대시 — 지상: 수평 / 공중: 방향키 조합 8방향** (무입력 = 바라보는 방향) |
| X (홀드) | **부유** — 제자리·제높이 고정 |
| A | **얼음 발판 설치** (전용 키) |
| D | **비행 발동** (전용 키) |
| 1~9 | 능력 토글 / F 마나 리필 / R 리스폰 / Esc 메뉴 |

## 2. 능력 스펙 (v2 확정)

| # | 능력 | 기본 | 스펙 |
|---|---|---|---|
| 1 | 대시(지상) | ON | 수평 620·0.14s·쿨 0.38s·무적 없음·**마나 4**. 획득 서사: 튜토리얼 첫 습득 마법. 성장: 마력석 강화 1단계당 거리 +12% |
| 2 | 대시(공중) | ON | **8방향** (방향키 벡터, 대각 정규화 — 거리 동일), 공중 1회(착지·벽접촉 회복), **마나 4** |
| 3 | 부유 | ON | X 홀드: **그 자리·그 높이에 고정**(속도 급감쇠 →0), 방향 전환 + 미세 표류(초당 40)만 허용. **지속 최대 2.0초** — 시간 만료·홀드 해제·마나 0이면 해제. **해제 후 쿨타임 3.0초, 착지 시 쿨 즉시 초기화**(지상 경유 없는 공중 재사용 차단). 마나 3·초 유지 |
| 4 | 이단점프 | OFF | 공중 Z 1회(-560), **마나 5**. 얼음 발판과 독립(조합 가능) |
| 5 | 벽달리기 | OFF | **모든 벽에서 발동(오리 방식)** — 상승 380, **1회 0.8s(~300px)**, 벽도약(±420/-520), **발동 중 마나 6·초**. **같은 방향 벽 재부착 금지: 주행한 방향의 벽은 잠기고, 해제 조건은 ①바닥 착지 ②반대 방향 벽 주행 단 둘뿐** — 탈부착 반복(홀드 해제→재홀드)으로는 타이머가 리셋되지 않는다(무한 상승 익스플로잇 봉쇄). 속성 연결 없음, 초반 수업 습득 |
| 6 | 얼음 발판 | OFF | **A 키 설치형** — 시전 순간 발밑 위치에 얼음 발판 생성, **3초 유지**, **동시 최대 1개**(새로 설치 시 기존 즉시 파괴), **쿨타임 5.0초**, **개당 마나 12**. **설계 의도: 쿨(5s) > 유지(3s)** — 연속 설치 공중 사다리 불가. *"모자란 발판 하나를 채우는 스킬이지, 아무 데나 가는 스킬이 아니다."* 이단점프 등 조합은 유지 |
| 7 | 활공 | OFF | **↓ 홀드**(공중): 낙하 상한 140, 상승기류 존 위 -260, **마나 2·초** |
| 8 | 물잠 | OFF | 물속 4방향 수영 240. **자원은 산소→마나→체력 3단 버퍼**: 잠수 중 ①**산소 10·초** 소모(마나 무소모) → ②산소 0이면 **마나 8·초** → ③마나도 0이면 **익사: 2초당 체력(마스크) 1 + 화면 경고**. 강제 부상 없음 — 버틸지는 플레이어의 선택. 산소는 물 밖·수면에서 **40·초 회복**, 맵의 **산소통(공기 방울) 접촉 시 즉시 리필**. OFF면 수면 부유만(잠수 불가) |
| 9 | 비행 | OFF | **D 키 발동형** — 마력 날개 소환, **6초** 자유 비행(방향키 300, 정규화). **마나 45 선불 + 쿨타임 12초**. 마나 부족 시 발동 불가. 상승기류 결합(연출·연장)은 추후 |

## 3. 공통 물리 (프로토타입 이식 — 유지)

달리기 280 / 가속 2600 / 감속 3200 / 중력 1500 / 낙하 상한 900 / 점프 -620 / 컷 -180 / 코요테 0.09 / 선입력 0.12 / 히트박스 20×34

## 4. 자원 (테스트 최소 구현)

- **마나 100** / 회복: 지상 20·초, 공중 6·초 / F 리필
- **산소 100** (v2.1) — 잠수 중 10·초 소모(=풀 산소 10초), 물 밖·수면 40·초 회복, 산소통 접촉 시 즉시 100. F 리필에 포함
- **체력 5 마스크** (물잠 익사 테스트용 최소 구현) — 0이면 리스폰

## 5. 레벨 디자인 연동 규칙 (월드 문서와 공유)

**통과 불가 수직 장벽 = 공중 체인 최대 수직 도달(점프+이단점프+상향 대시+벽달리기 1회 ≈ 400px, 튜닝 후 확정)보다 높은 민벽(중간 선반 없음) / 처마(오버행) / 위험 표면.** 굴뚝(마주보는 벽 쌍)은 의도된 등반 루트에만 배치. — 벽달리기 전벽 허용·8방향 대시 채택의 대가로 이 규칙이 룬 벽을 대체한다.

## 6. 테스트 방 요구 (v2 유지 + v2.1 추가분)

기존 8종 지형 유지 + ①대각 대시 검증 갭(45° 상단 선반) ②얼음 발판 조합 코스(팻말: "A로 발판을 놓고, 이단점프로 넘어가라") ③깊은 물(익사 경고 확인 가능한 깊이) ④부유 고정 확인 갭 ⑤비행 도달 목표(6초 내 왕복 거리감 확인) ⑥**(v2.1) 깊은 물 바닥에 산소통(공기 방울) 1개** — 접촉 시 산소 즉시 리필, 소비 후 **5초 뒤 재생성**(시각: 하늘색 원)
