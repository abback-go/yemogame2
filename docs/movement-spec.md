# 이동 마법 스펙 v1 — 플레이어 컨트롤러 구현 사양

> 2026-07-17 작성. 기획서 §3.2-③(이동 체계 v2)의 구현 사양. 수치는 전부 **시작값**(HTML 프로토타입 v0.2 검증값 이식 + 신규 마법은 추정치) — 유저의 F5 손 튜닝으로 확정한다.
> 대화에서 결정됐으나 기획서에 없던 2가지(조작 키 배치, 마법별 상세 스펙)를 이 문서가 확정 기록한다.

## 1. 조작 키 배치 (테스트 빌드)

| 키 | 동작 |
|---|---|
| ←→ | 이동 / ↓ 아래(수영 하강 등) |
| Z / Space | 점프 (공중: 이단점프 또는 얼음 발판) |
| C / Shift | 대시 (지상·공중) |
| X (홀드) | 시전 자세 — 공중이면 **부유** 발동 (컨트롤러 테스트용 더미 시전) |
| ↑ (홀드, 공중) | **비행** (켜져 있을 때) — 방향키로 자유 비행 |
| 1~9 | 능력 토글 (아래 표) |
| F | 마나 즉시 리필 (디버그) |
| R | 리스폰 / Esc | 메뉴 |

## 2. 능력 토글 (1~9) — 시작 킷만 기본 ON

| 키 | 능력 | 기본 | 스펙 (시작값) |
|---|---|---|---|
| 1 | 대시(지상) | **ON** | 속도 620, 지속 0.14s, 쿨 0.38s, 무적 없음, 대시 중 중력 0 (프로토타입 이식) |
| 2 | 대시(공중) | **ON** | 지상과 동일 스펙, 공중 1회 — 착지·벽 접촉 시 회복 |
| 3 | 부유 | **ON** | X 홀드 + 공중일 때 중력 ×0.15, 최대 0.6s/회, 착지 시 회복 (프로토타입 영창 부유 이식) |
| 4 | 이단점프 | OFF | 공중 Z 1회, 점프력 = 지상 점프의 0.9배 (-560) |
| 5 | 벽달리기 | OFF | 벽 접촉 + 벽 방향 입력 시 벽을 타고 상승: 속도 380, 최대 0.8s. 벽에서 Z = 벽도약(수평 ±420 / 수직 -520). 같은 벽 연속 재달리기 불가(반대벽 or 착지 후 회복) |
| 6 | 얼음 발판 | OFF | 공중 Z 시 발밑에 얼음 발판 생성+재도약(-620, 이단점프 대체·상위호환). 발판은 0.75s 유지 후 파괴, 밟고 재점프 가능. 공중 1회(착지 회복). ON이면 이단점프보다 우선 |
| 7 | 활공 | OFF | 공중에서 Z 홀드 시 낙하 속도 상한 140으로 감속. 상승기류 존 위에서는 -260으로 상승 |
| 8 | 물잠 | OFF | 물 존에서: OFF = 수면에 뜨기만(잠수 불가) / ON = 방향키 4방향 수영(속도 240) + **산소 대신 마나가 1초당 8 소모**, 마나 0이면 수면으로 강제 부상 |
| 9 | 비행 | OFF | 공중에서 ↑ 홀드로 발동, 방향키 자유 비행(속도 300). **마나 1초당 12 소모**, 마나 0이면 해제. 상승기류 존에서는 소모 절반+속도 1.5배 |

## 3. 공통 물리 (HTML 프로토타입 v0.2 이식 — 검증된 손맛)

달리기 280 / 가속 2600 / 감속 3200 / 중력 1500 / 낙하 상한 900 / 점프 -620 / 점프 컷 -180 / 코요테 0.09s / 점프 선입력 0.12s / 히트박스 20×34 (아트 치수 확정 시 ~54 스케일로 재조정 예정 — 지금은 프로토 비율 유지)

## 4. 마나 (컨트롤러 테스트용 최소 구현)

풀 100 / 자동 회복 6·초 (지상에서만 20·초) — 물잠·비행의 자원 긴장 테스트용. 전투 수급은 다음 단계.

## 5. 테스트 방 요구사항 (능력별 검증 지형 — 한국어 팻말 포함)

① 대시 갭 240px·380px(공중 대시 필요) ② 이단점프 선반(단일 점프 불가 높이 180px) ③ 벽달리기 수직 통로(높이 500px, 폭 140px) ④ 얼음 발판 고탑(연속 발판 필요 400px 상승) ⑤ 활공 활강 코스 + 상승기류 기둥(시각화된 존) ⑥ 물 웅덩이(깊이 300px, 바닥에 보상 표시) ⑦ 비행 시험 개활지 + 높은 도달 목표 ⑧ 부유 테스트: 갭 위에서 X 홀드로 체공 확인

## 6. 디버그 HUD

능력 1~9 ON/OFF 목록(현재 상태 색 표시) / 마나 바 / 속도·상태 표시(디버그) / 키 안내 / 토글 시 토스트 메시지

## 7. 구현 제약 (레포 규칙)

- Godot 4.7, 런타임 조립 원칙(씬 파일은 최소, 노드는 코드 생성 — 4.7 교훈), SystemFont 한국어 UI, `[진단]` 출력 패턴
- gdparse·gdlint 통과 필수 (한 줄 100자 제한)
- 기존 launcher 메뉴 [1]이 이 테스트 방으로 진입
