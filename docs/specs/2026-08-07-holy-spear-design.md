## 0. 한 줄 요약 (Elevator Pitch)

> "신전에서 창술과 신성력을 익힌 젊은 성창사(聖槍士)가 되어, **잊힌 성물(聖物)을 되찾으러 인간계로 강림**한다.
> 창의 리치와 신성력을 엮은 손맛 있는 근접 액션으로 타락한 마을과 야생을 헤쳐 나가고,
> **성물을 하나씩 되찾을 때마다 새로운 힘(=탐험의 열쇠)이 열리는** 할로우 나이트식 메트로바니아."

---

## 1. 디자인 필러 (Design Pillars)

충돌 시 우선순위는 번호 순.

1. **손맛 있는 창 액션 (Feel First)**
   창 특유의 **리치·간격 싸움**(찌르기·쓸기·올려베기) + 산나비식 묵직한 히트스톱·화면흔들림. 신성력으로 창을 빛으로 강화하는 "한 방"의 쾌감. **때리는 것 자체가 재밌어야 한다.**

2. **성물이 곧 성장이자 열쇠 (Relic = Power = Key)**
   성물을 되찾으면 **새 이동기/신성기**가 열리고, 그 힘이 **막혀 있던 지역을 여는 열쇠**가 된다. 스토리(성물 회수)·성장·탐험이 하나의 축으로 돌아간다.

3. **하나의 이어진 세계 (One Connected World)**
   포탈로 잘린 스테이지가 아니라, **인간계 전체가 연결된 지도**. 지름길·비밀·되돌아오기(백트래킹)의 재미. 능력이 늘수록 세계가 넓어진다.

4. **신전이라는 집 (A Home to Return To)**
   신전은 안전한 주거지 — 스승에게 배우고, 힘을 벼리고, 되찾은 성물을 안치하며 성장을 실감하는 곳. 인간계 탐험과 신전 귀환의 리듬.

## 2. 레퍼런스 — 무엇을 가져오고 버리나

| 요소 | 할로우 나이트 | 산나비 | 본작 채택 |
|---|---|---|---|
| 월드 | 거대한 연결 지도·능력 게이팅·백트래킹 | 선형 스테이지 | **연결 지도 + 능력 게이팅(성물)** |
| 전투 | 근접(가시촉수)·차지·주문 | 그래플·모멘텀·연출 | **창 근접 콤보 + 신성기 + 모멘텀 이동** |
| 타격감 | 담백·정확 | 히트스톱·카메라워크 강함 | **산나비식 juice를 창 액션에 이식** |
| 성장 | 부적(charm)·능력 획득 | 선형 강화 | **단일 스킬트리 + 성물 능력 + 랭크 스탯** |
| 분위기 | 정적·고독·미스터리 | 스타일리시·질주감 | **타락한 인간계의 애수 + 신성의 빛(대비)** |

**핵심 방향:** 세계·탐험 = 할로우 나이트 / 조작·타격감·질주 = 산나비 / 정체성 = **창 + 신성력 + 성물**.

## 3. 세계관 컨테이너 (구조 중심, 서사는 후속)

### 3.1 두 세계
- **신전(Temple) — 천상/성역:** 플레이어의 집이자 수련처. 하늘 위(또는 세계와 격리된 성역)에 있는 신성 기관. **마법학교의 역할을 그대로 계승**(배움·성장·귀환의 안전지대).
- **인간계(가칭, Human Realm) — 지상:** 신전 아래로 펼쳐진 인간들의 세계. 지금 **타락(마·역병·그림자)**이 번지고 있고, 오래전 흩어진 **성물**들이 곳곳에 잠들어 있다. **메트로바니아 탐험 무대.**

### 3.2 왜 강림하는가 (스토리 훅 — 잠정)
- 신전의 힘의 원천이던 **성물들이 오래전 인간계로 흩어져 잊혔고**, 그것들이 잠든 자리마다 타락이 스며들고 있다.
- 젊은 성창사(플레이어)는 **첫 강림**을 명받아 인간계로 내려가, **성물을 하나씩 되찾아 정화하며** 마을을 돕고 타락의 근원을 좇는다.
- 톤: **밝은 성장물 + 모험**을 기본으로, 타락한 지상의 애수를 대비로. (다크 판타지로 무게를 더 실을 여지는 열어둠.)

### 3.3 허브 = 신전 (상시 오가는 안전지대)
| 구역 | 기능 (구 학교 대응) |
|---|---|
| 대성전(중앙) | 스폰·집결, 신탁 게시판(퀘스트/공지) |
| 수련장 | 창술·신성기 실습, 허수아비 DPS 체크 |
| 사범실(강의) | **수업 = 스킬 습득 진입점** (스승 티어 §7) |
| 성물 안치소 | 되찾은 성물 전시·강화·능력 확인 (진행 실감) |
| 벼림간(공방) | 창·신성구 제작·강화·각인 |
| 회복소·양성소 | 세이브·휴식·소모품 |
| 강림문(게이트) | 인간계로 내려가는 문 (강림/귀환) |

### 3.4 인간계 = 메트로바니아 지도 (포탈 폐지, 연결형)
- 인간계는 **하나의 이어진 대형 지도**. 지역은 문·통로·수직 갱도로 자연스럽게 연결(로딩 경계는 방 단위).
- **강림 사당(Descent Shrine):** 지도 곳곳의 세이브·귀환·순간이동 지점. 신전과 인간계를 잇는다.
- **마을 = 서브 허브:** 인간계 안의 안전지대(주민 NPC·소상점·퀘스트). 단, **배움·핵심 강화는 신전**에서.
- **능력 게이팅:** 성물로 얻은 능력이 곧 열쇠 → 없으면 못 가는 길이 도처에(백트래킹 유도).
- **확장 원칙:** 새 콘텐츠 = 새 방/지역 추가 + 연결 + (필요시) 게이트. 데이터 주도(§16).

## 4. 플레이어 정체성 (종족·전공 폐지 → 단일 성창사)

> **결정(2026-08-07):** 종족 시스템 폐지, 전공/학과(전직 트리) 폐지. 플레이어는 **단일 클래스 "성창사"**.
> 개성은 **단일 스킬트리(§5)의 빌드 선택**과 **성물·각인 조합**으로 낸다. (1인·초보 개발 스코프에 최적.)

- 플레이어 = 신전에서 자란 젊은 성창사. 무기는 **창(고정 주무기)**, 힘의 원천은 **신성력**.
- "정답 빌드"가 아니라 **플레이스타일 선택**(공격 특화/생존·정화 특화/기동 특화)이 트리·성물·각인으로 갈린다.

## 5. 단일 스킬트리 (창술 + 신성술 통합)

> 전공 분기 없음. **모두가 하나의 트리**를 공유하고, 어디에 투자하느냐로 빌드가 갈린다.

### 5.1 구조
```
                 ┌── 창술(槍術) 가지 ── 콤보·차지·리치·기동 강화
[중앙: 기본기] ──┼── 신성(神聖) 가지 ── 신성기·창 강화·정화·보호
                 └── 공용 가지 ────── 체력·신성력·유틸·각인 슬롯
```
- **노드 해금 3열쇠:** ① **스킬 포인트(SP)**(레벨업) ② **수업 이수**(특정 노드는 스승에게 배워야 열림, §7) ③ **성물**(특정 노드는 해당 성물이 있어야 열림).
- 한 번에 다 못 찍음 → **선택과 재분배(리스펙)**로 다회차·실험. 리스펙은 신전에서 제한적 허용.

### 5.2 대표 노드 예시
| 가지 | 노드 예 | 효과 |
|---|---|---|
| 창술 | 삼재 연격 강화 | 3타 콤보에 4·5타 파생 추가 |
| 창술 | 관통 차지 | 차지 찌르기 관통·경직↑ |
| 신성 | 창 강화 지속↑ | 빛의 창 강화 모드 시간·리치 증가 |
| 신성 | 정화 확산 | 정화 시 광역 + 아군/자힐 강화 |
| 공용 | 신성력 순환 | 평타 적중 시 신성력 회복량↑ |
| 공용 | 각인 슬롯 +1 | 각인(charm) 장착 칸 확장 |

## 6. 성장 시스템

### 6.1 성장 3축
1. **성물(진행 게이트) ★핵심** — 되찾으면 새 능력 해금 + 새 지역 개방. 스토리 = 성장 = 탐험 (§10).
2. **랭크 스탯(D~SSS)** — 몸의 능력치. 수련·퀘스트·위계 시험으로 상승(§6.2).
3. **단일 스킬트리(SP)** — 전투 표현. SP + 수업 + 성물로 노드 해금(§5).

### 6.2 랭크 스탯 (D~SSS) — 유지·리테마
> 『퀘스트지상주의』식. 스탯은 숫자가 아니라 **랭크**로만 보인다("근력 C+"). 미세 증가 대신 **랭크가 오르는 순간의 쾌감**.

- **사다리(15단):** `D- D D+ → C- C C+ → B- B B+ → A- A A+ → S → SS → SSS`
- **색 문법:** D 회색 → C 초록 → B 파랑 → A 보라 → S 금 → SS 진홍금 → SSS 프리즘.
- **스탯 5종(리테마):**
  | 스탯 | 지배 영역 |
  |---|---|
  | **근력(STR)** | 창 물리 데미지·경직·중창 요구치 |
  | **신성(HOL)** | 신성기 위력·최대 신성력·창 강화 효율 |
  | **민첩(AGI)** | 이동/공격 속도·대시 쿨·크리 |
  | **체력(VIT)** | 최대 HP·방어·슈퍼아머 |
  | **심지(WIL)** | 신성력 회복·상태저항·피격 시 집중 유지 |
- **오르는 법:** 수련(신전 미니게임)·**퀘스트 보상 수련치**([소]/[중]/[대]/[특대])·위계 시험·행동 성장(일일 상한)·레벨업 자동·희귀 영약.
- **문자 티어 돌파 = 위계 시험**(승급 연출: 화면 정지→랭크 각인→발광). 상위(S+)는 특수 조건.
- **종합 위계(Holy Order Rank):** 5스탯+진행 종합 = 성창사 위계. NPC 반응·일부 게이트·엔드 자격.
- **숫자 비노출 원칙:** 성장 스탯은 랭크·눈금(◆◆◆◇◇)만. 단 **HP/신성력 바·데미지 넘버는 유지**(타격감 필수).

## 7. 수업 · 스승 시스템 (유지) — 게임의 배움 축

신전의 사범에게 **창술·신성기를 배워** 습득. "배워서 강해진다"를 실제 루프로.

### 7.1 스킬 제로 근처 스타트
- 강림 초기엔 **기본 3타 창술만** 보유. 신성기·이동기는 **수업 + 성물**로 하나씩 획득.
- 미습득 스킬은 트리에 **자물쇠**로 표시 → 다음 목표 시각화.

### 7.2 스승 티어
| 티어 | 스승(예) | 해금 조건 | 가르치는 성향 |
|---|---|---|---|
| **초급** | 수련장 사범 | 강림 즉시 | 창술 기본기·기초 신성기(저비용) |
| **중급** | 사제 | 첫 성물 회수 + 위계 C | 창 강화·정화·관통기(중비용) |
| **고급** | 대신관 | 성물 다수 + 위계 B + 지역 보스 격파 | 광역 신성기·심판(고비용·긴 쿨) |
| **대사제** | (엔드) | 성물 대부분 + 특수 퀘스트 | 궁극 신성기 — 전투를 바꾸는 한 방 |

- 각 스승 = 수업 체인(2~4개). 수업 = **플레이 가능한 실습**(지정 표적·필드 실습·평가전).
- 수업 보상: 스킬트리 노드 해금 + 경험치 + 수련치.

## 8. 전투 시스템 (창 + 신성력) — 타격감 ★

기존 Shadow Dagger juice 엔진 철학 계승·확장. **창의 리치와 간격**이 정체성.

### 8.1 기본 조작
| 입력 | 동작 |
|---|---|
| ← → | 이동 |
| Space/↑ | 점프 (성물로 이단·기타 확장) |
| ↓+점프 | 하강 점프 |
| Shift | 대시/회피 (짧은 무적) |
| 공격키 | **창술 3타 콤보** (찌르기→올려베기→회전 쓸기) |
| 공격 홀드 | **차지 찌르기** (관통·경직) |
| 공중+아래+공격 | **내려찍기** (착지 충격파) |
| 신성기 키 | 신성기 슬롯(빛의 창·정화·보호막·강타 등) |
| 신성 강화 키 | **창 강화 모드** (신성력 소모, 일정시간 리치·데미지·효과↑) |
| E | 상호작용 · 강림 사당 |

> 게임패드 지원 목표(근접 창 액션은 패드 손맛이 큼).

### 8.2 창술 3타 콤보 (근접 핵심)
- **찌르기(1타):** 긴 리치, 빠른 견제.
- **올려베기(2타):** 적 띄움(공중 콤보 연결).
- **회전 쓸기(3타):** 넓은 광역·강한 넉백. (트리로 4·5타 파생 확장 §5.2)
- 리치 무기라 **간격 관리**가 핵심 재미. 찌르기 포킹 ↔ 파고들어 쓸기.

### 8.3 신성력 & 신성기
- **신성력 게이지:** 평타 적중·회피·피격으로 충전. 신성기·창 강화에 소모.
- **창 강화 모드:** 신성력 소모 → 창이 빛으로 감싸여 **리치·데미지·특수효과 상승**(핵심 "한 방" 자원).
- **신성기(예):**
  | 신성기 | 유형 | 효과 |
  |---|---|---|
  | 신성 강타 | 강화 일격 | 창에 빛 폭발, 광역+경직 |
  | 빛의 창 투척 | 원거리 관통 | 원거리 딜·**원격 스위치/봉인 타격**(게이트) |
  | 성역 보호막 | 방어 | 짧은 무적/피해감소 배리어 |
  | 정화(淨化) | 회복/해제 | 자힐 + **어둠 장막·독안개 해제(메트로바니아 게이트)** |
  | 심판의 빛 | 궁극 | 광역 대폭발 광선 (강한 히트스톱·줌·셰이크) |

### 8.4 타격감(Juice) — 창 액션에 이식
히트스톱 · trauma 화면흔들림 · 넉백 · 히트플래시 · 파티클(창격 궤적·빛 스파크) · 데미지 넘버 · 콤보 카운터 · 크리 줌펀치 · 처치 연출. **수치는 Unity 슬라이스 명세서(§8) 참조.**

### 8.5 몬스터 & 보스
- 타락한 짐승·그림자·역병 걸린 것 등 인간계 위협. 명확한 windup(공정한 회피 학습).
- 지역 수문장(미니보스)·타락 근원(지역 보스) 페이즈제. 성물 근처엔 강한 수호자.

## 9. 탐험 & 메트로바니아 구조 ★

### 9.1 능력 게이팅 (성물 = 열쇠)
성물로 얻는 능력이 지형 게이트를 연다:
| 게이트(막힘) | 여는 능력(성물) |
|---|---|
| 높은 절벽 | **창대 도약**(pole vault) |
| 어둠 장막·독안개 | **정화의 빛** |
| 원거리 봉인/스위치 | **빛의 창 투척** |
| 넓은 낭떠러지·위험지대 | **빛의 대시**(무적 질주) |
| 더 높은 곳 | **이단 강림**(더블 점프/라이트 스텝) |
| 갈라진 바닥·하층 | **내려찍기 강타**(바닥 파괴) |
| 특정 벽 | **창 꽂기 벽타기** |

### 9.2 흐름
강림 → 첫 지역(능력 최소) → 벽에 막힘 → 성물 회수로 능력 획득 → 새 길 개방 + **이전 지역 재방문(백트래킹)으로 숨은 길 열림** → 반복. 강림 사당으로 세이브·귀환·이동.

---

## 10. 성물(聖物) — 핵심 진행 축

되찾을 때마다 **능력 해금 + 지역 개방 + 스토리 전진**. 신전 안치소에 전시(진행 실감). 예시:

| 성물 | 부여 능력 | 성격 |
|---|---|---|
| 도약의 창머리 | 창대 도약 | 초반 이동기 |
| 빛의 편린 | 빛의 대시 | 기동·회피 |
| 정화의 성배 | 정화의 빛 | 게이트 해제·힐 |
| 승천의 깃 | 이단 강림 | 수직 탐험 |
| 관통의 성창날 | 빛의 창 투척 | 원거리·스위치 |
| 심연의 추 | 내려찍기 강타 | 하층 개방 |
| (엔드) 여명의 성창 | 심판의 빛 각성 | 최종 |

> 모든 성물 회수 = 스토리 클라이맥스(타락 근원과의 결전). 일부는 선택적 히든 성물(전투 강화·각인).

---

## 11. 인간계 지역 스케치 (연결 지도)

> 상세 아틀라스는 후속. 여기선 뼈대만.

1. **강림지 — 무너진 관문 / 첫 마을 어귀** (튜토리얼 구간, 능력 최소)
2. **첫 마을(○○촌)** — 서브 허브(주민·소상점·의뢰)
3. **병든 들판 / 안개 든 숲** — 타락 확산, 정화 도입
4. **폐광 · 지하 수로** — 내려찍기/빛의 창 게이트
5. **강가 마을 · 벼림 마을** — 제작·강화 서비스
6. **버려진 성채 / 신성 유적** — 성물 수호자(보스)
7. **타락의 진원지** — 최종 지역

각 지역 = 여러 방 + 강림 사당 + 지역 수문장/보스 + 성물 1개 + 숨은 길.

## 17. 개발 로드맵 & 스코프

### 17.1 수직 슬라이스 (최우선) — 필 증명
- 창 3타 콤보 + 창 강화 + 신성기 1~2개.
- 이동기: 대시 + 이단 강림 + (시그니처) **창대 도약**.
- 인간계 한 구간(예: 강림지 어귀) + 몹 2종 + 성물 1개(능력 해금 시연).
- **목표: "창 액션이 손맛 있고, 성물로 힘이 열리는 게 재밌다"를 5~10분에 증명.**
- 상세: [`../unity-vertical-slice-spec.md`](../unity-vertical-slice-spec.md)

### 17.2 MVP
- 인간계 3~4개 지역 연결 + 성물 3~4개(능력 3~4) + 스승 초·중급 + 지역 보스 1~2 + 강림/세이브.

### 17.3 정식(1.0)
- 전 지역 + 전 성물 + 대사제/궁극기 + 최종 보스·엔딩 + 각인·경제·도감.

### 17.4 마일스톤 순서
1. **손맛 프로토(창+신성력+이동기)** ← 여기부터
2. 성물=능력=게이트 루프
3. 지역 연결(메트로바니아 지도)
4. 수업·스승·성장(랭크·트리)
5. 보스·스토리
6. 폴리시(아트·사운드·밸런스)
