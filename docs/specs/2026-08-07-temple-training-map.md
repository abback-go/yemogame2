# 성창 — 잊힌 성물 · 「신전 수련장」 통합 맵 설계 (전역 조립본)

> 조립 규약: 각 층을 아래→위로 쌓아 **전역 = (로컬x, 로컬y + Y오프셋)** 로 변환. 모든 층은 좌측 원점 정렬(x오프셋=0). 층 내부 물리·도달성은 각 층 검증본 그대로 보존되며, 조립은 좌표 변환과 층간 연결 정합만 다룬다.
> 층간 전이는 전부 **문/포탈(로컬 좌표 리셋)** — 따라서 출구·진입의 x가 달라도 무모순(포탈 연결). **유일한 물리적 연속 전이는 6→7층**(첨탑 상단 한방향 통과판, x=5.0 정렬).

## (C) 층별 요약 (뽐내는 것 · 핵심 동선)

1. **입구 대광장** — 달리기 최고속·가변점프·대시·기본 3타 콤보. 동선: 스폰(2,1)→평지 질주하며 허수아비 3기 콤보→P1/P2/P3 계단→포탈. *창 꽂기 의도적 미등장.*
2. **부서진 회랑** — 동일 2.5u 갭 반복 대시점프 + 기둥머리 위 공중 허수아비 에어콤보. 동선: 회복바닥→A~D 기둥머리 사슬(놓쳐도 무마찰 착지)→출구 렛지.
3. **첫 벽등반 샤프트 ★시그니처 첫 공개★** — 마주보는 벽이 없어 벽점프 불가 → **창을 벽에 박아 발판+창대 도약**으로만 등반. 필수 갭 3.6u·4.4u가 이단강림(2.9u) 초과라 창 꽂기 강제. 히든 빛결정은 우벽 가로지르기 창꽂기(투척 4.5u<5u)로만 도달.
4. **큰 균열 갭** — 대시점프→이단강림→**수평형 창 꽂기+창대 도약** 3비트 체이닝 종합 갭. 시작점→먼 기둥 8.9u>사거리라 초반 스킵 차단.
5. **수련 아레나** — 대시 i-frame 회피·창강화 게이지 루프·**전투용 창 꽂기 발판 위 에어콤보**·반격표적 2종. D-A2(y4.3 로컬)는 지상 이단강림(3.9)·인접 고지대 이격+기둥벽 차단으로 창발판 없인 불가(시그니처 강제). 동선 상승 후 성물 기둥 창대 도약으로 출구.
6. **첨탑 상승** — 낙하존 위에서 **벽점프→창꽂기→창대도약→이단강림** 4대 이동기 연쇄. 전 수직 전환이 x-스팬 밖 자유 모서리 아치 착지 또는 한방향 통과로 정합. 사당4(중단) 이후는 무체크포인트 연속 클라이맥스.
7. **정상 성종** — 좁음→넓음 반전의 승리의 랩. 성종 타격=클리어(정답: 스텝→플린스→단일점프+↑공격, 전부 ≤1.6u). 창 꽂기는 대들보 낙하 대시공격의 화려한 선택 마무리로만 개방.

**없음(의도적).** 창 꽂기 시그니처는 3층 "첫 벽등반 샤프트"에서 최초 공개. 2층은 순수 이동(대시점프)·공중 전투(에어콤보) 검증에 집중한다.

## 7) 허수아비 / 반격표적 배치

|---|---|---|---|
| 허수아비 G | (3.5, 1.0) | 지상 정지 | 진입 직후 3타 콤보 워밍업(1층 복습), 낙하 회복 지점 인지 |
| 허수아비 AS1 | (10.0, 4.2) | 공중(기둥 B 머리 위) | 기본 에어콤보 첫 실전 — 머리에서 단일점프 정점(≈4.4) 타격 |
| 허수아비 AS2 | (14.5, 4.9) | 공중(기둥 C 머리 위) | 윗공격(↑) + 이단 강림 연계 — 단일점프 정점(≈5.0) 또는 더블점프로 여유 타격 |

## 8) 강림 사당 · 목표물 위치
- **강림 사당 없음.** (사당1 = 1층, 사당2 = 5층 규약 준수.) 2층은 회복 회랑 바닥이 무마찰 세이프티를 대신하므로 사당 왕복 필요가 없음.
- **목표물 없음**(정상 성종은 7층). 본 층 목표 = 상단 출구 렛지 도달.

## 9) "정답 이동기" 동선 (도달성 수치 근거)
1. **(2.0,1.0) 스폰 → 우측 달리기**, 허수아비 G(3.5,1.0)에 3타 콤보 워밍업.
2. **회복 바닥 → 기둥 A 머리(표면 2.2)**: 수평 ~2.5u·상승 1.2u. 달리기+대시점프(대시 수평 2~3u, 점프 1.6u)로 안착. ✓
3. **A머리(우측단 6.5) → B머리(좌측단 9)**: 갭 **2.5u**, 상승 0.6u → 대시점프 1회. ✓  B머리 부근에서 **단일점프(정점 2.8→4.4)로 AS1(4.2) 에어콤보**.
4. **B머리(11) → C머리(13.5)**: 갭 2.5u, 상승 0.6u → 대시점프. ✓  **점프+윗공격(↑) 또는 이단 강림으로 AS2(14.5,4.9) 타격**(3.4→단일 정점 5.0, 여유는 더블점프 2.9).
5. **C머리(15.5) → D머리(18)**: 갭 2.5u, 상승 0.6u → 대시점프. ✓  **D머리(4.0)에서 단일점프 정점 5.6 / 이단 강림으로 AS3(19,5.5) 정점 타격**.
6. **D머리(20) → 출구 렛지(좌측단 22.5)**: 갭 2.5u, 상승 0.8u → 대시점프(점프 1.6u가 0.8 상승 흡수, 대시가 2.5 수평 담당). ✓
7. 렛지 위를 달려 **출구 문 (26.5,4.8)** → 3층 진입.
- **실패 시**: 어느 갭이든 놓치면 회복 바닥(y=1)으로 착지 → 바로 아래 기둥 사슬(A→B→…)을 다시 밟아 재등반. 사당 리스폰·페널티 없음.
- 모든 갭이 **동일 2.5u 규격**이라 대시점프 타이밍을 반복 학습 → "빠르고 공격적" 리듬이 몸에 붙음.

## 10) 신전 룩 연출 노트
- **기둥**: 절반쯤 부러진 대리석 기둥, 금세공 홈이 파인 기둥머리(코린트식 조각)가 한방향 발판. 몸통엔 세로 균열과 담쟁이 대신 **은청색 이끼-빛 결정** 실선이 흐름 → "성물의 잔광".
- **구름 하늘 배경**: 기둥과 기둥 사이로 발밑까지 트인 구름 바다가 보이도록(실제 낙하존은 없지만) 시각적으로 "허공을 건넌다"는 긴장감 부여. 회복 바닥은 반투명 구름에 반쯤 잠긴 낮은 회랑 잔해로 표현.
- **빛결정 광원**: 각 기둥머리 아래 모서리에 은청색 빛결정을 박아 **발판 착지 지점을 광원으로 유도**(공정성 — 다음 발판이 어디인지 빛으로 읽힘).
- **성스러운 광원**: 화면 우상단(출구 방향)에서 비스듬히 내리쬐는 성광(god ray)이 기둥머리 상단을 금빛으로 물들여, 플레이어 시선을 자연스럽게 오른쪽·위로 끌어올림.
- **에어콤보 연출**: 공중 허수아비 피격 시 빛결정 파편이 튀며 신성력 게이지 반짝임 → 3층 창 강화 루프로의 예고.

# 3층 — 첫 벽등반 샤프트 (First Ascent Shaft)

## 1) 한 줄 컨셉
벽점프만으론 절대 못 오르는 좁고 높은 구름 우물 안에서, **창을 벽에 꽂아 임시 발판을 만들고 그 위에서 창대 도약으로 튀어올라** 한 칸씩 정복하는 "시그니처 창꽂기 등반 샤프트." 아래는 통째로 낙하존(무마찰 재도전).

## 2) 이 층이 뽐내는 메커니즘
- **★창 꽂기 발판(시그니처) 첫 등장★**: 마주보는 벽이 없어 벽점프 지그재그가 원천 봉쇄된 구간 → 오직 창을 벽에 박아 발판 삼아야 오른다.
- **창꽂기 → 딛기 → 창대 도약(3.4u) → 회수 → 재투척**의 등반 루프(한 번에 창 하나만) 각인.
- **벽슬라이드/벽점프 워밍업**: 바닥 좁은 채널(2.0u)에서 지그재그로 몸풀기 → 곧 "벽점프로 못 넘는 높이"에 부딪혀 창의 필요성을 체감.
- **히든 '빛 결정' 갈래**: 주경로(좌벽)와 반대편 우벽으로 **가로질러 창을 박아** 도달 — 창꽂기 응용 마스터 보상.
- **낙하존 무마찰 규약 재확인**: 어느 높이에서 떨어져도 바닥 안전지대(y=1.0)로 즉시 복귀, 페널티 없음.

## 3) 크기
**7u(w) × 16u(h)** — 좁고 높은 수직 우물. 좁은 폭 덕분에 반대 벽이 창 사거리(5u) 안에 들어와 "가로지르기 창꽂기(히든)"가 성립.

## 4) 진입(하단)·출구(상단) 좌표

- **출구(상단)**: **(6.0, 14.5)** — 출구 렛지 우측 끝, 우측 경계벽 문 개구부. 여기서 4층 "큰 균열 갭" 하단 진입으로 연결.

## 6) 창 꽂기 발판 지점 (핵심 — 어디에 꽂아 어떻게 오르나)
> 규칙: 창은 반드시 벽 표면(spear-surface)에 박혀야 발판이 됨(공중 부양판 없음). 한 번에 하나만 → 딛고 올라선 뒤 상단 렛지에 안착하고 **회수(돌아오며 타격)** 후 재투척.

- **창꽂기 ① (좌벽, 표면 y≈6.7)**: R1(x≈2.5~3.5, 표면 5.2)에서 좌벽(면 x=0.5)까지 약 2.0u 던져 y≈6.5에 박음 → 발판 표면 6.7, x[0.5, 1.3]. R1에서 **단일점프(1.6u)**로 창 위(≈0.9, 6.7)에 올라섬.
- **창대 도약 → R2**: 박힌 창①을 딛고 **창대 도약(정점 3.4u)** 또는 이단강림 → 좌벽 렛지 R2(표면 8.8, +2.1u)에 안착. 이후 창① **회수**.
- **창꽂기 ② (좌벽, 표면 y≈10.3)**: R2(x≤2.0)에서 좌벽에 y≈10.1로 박음(던지기 ≈2u) → 발판 표면 10.3, x[0.5, 1.3]. R2에서 단일점프(1.5u)로 올라섬.
- **★창대 도약 강제 구간 → R3★**: 박힌 창②(10.3)에서 R3(표면 13.2)까지 **+2.9u** — 단일·이단(2.9u 경계)로는 불가, **창대 도약(3.4u)만이 확실히 넘김**. 이 갭이 창대 도약 손맛의 하이라이트. 안착 후 창② 회수.
- **창꽂기 ③ (우벽, 히든)**: 아래 7)·9) 참조 — 우벽(면 x=6.5)에 가로질러 박아 반대편 알코브로 건너가는 응용.

## 7) 허수아비/반격표적 배치
- **허수아비 A (벽걸이·대형, 창꽂기 연습용)**: 위치 x[6.0, 6.5], y[5.8, 7.3] (우벽 부착). 목적 — **"창은 적 표면에도 박혀 발판이 된다"** 확장 검증. 등반 중 선택적으로 창을 A에 꽂아 발판화→회수 관통 타격 연습(주경로엔 불필요, 손맛 실험용).
- **허수아비 B (공중, 히든 갈래 가드)**: 위치 (5.7, 10.6) 부근 부양. 목적 — 우벽으로 가로지르는 대시점프 동선 중 **대시공격/에어콤보로 낚아채기** 검증. 처치 여부와 무관하게 통과 가능(공정성).
- **반격표적(예고 공격/투사체)**: **이 층엔 없음** — 반격 표적은 5층 수련 아레나 전용(난이도 곡선 보존). 3층은 순수 이동기(창꽂기)에 집중.

## 8) 강림 사당·목표물 위치
- **정식 강림 사당: 없음** (사당은 1층·5층). 대신 **임시 강림 지점(무마찰 체크포인트)**을 진입 렛지 **(1.5, 1.0)**에 배치 — 낙하 시 바닥 안전지대(y=1.0)로 즉시 복귀, 페널티/왕복 없음.
- **목표물(히든 빛 결정)**: **(6.0, 9.9)** — 우벽 알코브 렛지(표면 9.4) 위에 부양. 창꽂기 ③ 응용으로만 도달(수집 요소).

## 9) "정답 이동기" 동선 (도달성 수치 근거)
1. **(1.5,1.0) → R1(5.2)**: 좌경계벽 면(0.5)과 워밍업 기둥 면(2.5) 사이 **2.0u 채널**에서 벽슬라이드→벽점프 지그재그(각 ≈1.6u)로 약 4.2u 상승, 기둥머리에 멘틀. *→ 벽점프 워밍업.*
2. **R1(5.2) → 창① → R2(8.8)**: R1→R2 직선 거리 **3.6u > 이단강림 2.9u**라 순수 점프 불가. 좌벽에 창① 박아(표면 6.7) 단일점프(1.5u)로 딛고, **창대 도약(3.4u)/이단강림으로 R2(+2.1u)** 안착. 창① 회수. *→ 창꽂기 필연성 각인.*
3. **(히든) R2(8.8) → 창③(우벽 9.2) → 알코브(9.4) → 빛 결정(6.0,9.9)**: R2 우끝(x=2.0)에서 우벽 면(6.5)까지 **4.5u < 창 사거리 5u** → 창③ 박음. **대시(수평 2~3u)+대시점프+이단강림**으로 4.5u 가로질러 창③(6.1,9.2)에 착지 → 알코브 렛지(9.4)로 0.5u 홉 → 빛 결정 획득. 복귀는 낙하(무마찰)로 안전지대 → 재등반. *→ 창꽂기 응용 보상.*
4. **R2(8.8) → 창② → R3(13.2)**: R2→R3 **4.4u > 2.9u** 불가. 좌벽 창②(표면 10.3) 단일점프(1.5u)로 딛고, **+2.9u는 창대 도약(3.4u)만 확실** → R3 안착. 창② 회수. *→ 창대 도약 하이라이트.*
5. **R3(13.2) → 출구 렛지(14.5) → 출구(6.0,14.5)**: 수평 약 2.3u·수직 1.3u → **대시점프(대시 2~3u + 점프 1.6u)** 한 방으로 마무리, 우벽 문으로 4층 진입.

> 검증: 필수 갭 3.6u·4.4u는 모두 이동기 최대치(이단 2.9)를 초과 → 창꽂기 없이는 클리어 불가(showcase 강제). 각 창 위에서의 상승분(2.1u·2.9u)은 창대 도약 3.4u 이내 → 확실히 클리어 가능. 모든 투척 거리 ≤4.5u ≤ 사거리 5u.

## 10) 신전 룩 연출 노트
- **구조**: 무너진 대리석 우물 — 좌우 경계벽은 금세공 문양이 흐르는 대리석 기둥면, 표면에 **은청색 빛결정 광맥**이 얇게 박혀 창을 꽂을 지점을 은은히 하이라이트(플레이어 유도).
- **박힌 창 연출**: 창이 벽에 박히는 순간 접점에서 **신성력 빛(빛결정 광원)**이 파문처럼 번지고, 발판 활성 동안 창대에 은청색 룬 링이 회전 → "여기 딛어라" 시그널. 회수 시 빛 잔상 트레일.
- **낙하존/깊이감**: 중앙 우물 아래로 구름이 소용돌이치며 흘러 바닥이 아득해 보이게(실제 안전지대 y=1.0은 얇은 구름 위 대리석 렛지). 떨어질 때 구름을 가르는 파티클로 무마찰 복귀가 "벌"이 아닌 "연출"로 읽히게.
- **광원**: 상단 출구(성종 방향)에서 내려오는 성스러운 역광 샤프트 → 위로 오를수록 밝아지는 광량 그라데이션(상승 동기 시각화). R1·R2·R3 렛지에 작은 금촛대형 광점.
- **히든 알코브**: 우벽 알코브는 유독 짙은 은청색 빛결정 군락 + 부유하는 빛 입자 → 탐험가에게 "특별한 곳" 신호. 빛 결정 획득 시 잠깐의 성가풍 광휘 플래시.
- **허수아비**: 대리석·금박 마감의 수련용 목표 인형(천상 신전 톤 유지), 피격 시 성스러운 빛 스파크로 타격감 강조.

# 4층 — 큰 균열 갭 (The Great Fissure)

## 1) 한 줄 컨셉
발밑이 통째로 무너져 내린 신전의 **거대한 수평 균열**을, 「달리기 대시점프 → 이단강림 → 먼 기둥에 창 꽂기 → 창대 도약」을 한 호흡으로 엮어 건너는 **종합 도약 시험대**. 세 개의 발판이 점점 멀고 높아지며 각 이동기를 순서대로 강제하고, 발밑 전부는 낙하존(무마찰 재도전)이다.

## 2) 이 층이 뽐내는 메커니즘
- **이동기 3종 체이닝**: ①대시점프(수평 속도) → ②이단강림(높이) → ③창 꽂기 발판 + 창대 도약(먼 거리+고도)을 **한 번의 크로싱 안에서 순차로** 요구.
- **수평형 창 꽂기**: 3층이 "수직 등반용 창꽂기"였다면, 4층은 **허공 건너편 먼 기둥의 벽면에 창을 던져 박아 디딤 발판을 만드는 "수평 도약용 창꽂기"**로 응용을 확장.
- **판단 압박**: 마지막 기둥은 어떤 점프로도 직접 못 닿음(사거리 밖) → "지금 창을 어디에, 어느 높이에 박을지"를 공중에서 판단하게 함.
- **공중 콤보 루프 유지**: 크로싱 중간의 공중 허수아비로 에어콤보/윗공격, 착지 지점에서 대시공격을 섞어 "이동=전투"의 실크송식 리듬 유지.
- **낙하존 무마찰**: 어느 발판에서 떨어져도 페널티 없이 진입 렛지로 즉시 복귀.

## 3) 크기
**16u(w) × 9u(h)** — 넓은 수평 균열이 주인공인 가로로 긴 챔버. 진입(좌하 y=1.5) → 출구(우상 y=6.5)로 약 5u 상승하며 서쪽→동쪽으로 건넌다.

## 4) 진입(하단)·출구(상단) 좌표

- **출구(상단)**: **(14.5, 6.5)** — 우측 출구 렛지, 우측 경계벽 상단 문 개구부. 여기서 5층 "수련 아레나" 하단 진입으로 연결.

## 6) 창 꽂기 발판 지점 — 어디에, 어떻게
- **투척 지점**: P2(좁은 렛지, x≈9.6)에 올라선 상태에서, **먼 기둥의 좌측면(x=11.5)**을 조준. P2에서 기둥 벽면까지 수평 ≈1.9u → 창 사거리 5u 안에 여유 있게 든다.
- **박는 높이**: 벽면 **y≈4.5** 지점에 수평으로 박는다. 창대가 좌측으로 약 0.6u 돌출 → **윗면이 디딤 발판(표면 y≈4.6, x[10.9,11.5])**이 됨. 너무 낮게 박으면(예 y<4.0) 이후 창대 도약 정점이 출구 렛지(6.5)에 못 닿으니, "적당히 높게 박기"가 판단 포인트.
- **등정 루프**: P2 → 창을 기둥에 박음 → 짧은 대시점프로 창 발판(y4.6)에 착지 → **창대 도약(정점 3.4u → y≈8.0)**으로 위·앞으로 튀어오름 → 상승 중 창 회수(돌아오며 타격, 다음 층 대비 창 복구) → 출구 렛지(y6.5)에 착지.
- **한 번에 창 하나** 규약 준수: 창은 도약 후 회수되므로 출구 도달 시 손에 창이 돌아와 있다.

## 9) "정답 이동기" 동선 (도달성 수치 근거)
1. **진입 (1.5,1.5)** — 시작 렛지에서 오른쪽으로 달려 가속.
2. **비트①: 대시점프** — 시작 렛지 끝(x2.6, y1.5)에서 **대시(수평 2~3u)+가변점프**로 P1 기둥머리(좌끝 x5.0, y1.8)로. 갭 **2.4u**, 상승 0.3u → 대시 단독으로도 거의 닿는 거리, 여유 착지. 착지 직후 허수아비 A에 대시공격.
3. **비트②: 이단강림** — P1 끝(x6.2, y1.8)에서 P2(좌끝 x8.6, **y3.6**)로. 갭 2.4u, **상승 1.8u**. 단일점프(1.6u)로는 못 오르므로 **대시+이단강림(누적 2.9u)** 강제. 도중 공중 허수아비 B로 에어콤보. (더블점프 실패 시 → B에 창 박아 발판 삼는 응용 안전망 존재.)
4. **비트③: 창 꽂기 → 창대 도약** — P2(x9.6, y3.6)에서 먼 기둥 좌면(x11.5)까지 1.9u(<5u) → **창을 y≈4.5에 박음**. 짧은 대시점프로 창 발판(x11.2, y4.6, 갭 1.3u·상승 1.0u)에 착지 → **창대 도약(3.4u → 정점 y≈8.0)**을 앞으로 뻗어 출구 렛지(좌끝 x13.5, y6.5)로. 수평 2.3u·상승 1.9u는 정점 3.4u 도약의 전진 에어컨트롤(+필요 시 대시)로 커버. 상승 중 창 회수(타격 겸 창 복구).
5. **출구 (14.5,6.5)** — 우상단 문 → 5층으로.
   - *직접 스킵 차단 검증*: 시작 렛지(x2.6)에서 먼 기둥 벽(x11.5)까지 8.9u > 사거리 5u → 초반 창꽂기 스킵 불가, 3비트 크로싱이 유일 정답 경로.

## 10) 신전 룩 연출 노트
- **대균열**: 화면 하단을 가로지르는 갈라진 대리석 바닥과 무너진 금세공 아치. 균열 아래로는 **구름 하늘이 무한히 내려다보이는 심연** — 낙하존을 시각적으로 "끝없는 하강"으로 연출(실제론 무마찰 리스폰).
- **부서진 기둥들(P1·먼 기둥)**: 반쯤 붕괴된 대리석 기둥이 심연에서 솟아오른 실루엣. 기둥머리는 금테 두른 원기둥 단면으로 "발판임"을 명확히.
- **창 발판**: 벽에 박힌 창이 **은청색 빛결정 광채**를 흘려 디딜 수 있는 표면임을 아우라로 표시(공정성: 발판 인지성).
- **광원**: 우상단 출구 문에서 **성스러운 빛기둥(god ray)**이 균열을 가로질러 쏟아져, 서→동 진행 방향과 상승 목표를 자연 유도.
- **히든 빛결정**: (12.6,7.5) 공중에 떠 은청색으로 맥동 — 정점 도약 시에만 스치는 "손 뻗으면 닿을 듯한" 높이감으로 유혹.
- **파티클**: 대시·창대 도약 순간 발밑에서 금가루·구름 흩날림으로 "빠르고 곡예적인" 템포 강조.

# 5층 — 수련 아레나 (The Trial Arena) — 개정본

> **개정 반영 요약(검토자 지적 대응)**
> - [치명적 좌표 모순 해소] 전투용 창꽂기 발판을 **낮은 중앙 단(y[0,2.4])의 우측면**이 아니라, 별도로 세운 **「수련 기둥」(부서진 부유 성구 기둥, spear-surface y[2.0,5.0])** 좌측면에 박도록 전면 교체. 이제 지형표의 spear-surface 범위와 본문(6번·9번)의 창꽂기 y좌표가 **완전히 일치**한다.
> - [자기정합성 확보] 창발판 **y3.2 → 단일점프 apex 4.8 → D-A2(y4.3)** 로 "작은 발판 딛고 에어콤보" 손맛 비트를 수치로 성립. **지상 이단강림(3.9)은 D-A2(4.3)에 못 닿고, 가장 가까운 고지대(중앙 단 2.4)와도 3.2u 이격 + 수련 기둥이 우측 동선을 벽으로 차단** → "창꽂기 발판 없이는 D-A2 불가"를 기하로 강제하여 시그니처 필요성을 살림.
> - [출구 동선] 검토자 승인대로 **성물 기둥 창대 도약 동선은 그대로 유지**(좌표 정합).
> - 바닥 연속성 보전을 위해 수련 기둥은 **하부 y[1.0,2.0] 통행 개구(1.0u 클리어런스)**를 둔 부유 기둥으로 설계(무너진 신전 정서와 정합).

## 1) 한 줄 컨셉
넓게 펼쳐진 신전 수련장에서 **「대시 i-frame 회피 → 창강화 게이지 빌드 → 창꽂기 발판 위 에어콤보 → 창 회수 타격」의 전투 풀 루프**를, 지상·공중·벽에 흩어진 허수아비와 두 종의 느린 예고형 반격 표적을 상대로 **한 호흡의 실크송식 리듬으로** 완성하는 수평형 종합 전투 시험장. 앞선 층이 "이동"을 가르쳤다면 5층은 "이동=전투"를 증명한다.

## 2) 이 층이 뽐내는 메커니즘
- **전투용 창꽂기 콤보(시그니처)**: 3·4층의 창꽂기가 "등반/도약"이었다면, 5층은 **공중 허수아비 옆의 「수련 기둥」 좌측면에 창을 박아 즉석 발판을 만들고 → 딛고 올라 에어콤보 → 창을 회수하며 관통 타격**하는 "전투 도구로서의 창꽂기"를 뽐낸다. **이 발판 없이는 D-A2에 물리적으로 닿지 않도록 수치·기하로 강제**한다.
- **대시 i-frame 회피 시험**: 느린 예고 근접 표적(CT1)·투사체 표적(CT2)이 명확한 윈드업을 보인 뒤 공격 → 대시 무적 프레임으로 통과·반격하는 공정한 회피 루프.

## 10) 신전 룩 연출 노트
- **공간감**: 하늘로 열린 원형 수련장. 사방에 온전한/부서진 **대리석 기둥**이 도열하고, 부서진 기둥머리(P-air1~2)가 공중 발판이 되어 "무너진 신전에서 수련한다"는 정서를 만든다.
- **수련 기둥(x11.6, 전투 창꽂기)**: **신성력으로 공중에 떠 있는 부서진 성구 기둥** — 밑동이 끊겨(하부 통행 개구) 지면과 분리된 채 은청색으로 발광. 성물 기둥과 같은 계열의 **금세공 문양**으로 "창을 박는 표면"임을 색으로 예고(어포던스). 창이 박히면 박힌 지점에서 성스러운 광원이 퍼진다.
- **성물 기둥(x14.5, 출구용)**: 다른 기둥과 달리 **금세공 문양이 감긴 은청색 발광 기둥** — 최종 상승 관문임을 색으로 강조. 창이 박히면 광원이 퍼져 창대 도약 지점을 명시.
- **빛결정**: 아레나 상단 가장자리·기둥 사이에 **은청색 빛결정**이 은은히 부유해 상승 방향(우상 출구)으로 시선을 유도.
- **강림 사당2(2.5,1.0)**: 바닥에 새겨진 금빛 강림 문양 + 위로 솟는 부드러운 빛기둥 — 좌측 안전지대임을 명시.
- **반격 표적**: 허수아비와 달리 **붉은/황금 예고 오라**로 윈드업을 광원 연출 → 공정한 회피 신호(품질기준 ④).
- **배경**: 흐르는 **구름 하늘**이 기둥 틈으로 보이며, 광원은 상단에서 비스듬히 내리는 성스러운 역광 — 도트 실루엣과 창의 궤적이 또렷이 읽히도록 대비 확보.

# 6층 — 첨탑 상승 (The Spire Ascent) — 개정본 v2

> **개정 요지**: 검토자 지적을 전면 반영. (1) 머리 위 solid 판에 수직 안착 불가 문제를 4개 전환 전부에서 해소 — 도약 나브/창발판을 착지단 x-스팬 **밖**으로 오프셋해 "자유 모서리 아치 착지"로 통일(정상 동작하던 B2→L2 원리를 전 구간 복제), 마지막 L5→XE는 '상단 개구' 서술에 맞춰 **한방향(아래→위 통과) 판**으로 명시. (2) 모든 수직 전환에 **착지 접근 방향(좌/우/통과)** 표기 및 '판 밑면 회피 + x-스팬 밖 접근' 기준 재검증. (3) 히든 분기 복귀를 '창발판 미회수 상태 유지 → HC→발판→L5 → 마지막에 회수'로 순서·Δ수치 명시. (4) 후반 난이도 '정점' 체감 보강(사당4 이후 전 구간을 무체크포인트 연속 클라이맥스로 재프레이밍).

## 1) 한 줄 컨셉
구름을 뚫고 하늘 신전의 성종으로 향하는 좁고 높은 첨탑 내부를, **벽점프 → 창꽂기 발판 → 창대 도약 → 이단강림을 한 호흡으로 엮어 올라가는** 수직형 마스터리 상승 구간. 발밑은 전 구간이 낙하존이라, "네 가지 이동기를 정확히 순서대로 쓰지 못하면 아래로 떨어진다"는 실크송식 긴장감 위에서 앞선 다섯 층의 모든 이동 문법을 하나로 증명한다.

## 2) 이 층이 뽐내는 메커니즘
- **4대 이동기 통합 상승**: 각 전환이 서로 다른 이동기를 "정답"으로 요구하고, 상단으로 갈수록 연쇄가 길어진다.
  - B1: **벽점프** 슈트(재도입·워밍업)
  - B2: **창꽂기 발판(시그니처)** — 갭 건너 벽면에 창을 박아 딛고 오름
  - B3: **창대 도약** — 도약 나브를 딛고 정점 3.4u로 고지 확보(자유 모서리 아치 착지)
  - B4~B5: **창꽂기 + 이단강림 + 창대 도약** 연쇄 (종합 클라이맥스)
- **낙하존 스테이크**: 첨탑 내부는 바닥이 없다. 미끄러지면 최하단 낙하존 → 사당 즉시 리스폰(무마찰). 중간 체크포인트 사당(사당4, L3) 1개로 공정성 확보.
- **창 1자루 규약 준수**: 한 번에 창 하나. 각 창꽂기 구간마다 "던져 딛고 → 다음 발판 확보 후 → 회수(재무장)"의 리듬을 강제.
- **적 없음**: 순수 이동 마스터리 무대. 낙하존이 유일한 실패 조건.

## 6) 창 꽂기 발판 지점 (구체 동선)
> 규약: 창은 반드시 벽/지형/적 표면에 박혀야 발판이 됨. 공중 부양 발판 없음. 한 번에 하나 → 매 구간 회수 필수. **창발판은 벽에서 돌출한 작은 레지 → 옆/위에서 딛고 올라섬(밑면 안착 아님).**

- **[B2 · 시그니처] 수련 성구 PB 좌면**: L1 우측 모서리(x2.0, y4.5)에서 PB 좌면(x5.5)을 향해 던짐(거리 3.5u ≤ 5u). y5.5에 박혀 창대가 좌측으로 돌출 → **발판 x4.7~5.5, y5.5** 생성. → 대시점프(Δx 2.7u, Δy +1.0u)로 발판 딛고 → 좌상 L2로 **대시+이단강림**, L2는 발판 좌측으로 오프셋되어 **우측 자유 모서리로 아치 착지**. **L2 안착 후 회수**(재무장).
- **[B4] 우벽 창표적 구간**: L3 우측 모서리(x5.5, y11.0)에서 우벽 내측면(x8.4)을 향해 던짐(거리 2.9u ≤ 5u). y11.5에 박혀 좌측 돌출 → **발판 x7.6~8.4, y11.5** 생성. → 대시점프(Δx 2.1u, Δy +0.5u)로 발판(x8.0) 딛고 → **이단강림**으로 L4. **L4는 발판보다 좌측(x[6.0,7.4], 우끝 7.4 < 발판 좌끝 7.6)에 있어** 발판 위 상승 컬럼 머리 위가 비어 있고, 상승 후 좌측으로 드리프트해 **L4 우측 자유 모서리로 아치 착지**. **L4 안착 후 회수**.
- **[히든] 좌벽 창표적 구간**: L5 좌측 모서리(x3.5, y17.0)에서 좌벽 내측면(x0.3)을 향해 던짐(거리 3.2u ≤ 5u). y16.5에 박혀 우측 돌출 → **발판 x0.6~1.4, y16.5** 생성. (복귀 동선은 §9-히든 참조 — **회수는 반드시 L5 복귀 후 마지막에** 수행.)

## 9) "정답 이동기" 동선 (도달성 근거 · 접근 방향 표기)
> 클리어런스 재검증 기준: **'정점 y > 상단 y'만으로는 불충분** → 각 수직 전환은 ①판 밑면 회피(상승 컬럼 머리 위가 비어 있음) + ②판 x-스팬 밖에서 접근해 자유 모서리로 아치 착지, **또는** ③한방향 통과, 중 하나를 반드시 충족. 접근 방향을 (←/→/↑/통과)로 표기.

1. **E → L1 (벽점프 슈트)**: 좌벽 내측면(x0.3)과 기둥 PA 좌면(x2.6) 사이 **갭 2.3u** 슈트에서 좌우 벽점프 2~3회로 y0.5→y4.5(+4.0u). 벽점프 1회 ≈ +1.6u·수평 2.3u. → **슈트 상단으로 탑아웃**해 L1(x[0.3,2.0]) 안착. *(수직-안착 문제 없음: 벽 사이 상승 후 열린 상단으로 빠져나옴.)*

2. **L1 → 창발판(B2) → L2 (창꽂기 + 대시점프 + 이단강림)** — **접근 ←(우측 모서리 아치)**: L1 우끝(x2.0, y4.5)에서 PB 좌면에 창(3.5u). 발판(x4.7, y5.5)로 **대시점프**(Δx 2.7u ≤ 대시 3u, Δy +1.0u ≤ 점프 1.6u). 발판에서 좌상 L2(x[0.3,2.2], top y7.5)로 **대시+이단강림**(Δx 2.5u, Δy +2.0u ≤ 이단강림 2.9u). L2가 발판(x4.7~5.5)보다 **좌측으로 오프셋 → L2 우측 자유 모서리(x2.2)로 아치 착지**. **L2에서 회수.**
   - *기하 강제*: 창발판 없이는 L1↔L2 최단 갭이 이단강림(2.9u) 초과 → 시그니처 필수.

3. **L2 → NB1 → L3 (창대 도약)** — **접근 →(좌측 모서리 아치)**: L2 우끝(x2.2)에서 NB1(x[2.2,2.9], top y8.0)로 짧은 스텝(Δx 0.4u, Δy +0.5u). NB1(~x2.55)에서 **창대 도약**(정점 y8.0+3.4=11.4u). **NB1은 L3(x[3.0,5.5]) 좌측 밖**(NB1 우끝 2.9 < L3 좌끝 3.0)이라 상승 컬럼 머리 위가 비어 있음 → 정점 부근에서 **우측으로 ~0.5u 드리프트해 L3 좌측 자유 모서리(x3.0)로 아치 착지**(top y11.0 ≤ 11.4u). **사당4 활성화.**
   - *수정 전 문제*: 구버전 NB1[3.2,4.0]은 L3[3.0,5.5] 안쪽 → 수직 도약이 L3 밑면 충돌. NB1을 좌측 밖으로 이동해 해소.

4. **L3 → 창발판(B4) → L4 (창꽂기 + 대시점프 + 이단강림)** — **접근 ←(우측 모서리 아치)**: L3 우끝(x5.5, y11.0)에서 우벽 창표적(x8.4)에 창(2.9u). 발판(x7.6~8.4, y11.5)로 **대시점프**(Δx 2.1u, Δy +0.5u). 발판(x8.0)에서 **이단강림**으로 L4(x[6.0,7.4], y14.0)로 상승(Δy +2.5u ≤ 2.9u). **L4가 발판보다 좌측**(L4 우끝 7.4 < 발판 좌끝 7.6)이라 x8.0 상승 컬럼 머리 위가 비어 있음 → 좌측으로 ~0.6u 드리프트해 **L4 우측 자유 모서리(x7.4)로 아치 착지**. **L4에서 회수.**
   - *수정 전 문제*: 구버전 발판[7.6,8.4]·L4[6.0,8.4] 우측 정렬 → 발판 위 도약이 L4 밑면 충돌. L4 우끝을 7.4로 후퇴시켜 발판을 L4 스팬 밖(우측)에 둠으로 해소.

5. **L4 → NB2 → L5 (창대 도약)** — **접근 ←(우측 모서리 아치)**: L4(x6.6)에서 NB2(x[6.2,7.0], top y14.5)로 짧은 스텝업(Δy +0.5u; NB2는 L4 위에 얹힌 finial). NB2(~x6.6)에서 **창대 도약**(정점 y14.5+3.4=17.9u). **NB2는 L5(x[3.5,6.0]) 우측 밖**(NB2 좌끝 6.2 > L5 우끝 6.0)이라 상승 컬럼 머리 위가 비어 있음 → 좌측으로 ~0.6u 드리프트해 **L5 우측 자유 모서리(x6.0)로 아치 착지**(top y17.0 ≤ 17.9u).
   - *수정 전 문제*: 구버전 NB2[4.5,5.3]은 L5[3.5,6.0] 안쪽 → 밑면 충돌. NB2를 L5 우측 밖으로 이동해 해소.

6. **L5 → XE → 출구 (이단강림 통과)** — **접근 ↑(한방향 통과 안착)**: L5(x~4.75, y17.0)에서 **이단강림**으로 상방(Δy +2.0u; 단일점프 1.6u로는 부족 → 이단강림 필수). **XE는 한방향(아래→위 통과) 상단 개구**이므로 밑면 충돌 없이 개구를 관통해 위에 안착. XE(x[3.5,6.5]) 착지 후 `(5.0, 19.0)`에서 7층으로.
   - *수정 전 문제*: 구버전 XE는 solid + L5 바로 위 → 목표 관문으로의 마지막 이동이 밑면 충돌. '상단 개구' 서술에 맞춰 한방향 통과로 명시해 해소.

- **(선택) 히든 빛결정** — **창발판 미회수 유지가 전제**:
  1. L5 좌끝(x3.5)에서 좌벽에 창(3.2u) → **발판(x0.6~1.4, y16.5) 생성, 회수하지 않음.**
  2. L5 → 발판으로 좌측 하강 도약(Δx ~2.5u ≤ 대시, Δy −0.5u) → 발판(y16.5) 딛기.
  3. 발판 → HC(top y15.5)로 하강(Δy −1.0u) → **빛결정 획득.**
  4. HC → 발판으로 복귀 상승(Δy **+1.0u** ≤ 단일점프 1.6u, Δx 소량) — *창발판이 아직 박혀 있어야 성립(그래서 3단계 전까지 회수 금지).*
  5. 발판(x1.4, y16.5) → L5로 **대시점프**(Δx 2.1u ≤ 대시, Δy +0.5u), L5 **좌측 자유 모서리(x3.5)로 아치 착지(→)**.
  6. **L5 복귀 후 마지막에 창 회수(재무장)** → 주 동선(6번)으로 합류.
  - Δ요약: L5 y17.0 → 발판 y16.5 → HC y15.5 → 발판 y16.5(+1.0) → L5 y17.0. 4대 이동기 응용을 아는 자만의 보상.

**요약 리듬**: 벽점프(슈트 탑아웃) → **(창·대시점프·이단강림, 우모서리←)** → 창대도약(좌모서리→) → **(창·대시점프·이단강림, 우모서리←)** → 창대도약(우모서리←) → 이단강림(통과↑).
**정점 체감 보강**: 개별 이동기 수가 진동하는 것은 유지하되, **사당4(y11) 이후 출구까지는 체크포인트가 없는 단일 연속 런**으로 프레이밍 — B4 창꽂기 연쇄 → 즉시 NB2 도약 → 즉시 L5 아치 → 즉시 통과 이단강림까지 "발 붙일 쉼이 최소인 무정지 상승"이 이 층의 진짜 클라이맥스. 마지막 통과 안착(개구 관통)은 가장 좁은 타이밍 창을 요구해 정상 직전 긴장을 최고조로 올린다.

## 10) 신전 룩 연출 노트
- **수직 첨탑 구조**: 화면 양옆은 은청빛 대리석 기둥이 위로 솟은 첨탑 내벽. 상승할수록 금세공 문양(성물 각인)이 촘촘해져 "정상 근접"을 시각화.
- **구름·고도감**: 좌우 벽 틈새로 구름 하늘이 흐르고, 아래(낙하존)는 짙은 구름바다로 흐릿하게 가려 "떨어지면 구름 아래로 사라진다"는 스테이크를 연출. 위로 갈수록 하늘이 밝아지고 신성한 역광이 강해짐.
- **발판 오브젝트**: 착지 단은 부서진 성구 파편·떨어진 기둥머리(broken capital). NB1·NB2 도약 나브는 위로 뾰족한 첨탑 장식(finial) — 딛고 튀어오르기 좋은 어포던스. **자유 모서리 아치 착지를 유도하도록 착지단의 '열린 모서리' 쪽을 시각적으로 살짝 낮게/개방적으로** 표현(플레이어가 어느 쪽으로 아치할지 직관).
- **한방향 개구(XE)**: 최상단 XE는 바닥이 반투명한 성광 커튼/빛 개구로 표현 — 아래에서 통과 가능함을 시각 신호(2층 한방향 발판과 동일 문법). 관통 순간 성광이 갈라지며 위로 안착.
- **창꽂기 표적(PB·우벽·좌벽)**: 창이 박히면 표면에서 은청빛 성광이 파문처럼 번지고 창대에 빛 입자가 감겨 "발판이 됨"을 명확히 신호. 회수 시 빛 궤적이 플레이어에게 돌아옴.
- **빛 결정(히든 HC)**: 좌측 그림자 알코브 안에서 은청색으로 맥동하는 결정 — 주 동선에서 살짝 어긋난 어둠 속에 배치("빛으로 유혹하되 정답 이동기로만 닿는" 히든 문법). 창발판이 박혀 있는 동안에만 위로 돌아나올 수 있어, "회수를 참는 판단"까지 연출로 강조.
- **사당**: 강림 사당3·4는 바닥에 뿌리내린 작은 성단(빛기둥 세이브 포인트) — 낙하 후 이 빛기둥으로 강림하는 리스폰 연출.
- **정상 예고**: XE 개구 너머로 성종 실루엣과 강한 황금 광원을 살짝 노출해, 마지막 통과 이단강림 직전 "목표가 눈앞"임을 각인.

# 7층 — 정상 성종 (The Summit Bell) — 상세 설계

## 1) 한 줄 컨셉
좁고 아찔했던 첨탑을 뚫고 **구름 위 개방 테라스**로 솟아오르는 순간, 카메라가 확 줌아웃되며 하늘 신전의 전경이 펼쳐진다. 여기서는 낙하존도 적도 없다. 넓은 대리석 전망대를 시원하게 질주해 마지막으로 **성종(聖種)을 창으로 울리면 클리어** — 앞선 여섯 층에서 벼린 손맛을 마음껏 뽐내는 "승리의 랩(victory lap)"이자 피날레 연출 무대.

## 2) 이 층이 뽐내는 메커니즘
- **개방감의 반전(Payoff)**: 6층의 폭 8.4u 수직 샤프트 → 폭 16u 수평 전망대로 극적 전환. 좁음→넓음, 긴장→해방의 대비가 상승 여정의 보상이 된다.
- **시그니처의 마지막 무대(선택형 플로리시)**: 성종 타격은 초간단 정답(스텝→단일점프+↑공격)으로 누구나 클리어 가능하되, 원하면 **종탑 대들보에 창 꽂기 → 딛고 위에서 낙하 대시공격으로 종 크라운 강타**라는 화려한 마무리를 열어둔다. 시그니처를 강요하지 않고 "자랑"으로 배치.
- **무해한 승리의 랩**: 지상·공중 허수아비 배치로 클리어 직전 마지막 콤보/창강화 소진 연출을 유도. 실패 조건이 사실상 없어 순수한 손맛 자축 무대.
- **연출 클라이맥스**: 종을 울리면 신성력 광파가 퍼지고 구름이 갈라지며 카메라가 하늘로 팬 → 소프트 엔딩.

## 3) 크기 (w × h)
**16.0u × 9.0u** (넓고 낮은 개방 전망대). 6층의 좁고 높은 비율을 정확히 뒤집는 형태.

## 4) 진입(하단) · 출구(상단) 좌표 (로컬)
- **진입(하단)**: `(5.0, 0.5)` — 6층 첨탑의 상단 개구(한방향 통과판, 아래→위)를 뚫고 올라와 테라스 바닥에 안착. 6층 출구 `(5.0, 19.x)`와 x=5.0으로 수직 정합. 개구 자리는 테라스 바닥 x[4.0,6.0] 구간의 oneway(아래→위 통과)로 표현되어, 올라온 뒤에는 그 위에 자연스럽게 선다.
- **출구(상단)**: **없음 — 최종 층.** 목표물 = 성종. **성종 타격 = 클리어(소프트 목표).** (물리적 출구 대신 종 타격 트리거가 엔딩 연출을 발동.)

## 6) 창 꽂기 발판 지점 (선택형 플로리시)
- **어디에**: 종탑 **대들보**(`x[12.9,15.1], y=6.6`, spear-surface) 또는 아치 **기둥**(`x=12.6/15.1`)에 창을 박는다.
- **어떻게 오르나(연출용 화려한 경로)**:
  1. 플린스(y=3.5)에서 위로 **창 던지기**(사거리 5u 내, 대들보까지 Δy=+3.1u — 사거리 안). 대들보에 창이 박혀 **작은 발판** 생성.
  2. 박힌 창을 딛고(창대 도약 또는 단일점프) 성종 **위쪽**으로 올라선다.
  3. **낙하 대시공격/차지 찌르기**로 종 크라운(y=6.2)을 위에서 강타 → 커다란 신성력 광파 연출과 함께 클리어.
  4. 마지막에 **창 회수**(돌아오며 타격) — "재무장한 채 종을 울리고 하늘을 본다"는 그림으로 마무리.
- **규약 준수**: 한 번에 창 하나. 플로리시를 안 써도(정답 경로) 클리어 가능하므로 창 상태 부담 없음.

## 7) 허수아비 / 반격 표적 배치

|---|---|---|
| (7.0, 0.5) | 지상 허수아비 | 클리어 직전 3타 콤보(찌르기→올려베기→회전쓸기) victory-lap 확인 |
| (8.5, 0.5) | 지상 허수아비 | 대시공격·차지 찌르기 관통(2체 정렬로 관통 히트 시험) |

- **강림 사당5**: `(2.5, 0.5)` — 진입부 좌측, 전망 발코니 아래. 사실상 실패 조건이 없는 층이지만 (선택) 우측 개방 낙하존 이용 시 무마찰 즉시 리스폰 지점. 6층 사당4 이후 첫 안전 사당으로, "정상에 도달했다"는 안도의 체크포인트.

## 9) "정답 이동기" 동선 (도달성 수치 근거)
1. **진입·개방 연출**: 첨탑 상단 개구를 통과 → `(5.0,0.5)` 테라스 안착. 카메라 줌아웃, 구름 위 전경 공개.
2. **victory-lap(선택)**: 오른쪽으로 **달리기**하며 지상 허수아비 A(7.0)·B(8.5)에 3타 콤보/대시공격. 넓은 수평 속도감 재현.
3. **스텝 A 등정**: 테라스(y=0.5)→스텝 A(y=2.0), 상승 **1.5u ≤ 단일점프 1.6u**. 단일점프로 안착.
4. **공중 허수아비 에어콤보(선택)**: (11.0,3.4)에 이단강림+↑공격. 클리어 전 마지막 공중 손맛.
5. **플린스 등정**: 스텝 A(y=2.0)→플린스(y=3.5), 상승 **1.5u ≤ 1.6u**. 단일점프.
6. **성종 타격(정답)**: 플린스(y=3.5)에서 성종 하단 림(y=4.8) 향해 **단일점프(+1.6u) + ↑공격**. 실질 갭 **1.3u < 1.6u**로 여유 명중 → **종 울림 = 클리어**. 신성력이 남아 있으면 **창강화 후 강타**로 빛의 한 방 연출.
   - **또는 플로리시**: §6 경로(대들보 창 꽂기→위에서 낙하 대시공격). 창 던지기 사거리 5u·창대 도약 정점 3.4u 내에서 전부 성립.

> 모든 수직 이동이 단일점프(1.6u) 이하로, 최종 층답게 관대함. 시그니처(창 꽂기)는 자랑용 옵션으로만 요구되어 공정성·난이도 하강 곡선을 만족.

## 10) 신전 룩 연출 노트
- **대리석 전망대**: 은백색 대리석 바닥에 금세공 문양 상감. 좌우 낮은 난간에는 은청색 **빛결정**이 일정 간격으로 박혀 진동한다(전망 확보용 낮은 높이).
- **성종**: 거대한 금·청동 성종. 표면에 성문(聖文) 음각, 매달린 사슬은 금세공. 미타격 시 은은한 숨결광, **타격 순간 신성력 광파(빛결정색)가 동심원으로 퍼지고** 화면 전체가 한 프레임 하얗게 번쩍(산나비식 juice).
- **구름·전망**: 테라스 가장자리 아래로 뭉게구름 바다가 흐르고, 먼 곳에 다른 신전 첨탑 실루엣이 떠 있다. 배경 스크롤로 "정상"의 고도감 강조.
- **광원**: 상단 후방에서 태양 신광(god ray)이 아치 기둥 사이로 쏟아져 종을 역광으로 감싼다. 종을 울리는 순간 태양광이 강해지며 카메라가 하늘로 팬 → 소프트 엔딩 컷.
- **좌측 전망 발코니**: 큰 단일 빛결정 1개(연출용 랜드마크). 플레이어가 잠시 멈춰 구름 전경을 감상하도록 유도하는 "숨 고르기" 지점.

## 물리 상수 단일 진실원

`REACH`를 손으로 적지 않고 **`PHYS`에서 유도**한다(유니티 스펙 §4와 동일 값).
물리를 튜닝하면 게이팅이 자동 재검증된다.

| 값 | v1.0(수기) | v1.1(유도) | 근거 |
|---|---|---|---|
| 단일점프 | 1.6 | **1.592** | `jumpV²/2g = 9.10²/52` |
| 이단강림 | 2.9 | **2.886** | `+ airJumpV²/2g` |
| 창대 도약 | 3.4 | **3.402** | `vaultV²/2g`, `vaultV=13.30` |
| 대시점프 수평 | 3.0 | **3.153** | `dashSpeed·dashTime + (체공−dashTime)·runSpeed·airControl` |
| 공격 위리치 | — | **0.80** | 게이팅 판정에 신규 반영 |

> **창대 도약은 도약 나브(NB) 또는 박힌 창 위에서만 발동**한다. 아무 발판에서나 3.4u가 나오지 않는다.
> **게이트 갭은 이동기 한계 대비 최소 0.30u 초과**(프로젝트 규칙). v1.0의 여유 0.1u 게이트들을 재조정했다.

## 검증 (11항목 · 인게임 `T`키 / `node proto/verify-map.mjs`)

1. 충돌 타입 겹침 없음 · 2. 창 계획 유효(면·사거리) · 3. 창 발판이 기존 지형에 안 파묻힘
4. **게이트 표면이 이동기만으로 도달 불가**(진입점 기준 도달 폐포 + 기둥 차폐 판정)
5. **게이트 표적이 공격 리치 포함해도 도달 불가** · 6. 게이트 갭 여유 ≥0.3u
7. 층간 포탈 양방향 정합 · 8. 체크포인트 참조 유효
9. **모든 층 클리어 가능**(창을 쓰면 출구 도달 — 가상 창 발판 포함 탐색)
10. 히든 수집물 전부 도달 가능 · 11. **히든 게이트 성립**(전용 면 없이 불가 / 복귀 제약)

> 검증기 자체를 역검증했다: C1~C4를 코드에서 되돌리면 **전부 FAIL이 재현**된다(테스트가 공허하지 않음).

## 데이터 스키마 (schema `temple-map/1.1`) — 유니티 이식 대비

- 모든 요소에 **ascii `id`**(1차 키), 한글 `label`은 표시용
- 형상은 **`rect:[x,y,w,h]`** 좌하단 원점 → Unity `Rect`/`BoxCollider2D`(`size=(w,h)`, `offset=(w/2,h/2)`) 1:1
- `stand:true|false` + `cap:"finial"` — **착지 가능 여부를 데이터가 선언**(C1·4F 결함의 근본 차단)
- `gate:"spear"|"vault"` — 이 표면에 도달하려면 필요한 수단(자동 감사 대상)
- `spearFaces[]` 분리 + **`normal:[nx,ny]`** — 콜리전이 아니라 레이캐스트 표적. 발판은 **법선 방향으로 돌출**
- `hazards[].respawn` → 체크포인트 id · `checkpoints[]` · `portals[]`(`mode:"door"|"physical"`, `toPortal`)
- `targets[]`(`kind:"ground"|"air"|"wall"|"counter"`, `gate`) · `collectibles[]`(`gate:"spear-face"|"spear-return"|"vault-arc"`)
- `spear:{ledgeLen:0.8, ledgeThick:0.12, maxPlanted:1}` — 발판 치수를 데이터로(렌더 마법수 제거)
- `oneway`별 `dropThrough` 명시(7F 개구는 `false`) · 층별 `camera` 힌트
- 게임 내 **`E`키 → `temple-map.json` 내보내기**(유니티 임포터 입력)

## 런타임 골격 (다음 단계 캐릭터 컨트롤러 대비)

- `buildWorld()`로 **월드 좌표 1회 평탄화**(`WORLD_GEO`/`SPEAR_FACES`/…) — `yOff` 산술이 코드에서 사라짐
- `SpatialHash(2u)` + 질의 API: `Q.sweep / groundBelow / wallContact / ceilingAbove / onewayBlocks / hazardAt / checkpointNear / raycastSpear`
- **동적 창 발판**: `plantSpear(faceUid, y)` → 법선 방향 레지 생성 + 해시 등록, `recallSpear()` 해제. `maxPlanted:1`
