## 1. 컨셉

> **할로우 나이트의 탐험 × 마법학교의 낭만 × 스컬의 스타일리시 전투 × 시스템 웹툰의 성장 가시성.**
> 마법학교를 허브로 넓고 유기적인 세계를 탐험하며, 마법을 배우고 몸에 새겨 승급하고,
> 압도적 강자들의 서사를 만나다가 — 끝내 그들을 넘어서는 이야기.

### 네 개의 기둥
1. **탐험 (할로우 나이트)** — 유기적으로 얽힌 맵, 직접 그려나가는 지도, 능력으로 재개방되는 길. 적은 물량이 아니라 **개체** — 한 마리 한 마리가 상대다.
2. **마법학교 감성 (아르피아의 '느낌')** — 수업과 모험으로 마법을 배우는 여정, 승급 제도, 전설적인 선생, 아늑한 비밀 공간, "한 층 위의 마법"이라는 동경.
3. **스타일리시 전투 (스컬의 '감각')** — 쿨 없는 화려한 기본기 + 굵직한 스킬. 난사가 아니라 리듬 — 손은 단순하고 화면은 화려하게.
4. **강자들의 서사 (히어로 킬러의 '기법')** — 개성 강한 강자 앙상블, 반전으로 풀리는 과거사, 초반엔 업혀가고 후반엔 넘어서는 곡선.

- **타깃**: HN·스컬·셀레스트를 즐긴 액션 메트로베니아 팬(스팀, 15~35). 난이도 철학 = "실력이 우선"(§4.3-7).

**엔진은 본격 개발 착수 시점에 재결정한다** (3트랙 체제 — 현재 Track 2는 구현 동결·기획만). 아래는 검증된 자산.

### 검증 완료된 개발 루프 (Godot 4.7 실험, 2026-07-15)

3. 클라우드 검증: 파서/린터 + 데이터 정합성 린트 + (월드) 그래프 BFS — 커밋 전 자동 점검. 실부팅 검증은 유저 몫
4. **휴가(집)**: 컨트롤러 테스트, 풀 빌드, Steam 업로드

## 3. 마법 체계 — "배우고, 새기고, 넘어선다"

### 3.1 설계 목표
- **직관성**: 보자마자 이해되는 원소 (불/물/바람)
- **아르피아 계승 + 확장**: 내 속성은 아르피아처럼 **캐릭터에 고정**(태생 정체성)하되, 그 위에 배움과 수집으로 넓히는 층을 얹는다 — 고정된 뿌리 + 넓어지는 가지
- **메트로베니아 결합**: 마법이 이동·퍼즐 열쇠를 겸함
- **1인 스코프**: 수집은 넓게, 장착은 좁게(각인) — 시스템 재사용 극대화

### 3.2 마법의 갈래

**⓪ 무속성 마법 — 이동술 (슬롯 면제)**
- 이동 마법(③) 전부가 무속성·슬롯 면제. **진행 필수 이동기는 전부 여기에 둔다** — 속성과 무관해야 어떤 속성으로 시작해도 같은 경로로 진행할 수 있다(§3.5-b).

**① 정규 속성 마법 — 불 / 물 / 바람 (학교에서 배움)**
- **초급**: 요건(수강 자격·간단한 과제)을 채우면 수업으로 배운다. 전원 이수 가능 — 기초 주문은 월드 상호작용 열쇠를 겸함(불=태우기, 물=물길 잇기, 바람=날리기·풍차).
- **고급**: 수업만으로는 못 배운다 — **해당 마법의 주문서/마법서를 구해 와야** 선생이 전수한다. 주문서 입수에는 **랜덤성**: 어떤 퀘스트·지역을 지났는가에 따라 손에 들어오는 주문서가 달라진다(플레이어마다 빌드가 갈리는 장치).
- 마도서는 물건이다: 도서관 등록, 달시장의 수상한 마도서, 던전 깊은 곳에 그냥 꽂힌 책(순수 탐험 보상)도 존재.

**② 확장 속성 마법 — 전기 / 땅 / 어둠 / 빛 (모험에서 배움)**
- 각 마법과 관련된 장소(지역·퀘스트·이벤트)에서 습득. 지역당 1~2개 — 습득량 자체가 총량 통제 장치.
- **필수 진행 게이트로 쓰지 않는다** — 외속성을 필수로 걸면 결국 전부 배워야 하고, 희소성도 속성 선택도 함께 죽는다(§3.5-b). 지름길·비밀·선택적 접근만 연다.
- 속성 마법 공통(①·②): 강력한 **쿨타임 공격 마법** — 스킬 난사 금지 원칙(§6.1)의 몸통. 배웠어도 **각인해야** 사용(§3.3).
- **외속성을 쓸 유인**: ⓐ상황 단축키 — 특정 적·지형에서 눈에 띄게 편해진다(없어도 클리어 가능) ⓑ수집욕 — 도감·획득 서사·비실용 마법·등급(§3.5-c) ⓒ지름길·비밀 접근.
- 빌드 정체성 = "어떤 속성으로 태어났고, 무엇을 새겼으며, 어떤 카드를 곁들였는가."

**③ 이동 마법 — 메트로베니아의 척추**

> **공통 원칙: 모든 이동 마법은 마나를 소모한다.** 지상 마나 회복이 평지 이동 비용을 상쇄 — 걷기는 공짜처럼, 공중 곡예는 마나만큼. 수치 정본 = `docs/movement-spec.md` v2.1 (유저 손맛 검증 완료).

*기본 이동 마법 — 각인 불필요, 항상 사용:*
| 마법 | 획득 | 내용 |
|---|---|---|
| 달리기·점프 | 처음부터 | — |
| **대시** | 튜토리얼 첫 습득 | 지상 수평 / **공중 8방향**. 무적 없음(회피는 간격). 마력석 강화로 거리 성장 — "첫 마법이 끝까지 자란다" |
| **부유** | 처음부터 | 홀드 중 그 자리·그 높이 고정(미세 표류만). 지속 ≈2초 + 쿨, 착지 시 쿨 초기화 — 공중에 닻을 내리는 한 박자. 전투 시그니처 |
| **이단점프** | 초반 수업 | 공중 점프 — 초반 맵을 여는 첫 게이트 |
| **벽달리기** | 초반 수업 | 모든 벽 발동(오리 방식) — 1회 0.8초(~300px)·같은 방향 벽 재부착 금지·발동 중 마나 소모. 통제는 룬 벽이 아니라 레벨 지형(수직 장벽 규칙) |

*모험 이동 마법(엑스트라) — 모험에서 습득, 각인 불필요·배우면 상시. 통제는 자체 마나·쿨:*
| 마법 | 내용 | 자체 제한 |
|---|---|---|
| **얼음 발판** | 설치형(전용 키) — 그 자리에 발판 생성. *"모자란 발판 하나를 채우는 스킬"* — 다른 이동기와의 조합이 설계 의도 | 동시 1개 + 쿨(5s) > 유지(3s) — 연속 사다리 불가 |
| **활공** | ↓ 홀드 — 낙하 감속 + 상승기류 타기 | 마나 2/초 |
| **물잠** | 수중 이동 + **산소→마나→체력 3단 버퍼**(강제 부상 없음 — 버틸지는 선택). 산소통(공기 방울)으로 연장 | 잠수 리스크 자체 |
| **비행** | 발동형 — 마력 날개 ≈6초 자유 비행 | 마나 45 선불 + 쿨 12s — 전투 직후엔 못 낢 |

- **비행 가드레일**: 대량 마나 선불+쿨 / 습득은 최후반(부유군도 직전) / 게이트 구간은 지속시간 내 도달 거리로 설계 / 폭풍·급류 구역은 비행 무력화 가능.
- **월드 게이트 사다리**: 이단점프 → 벽달리기 → 얼음 발판 → 활공 → 물잠 → 비행.
- **수직 장벽 규칙**: 공중 체인 최대 수직 도달(≈400px, 튜닝 후 확정)보다 높은 민벽·처마·위험 표면 = 통과 불가. 굴뚝(마주보는 벽 쌍)은 의도된 등반 루트에만.
- **소프트락 방지**: 이동 마법이 전부 각인 밖(상시)이라 슬롯 스왑형 소프트락 원천 불가. 필수 게이트 너머 첫 거점 전에 일방통행 금지.
- HN 회피: 크리스탈 하트식 차지 대시·그림자 망토식 무적 통과 미채용. 연출은 시전 언어(문양·영창).

**④ 패시브 마법**
- 공격력·쿨감·체력 등 지속 효과. **전용 패시브 칸 1~2에 장착** — 공격 각인과 분리("패시브만 끼는 정답" 방지).
- 획득 방식 미결(§11) — 후보: 수업 과제·의뢰 평판·비밀 방·펫 연동.

### 3.3 각인(刻印) — "아는 마법이 아니라, 새긴 마법으로 싸운다"
> 마법은 배우는 것만으로는 쓸 수 없다 — 마나 회로에 **각인**해야 하며, 몸이 품을 수 있는 각인 수는 유한하다.

- **공격 각인 2~3칸 → 승급으로 최종 5~6칸**(내 속성 전용) + **패시브 칸 1~2** + **외속성 칸 1**(§3.5-b). 도감(수집)은 넓게, 장착은 좁게.
- **칸을 분리하는 이유**: 같은 칸에서 경쟁시키면 "주력을 빼면서까지 곁들이진 않는다" → 외속성 사장, 또는 "패시브만 끼는 정답". 역할별 분리로 각 층이 독립적으로 산다.
- 각인칸 확장 출처: 승급(§7.4), 일부 펫 스킬(§8.2), 희귀 보상.
- **각인 교체는 거점에서만** — 빌드 선택이 '결심'이 되게.
- **이동 마법·생활 마법은 각인 밖 상시** — "문 열려고 거점 가서 스왑"하는 백트래킹 지옥 방지. 각인은 전투 성능만 관리.
- **수집이 재미의 축**: 아는 마법이 늘수록 각인 구성의 폭이 넓어지는 것이 성장의 실감. 조합(속성 섞기)은 축이 아니다 — 초점은 내 속성이 잡고, 수집은 도감이 보상한다(§3.5-c).

### 3.4 속성별 스킬 구조 — "같은 뼈대, 다른 성질"

> **아르피아 참조**: 각 속성이 같은 역할대를 갖되 형태·성질이 다르다(불꽃=광역 화력, 얼음=빙결·투척·내리찍기).
> **메커니즘을 완전히 갈라놓지 않는 것이 의도** — 코드·시스템 재사용률이 1인 스코프의 생명줄(§9).

각 속성은 **4개 역할대**를 각각 하나 이상 갖는다. 시작 3속성의 초기 라인업(설계안):

| 역할대 | 불 | 물 (얼음) | 바람 |
|---|---|---|---|
| **기본기 (투척)** | 화염창 — 관통·화상 | 빙창 — 명중 시 둔화 누적 | 풍참 — 빠르고 길되 단발 위력 낮음 |
| **광역** | 화염 낙하(운석 순차 낙하) | 서리 폭풍(지속 장판) | 회오리(한 점으로 끌어모음) |
| **대인** | 작열 낙인(지연 폭발·스택) | 빙결(굳힌 뒤 파쇄) | 진공파(단일 다단) |
| **생존** | 염화 외피(무적+해제 폭발) | 얼음 갑주(피해 흡수) | 질풍(고속 이동+무적) |

> **⚠ 속성 명칭 미결(§11)**: 아르피아의 시작 3속성은 불꽃/얼음/대지지만, 본작 정규 3속성은 불/물/바람이고 **월드 295방의 퍼즐 문법이 여기 묶여 있다**(물길·풍차). 변경 시 world-map 재정합 필요 — 현재는 기존 3속성 유지.

- **광역 역할대의 존재 이유** (유저 확정): 잡몹 물량전은 없지만(§6.7) **정예 2~3마리 동시 인카운터**는 있다 — 광역기의 의의는 그 자리. 화면을 덮는 크기가 아니라 *두세 개체를 함께 거는* 크기로 설계한다.
- **역할대가 같으므로 속성을 바꿔도 조작 문법이 유지된다** — 손이 다시 배울 필요가 없다.
- **차이는 부가효과·궤적·타이밍에서**: 화상(지속딜) vs 둔화(누적 제어) vs 경직(밀림). 숫자만 다른 게 아니라 **싸우는 리듬**이 달라야 한다.
- 확장 속성도 같은 역할대 문법. 단 4역할대를 꽉 채울 필요 없음 — 1~2개 역할대가 스코프에 맞다.
- **검증 상태**: 불 4종은 `game/combat.html`에서 구현·유저 손맛 확인 완료. **물·바람은 미검증 — 표는 설계안이다.**

### 3.5 내 속성 — 캐릭터 고정

> **내 속성은 캐릭터의 것이다.** 갈아끼우는 장비가 아니라 "그 사람이 어떤 마법사인가" — 아르피아의 태생 속성 구조를 따른다.

- **결정**: 게임 시작 시 정규 3속성 중 **선택, 이후 변경 불가**.
- **캐릭터 아트는 1벌 공용** — 시전 모션은 속성 무관 동일, **이펙트의 색·형태만 교체**. 속성별 실루엣 액센트(불=어깨의 잔열, 얼음=로브의 서리)는 소량 델타. → 속성 선택제를 쓰면서도 아트 물량은 캐릭터 1명으로 묶인다(§9.1).
- **효과**: 내 속성 마법은 온전한 효율(마나·데미지·쿨). 타 속성은 §3.5-b 페널티.
- **절대 규칙 — 딜의 정점은 언제나 내 속성.** 타 속성이 주력 딜을 이기는 일은 없다. 이 선이 무너지면 속성 선택 자체가 무의미해진다.
- **습득**: 내 속성 마법은 **스토리 진행을 따라가면 자연히 배운다**(주력 계통). 변형·강화·상위 티어는 탐험이 준다 — **진행이 뼈대를, 탐험이 살을.** (비선형성을 선형 습득이 잠그지 않게 하는 절충)

### 3.5-b 외속성 마법 — "가끔 꺼내는 카드"

> **자기 속성만으로 엔딩까지 갈 수 있다.** 외속성은 진행 요건이 아니라 수집물이며, 특정 상황의 단축키다.

- **습득**: 마을·거점을 **직접 찾아가** 하나씩. 마을당 1개 — 경로의 물리적 분산 자체가 총량 통제(많이 배우기 어렵다).
- **페널티**: 마나·데미지 효율 하락. 단 **가능/불가능이 아니라 시간·편의의 차이**여야 한다.
  - 좋은 예 — 화염 저항 적: 얼음이면 30초, 불로만 하면 90초. 둘 다 잡힌다.
  - 금지 — 화염 면역 적: 얼음 없으면 못 잡음. 선택이 숙제가 되는 순간 이 체계는 죽는다.
- **외속성 칸 1 — 주력 각인과 분리.** 주력을 빼지 않고 하나만 곁들인다. 칸이 하나뿐이라 동시에 두 속성 이상 안 섞인다 — 빌드 조립 게임으로 번지는 것을 구조로 차단.
- **교체는 거점에서 자유** — "이 구역은 불 저항 적이 많다더라" → 원정 단위로 갈아끼움.
- **조합 시너지는 기둥이 아니다.** 상시 연계(얼리고→깨기)를 주력 루프로 두면 매 전투 속성 섞기를 강제하게 된다 — 유저 의도(자기 속성 주력, 타 속성은 가끔)와 정면 충돌. 곁들였을 때의 작은 보너스로만.
- **속성별 진행 유틸은 필수 경로 금지** — 지름길·비밀·선택 접근만(물 계열로 비밀 수로, 땅 계열로 갈라진 벽). 진행 필수 이동기는 전부 무속성 공용(§3.2-⓪).

### 3.5-c 수집 설계 — 필수가 아닌 것을 모으게 하는 법

> 클리어에 필수가 아니므로 **동기는 전부 수집욕에서 나와야 한다.** 네 장치로 지탱한다.

1. **빈칸이 보인다** — 개인 장서(마법서) 화면. 빈 칸 자체가 훅. `이 지역 4개 중 2개` 진행률 표시.
2. **획득이 사건이다** — 마을마다 습득 방식이 다르다(시련·대가·평판·술 한잔). **마법 하나가 곧 그 장소의 기억.**
3. **쓸모없어도 갖고 싶은 것을 섞는다** — 연출 과잉형·장난용·NPC 반응 변화형을 배치해 수집을 실용에서 분리.
4. **등급으로 대상이 선명해진다** — §6.6 등급제를 도감 표시에 연동.

- "전 마법 수집"은 완주 목표(§9)의 하나.

### 3.6 진행 구조 — HN형 성장식
- **로그라이크 다회차 아님.** 한 세계를 이어서 탐험하며 능력·마법·각인칸이 영구 누적 성장(할로우 나이트형).
- 사망은 리셋이 아니라 되돌아가기 — 기록만 잃고 성장은 남는다(§6.8).
- 주문서 랜덤성(§3.2)은 "이번 세계에서 어떤 마법이 손에 들어오는가"의 변주 — 회차 리셋과 무관.
- 마법 수집·등급·진화도 단일 회차 안의 성장. 단 **내 속성만은 시작 시 확정·불변**(§3.5).

## 4. 스탯 & 감정

### 4.1 스탯 (확정)
| 스탯 | 실효 |
|---|---|
| **마력** | 공격 피해 |
| **마나** | 마나 풀 크기·회복 효율 |
| **속도** | 공격/시전 속도 (**이동 속도는 불변** — 손맛 고정) |
| **체력** | HP(마스크 단위), 경직 저항 |

- **랭크(F~SSS+EX)는 실효가 있되 소프트하게** — 캡을 두고, 플레이 실력이 언제나 더 중요(스킬 좋은 저스탯 플레이어가 이길 수 있어야 함 — 플레이테스트 지표).
- **표시 레이어와 엔진 레이어 분리**: 화면의 랭크는 화려하게, 엔진 수치는 이산 단계로 매핑.
- **랭크 상승은 굵고 드문 사건** — 상승 순간 스탯 그래픽이 극적으로 변한다(퀘지주 등급 연출 원리 — 표면 카피 금지). 출처는 승급·시련·과제·희귀 보상만.

### 4.2 감정(Appraisal) — 작은 연출 요소
- 대상의 대략적 강함을 랭크로 훑어 보여주는 가벼운 편의 기능. 누구에게나 성공.
- 유일한 역할: 강자를 만났을 때 줄지어 박힌 SSS·EX가 "세다"를 한눈에 전하는 것. 그 이상의 규칙(감정 실패·정보 단계 등) 없음.

### 4.3 안티패턴 (전 기획 적용)
1. 적 레벨 스케일링/데미지 스펀지 금지 — 보스는 깔끔한 히트 몇 방에 죽는다
2. 레벨 게이팅 금지 — 벽은 이동 마법(하드)과 적의 강함(소프트)으로만
3. 갈아서 뚫리는 벽 금지 — 반복 파밍 XP 최소화
4. 승급은 수치 임계가 아니라 스탯 조건 + 미션(스킬 체크)
5. 퍼센트 수프 금지 — 업그레이드는 즉시 이해되는 것으로
6. 표시 숫자와 엔진 숫자 분리
7. 스킬 좋은 저스탯 플레이어가 이길 수 있어야 한다

## 6. 전투 시스템 — "스타일리시하되, 난사는 없다"

### 6.1 조작 골격 (게임 내내 고정)
| 층 | 내용 | 제한 |
|---|---|---|
| **기본 공격** | 내 속성 투척체를 빚어 직선 발사 — 사거리 제한 (§6.2) | 쿨 없음 / **마나 수급원** |
| **속성 마법 (스킬)** | 공격 각인 2~3→5~6칸 — 내 속성 전용 (§3.4) | 쿨타임 + 마나 + 각인 |
| **패시브 마법** | 전용 칸 1~2 — 공격 각인과 분리 | 패시브 칸 장착 |
| **외속성 마법** | 외속성 칸 1 — 상황용 카드 (§3.5-b) | 거점 교체 / 효율 페널티 |
| 생활 마법 | 퍼즐·월드 상호작용 | 각인 무관 상시 |
| 이동 마법 | 대시·벽달리기·비행 등 (§3.2-③) | 각인 밖 상시 — 통제는 자체 마나·쿨 |

- 버튼은 게임 내내 늘지 않는다. 복잡성은 거점에서의 각인 선택(머리)에만 있고 손은 단순하다.
- **스킬 난사 금지**: 쿨과 마나가 이중으로 잠근다. 스킬은 문장이 아니라 마침표.

### 6.2 기본 공격 — "내 속성으로 빚어서 던진다"

> 레퍼런스: 메이플스토리 일리움 `크래프트:자벨린` 결 — 창을 *만들어서* 날린다.

- **정의**: 마도구/촉매로 내 속성의 투척체를 그 자리에서 빚어 **직선으로** 날린다. 처음부터 사용·각인 불필요·쿨 없음 — 마나 수급원(§6.3).
- **2박자가 핵심**: 빚는 선딜 → 발사. 첫 박이 있어야 "활을 쏜다"가 아니라 **"마법을 만들어 던진다"**로 읽힌다 — 마법 가시성의 몸통.
- **유도 없음 · 완전 직선.** 조준은 정면 + ↑/↓ 각도만. 맞히는 책임은 플레이어에게.
- **사거리 제한 (최우선 가드레일)**: 뒷걸음 원거리 견제가 최적해가 되는 순간 전투가 납작해진다. 사거리를 **화면 폭의 1/3** 수준으로 묶어 "붙어야 닿게"(거리 조절의 긴장 = 전투의 심장).
  - **한계가 눈에 보여야 규칙이 된다**: 투척체는 사거리 끝에서 가늘어지고 사위다가 흩어진다. 안 보이면 버그로 읽힌다.
- **연타 리듬**: 3연타째는 대형 투척체(관통 +1) — 마지막 타를 크고 시원하게(스컬식).
- **아트 구조**: 모션 1벌 공용 + 속성 이펙트만 교체 — §9 아트 병목의 구조적 해소. 속성 차이는 색·입자·부가효과.
- 강철 무기처럼 그리지 않는다 — 마력으로 빚은 형상, 매개체(마도구)가 항상 출처로 보이게.
- **성장**: 등급 체계(§6.6)를 따른다 — 등급 임계마다 외형·피니시 강화.
- **타이밍**: 별도 박자 입력 없음 — 적의 패턴을 읽고 열린 윈도우에 던진다.
- **검증**: `game/combat.html`에 불 속성 구현, 유저 손맛 확인 완료. 수치는 F1 패널로 튜닝 중 — 확정값 아님.

### 6.3 자원 — 마나 충전식
> "시전은 모은 마나로 한다. 마나는 가만히 있어도 차오르고, 벤 자리에서 더 크게 거둬들인다."

- **자동 회복(소량) + 타격 수급(대량)** — 공격적인 플레이가 마법의 연료. 스킬 무한 돌리기는 마나가 잠근다.
- 회복은 마나와 분리: **횟수제 정수병, 거점에서만 충전** — 거점에서 멀수록 잔여 병 수가 원정의 카운트다운.

### 6.4 잔광(殘光) — 보류
- 재미 대비 복잡도로 보류. 원안은 부록 B — 전투가 밋밋하면 되살릴 카드.

### 6.5 마법의 역할 분담
- **내 속성 기본기(투척) = 효율·마나 수급(쿨 없음)** / **내 속성 각인 마법 = 결정력(쿨+마나)** / **외속성 1칸 = 상황 대응 카드**.
- 조합 시너지는 곁들임 보너스 수준(§3.5-b) — 기둥 아님.
- **화려함 도징**: 평시 화면은 절제, 스킬이 터지는 순간만 최대 연출.

### 6.6 성장 — 마법 등급과 진화
- **전 마법 F~SSS+EX 등급** — 스탯과 같은 척도·표시-엔진 분리. **마력석 업그레이드**(§8.1)로 상승.
- **성장 곡선 비대칭**: 강한 마법=고등급 출발·저성장 / **기본 마법=낮게 시작해 크게 자란다** — "첫 수업의 그 마법이 끝까지 함께 자라 오의가 된다."
- **진화**: 최대 등급 + 관련 장소의 시련/의식 + 진화 아이템(한정) → **질적 변신**(이름·형태·이펙트 교체. 예: 불화살→화염창→불사조 화살). 등급 업=수치, 진화=도약.
- **진화는 희소하다**: 아이템이 한정돼 모든 마법을 진화시킬 수 없다 — "어떤 마법에 헌신할 것인가"(각인 철학의 연장). 수량·상한은 §11.
- 진화 조건의 장소성(속성의 성지·은거 선생)이 월드 탐험과 성장을 묶는다.

### 6.7 인카운터 설계 — "물량이 아니라 개체"
- **잡몹 물량전 지양**: 소수 정예 개체를 하나하나 상대하며 나아간다 — HN의 배치 감각. 정예 2~3 동시 인카운터가 상한(광역기의 자리 — §3.4).
- **지형지물이 전투의 절반**: 좁은 발판·낙차·매달린 구조물·지역 기믹. 강한 적에게서 도망치는 비전투 이벤트도 활용(도주가 목표인 구간).
- **공용 아키타입 8종**: ①보행 근접 ②원거리 사수 ③비행 급습 ④방패 방어 ⑤돌진 자폭 ⑥소환/버프 ⑦매복/의태 ⑧중장 엘리트(미니보스 겸용). `아키타입 × 지역 스킨 × 속성 라이더 × 파라미터` = 체감 25~35종, 고유 스프라이트 12~16벌.
- **원칙**: 모든 공격에 읽히는 예비 동작 / 새 적의 첫 등장은 안전한 방에서 / 속성 약점은 소프트하게 / 적의 강함이 소프트 게이트.
- **보스는 별도 정성 설계** — 지역 기믹의 졸업시험.

#### 가독성 2원칙 (마법 주력 2D 액션의 최대 함정)
> 2D는 화면이 좁다. **내 마법 이펙트가 적의 예비동작을 덮는 것** — 이 장르에서 마법 주인공이 드문 핵심 이유 중 하나. 구조로 막는다.

1. **색 채널 분리** — 내 마법 = 난색(주황·적) / **적의 위험 신호 = 한색(시안·보라), 난색 금지(예외 없음).** 환경도 한색으로 두되 위험 신호는 환경보다 채도를 높인다.
2. **위험 레이어는 항상 최상단** — 적의 예비동작·위험 범위는 내 이펙트·파티클보다 나중에 그린다. 위험 영역은 면이 아니라 **외곽선**, 라벨은 어두운 판 위에.
- 보조: 화려함은 순간에 몰고 빨리 지운다(§6.5) / 시각이 붐비면 텔레그래프를 소리로도 뺀다.
- 검증: `game/combat.html` 최악 케이스(화염 낙하 + 화상 최대 + 돌진 예고 동시)로 확인.

### 6.8 사망/리스크 — "기록의 리스크"
> 죽음은 아무것도 빼앗지 않는다 — 마법도, 돈도. 대신 **직전 세이브 이후의 여행 '기록'이 소실**된다.

- 죽으면 마지막 거점에서 부활·완전 회복·적 리스폰. 각인·마법·재화 무손실.
- 소실: 세이브 이후의 지도 스케치·도감 메모·이야깃거리(젖어 번진 수첩 연출). *"기록은 거점에서 정리해야 비로소 내 것이 된다."*
- 리스크 3겹: ①정수병 잔량 ②거점 간격(초반 촘촘→후반 성김, 보스 앞 필수) ③미정리 기록.
- 즉사 지형(가시·낙사) = 사망 아님: 소량 피해 + 직전 발판 복귀.
- "죽음이 두려운" 게임이 아니라 **"되돌아가는 게 아까운"** 게임.

### 6.9 게임필 체크리스트 (수직 슬라이스 최우선)
입력 버퍼 / 코요테 타임 / 캔슬 창 / 히트스톱 / 짧은 선딜 / 착지·피격 경직 최소화. 이동 속도는 스탯 영향 금지. **이 영역은 개발자 본인의 손 튜닝이 최우선** — AI가 대신 못 하는 유일한 영역.

### 6.10 난잡함 방지 (요약)
①버튼 고정 ②생활 마법은 각인 밖 ③각인 교체는 거점만 ④총 습득 마법 20~25 / 동시 장착 = 기본기 + 공격 각인 2~3→5~6 + 패시브 1~2 + 외속성 1 ⑤스킬은 쿨+마나+각인 삼중 잠금 — "HN보다 딱 한 겹 복잡한" 지점 유지.

## 7. 학교 콘텐츠 루프

### 7.1 금지 3원칙
달력 시뮬 금지(수업은 내가 갈 때 기다린다, missable 없음) / 메뉴 클릭'만' 하는 수업 금지(수업은 반드시 플레이) / 컷신 복도 금지.

### 7.2 수업 = 3단 플레이
**이론(1~2분, 선생의 개성) → 실습(챌린지 룸 1개를 전 수업이 재사용) → 과제("배운 것을 세계에서 증명해 와라").** 과제 완료 = 습득 확정·성장·스탯 랭크 상승의 출처.

### 7.3 마법 습득 경로
| 경로 | 대상 | 방식 |
|---|---|---|
| **스토리 진행** | 내 속성 주력 계통 | 진행하면 자연히 배운다 — 뼈대(§3.5) |
| 수업 (요건 충족) | 정규 초급 | 이론→실습→과제 |
| 주문서 전수 | 정규 고급 | 주문서를 구해 오면 선생이 전수 — 입수처에 랜덤성 |
| **마을 순례** | 외속성 | 마을을 직접 찾아가 하나씩(마을당 1개, 마을마다 방식이 다름 — §3.5-b·c) |
| 모험 습득 | 지역·특수 마법 | 퀘스트/이벤트/지역 — 내 속성의 변형·강화도 여기서 |
| 개인 교습 | 오의·비전 | 선생 신뢰 라인 (은거 선생 포함) |

### 7.4 승급
- **조건 = 스탯 도달 + 미션 달성**(지정 과업·대련 승리 등 스킬 체크). XP 임계치 아님.
- **보상 = 각인칸 확장**(공격 +1, 이정표 승급에서 패시브 +1) + 상위 수업·출입 개방. 승급은 의식(ceremony)으로 연출, 스탯창에 등급 표시.
- 임시 명칭: 예과생 → 4급~1급 마도생 (정식 작명 추후).

### 7.5 의뢰 게시판
마을·지역의 부탁 = 로컬 스토리(60%)의 공식 입구. 의뢰 평판 → 상점 할인·특수 수업 추천서 등 소소한 특전.

### 7.6 교수진 2계층
담당 교수(상주 — 초급 수업·과제·승급 추천) + 고급마법 선생(속성 마스터 — 일부는 세계에 은거: 가마 마을의 화염술사, 부유군도의 바람 은자). 개인 교습은 모든 선생에게(분량 차등).

### 7.7 허브 인력
학교로 돌아올 이유 상시 2~3개: 각인 재구성 + 기록 정리 + 게시판 갱신 + 진행 중 수업 + 급식·기숙사 소극.

### 7.8 스코프
1회차 체감 수업 10~14개(정규 초급 3속성 + 고급 라인 3~4 + 이동 2~3 + 교양 2~3). 챌린지 룸 1개 재사용, 과제·의뢰는 데이터 양산.

## 8. 경제·펫·조력자

### 8.1 이중 통화
| | **화폐** | **마력석** |
|---|---|---|
| 정체 | 세상의 돈 | 마나가 응결된 광석 — 거인의 광산의 산물 |
| 획득 | 의뢰·퀘스트·판매 | **탐험** — 광맥·숨은 방·보스 (잡몹 파밍 없음) |
| 쓰임 | 생활·편의 | **성장·마법**: 스킬 강화, 일부 습득/전수 비용, 정수병 확장, 각인·승급 준비물 |

- **돈으로는 강해질 수 없다** — 파워는 마력석+과제의 영역.
- **비대칭 환전**: 마력석→화폐 상시 / 화폐→마력석은 제한적(달시장 — 보름마다, 한정 수량, 비싼 값).

### 8.2 펫
- 모험 중 인연으로 영입, 동반 1마리(교체는 거점). 스코프 4~6종.
- **펫 스킬 = 공격형 또는 패시브형 1개+α.** 후보 풀: 각인칸 +1 / 전 스킬 1단계 강화 / 펫 전용 마법 / 융합 변신 / 짧은 무적기 / 어둠 밝히기 / 마력석 감지 / 사망 시 기록 일부 보호. 강력 효과는 후반 배치·밸런스 주의(§11).
- 자동 발동 또는 기존 키 공유 — 신규 버튼 금지.

### 8.3 조력자
- 펫과 유사한 동반 시스템 — 강자/동료가 일정 구간 동행하며 패시브+시그니처 스킬 1개를 빌려준다.
- 구체 설계는 미션 콘텐츠·스토리 확정 후.

## 9. 스코프 가드레일 (1인 · 2~3년)

- **목표 분량**: 주선 **8~12시간** / 완주(100% — 전 지역·전 마법·전 비밀) **20~30시간** (수직 슬라이스에서 방당 체류 실측 후 확정, 295↔260방 컷과 연동) / 보스 5~8 / 총 습득 마법 20~25.
- **개발 순서**: 코어(이동+전투 부품) → 수직 슬라이스(학교 일부+곤돌라 마을+광산 상부, 15~20분, 출시 퀄) → 방 생산 시간 실측 → 스코프 최종 결정 → 지역 단위 반복.
- 1인 개발을 죽이는 순서: ①맵 비대 ②메커닉 난발 ③아트 병목(애니메이션) ④재사용 없는 수제 제작.
- 기본기 아트 비용: **모션 1벌 공용 + 속성 이펙트 교체**(§6.2) — 상한은 속성 이펙트 7벌 + 진화 이펙트(한정 수량만큼). 손맛은 도형 단계에서 아트 0으로 선검증.
- 마케팅: 스팀 페이지 조기 개설, 한국 인디 대회 출품, 넥스트페스트는 위시리스트 모멘텀 후.
- **재개 가능성**: 이 문서와 TODO를 항상 최신 커밋.

### 9.1 아트 방향 (확정)
> **최종 화풍을 지금 정하지 않는다. 게임을 먼저 완성하고, 아트는 딱 한 번만 입힌다.**

- 재미 검증은 **주스(히트스톱·흔들림·파티클)를 입힌 읽히는 도형** 상태에서 한다 — 주스 코드는 최종 아트에도 그대로 산다.
- 최종 화풍은 **스컬급 HD 픽셀**(유력 — 아티스트 접근성·단가) 또는 HN급 벡터(성공 시 리마스터 카드) 중 **한 번만 결정·제작**. 두 번 만들지 않는다.
- **미룰 수 있는 근거**: 충돌을 월드 단위 폴리곤으로 처리(타일·픽셀 격자에 안 묶임) → 최종 아트가 무엇이든 코드·레벨·충돌 재사용.
- **지금 잠근 치수(화풍 무관)**: 카메라 뷰 = **640×360 월드 단위 상당**(1080p 정수 3배) / 캐릭터 높이 ≈ **54 월드 단위**(화면의 ~1/6.7) / 히트박스·충돌 = 월드 단위 명시 폴리곤(스프라이트와 분리).
- **파이프라인 규격**: 애니메이션 상태명·프레임 규격을 계약으로 고정(플레이스홀더→최종 = 데이터 교체). 적 스프라이트 12~16벌 상한·스켈레톤 재사용.
- **접근성 커밋**: 키 리매핑 / 색약 대응(속성 텔레그래프는 색+형태·아이콘 병행) / 대사 자막.
