## 1. 컨셉 한 줄

> **할로우 나이트의 탐험 × 마법학교의 낭만 × 시스템 웹툰의 성장 가시성.**
> 마법학교를 허브로 넓고 유기적인 세계를 탐험하며, 원소 마법을 전공으로 배워 승급하고,
> 압도적 강자들의 서사를 만나다가 — 끝내 그들을 넘어서는 이야기.

### 세 개의 기둥
1. **탐험의 재미 (할로우 나이트)** — 유기적으로 얽힌 맵, 직접 그려나가는 지도, 능력으로 재개방되는 길, 전투 외 다양성(추격·장애물·비밀·미로).
2. **마법학교 감성 (아르피아의 '느낌')** — 수업·퀘스트로 마법을 배우는 여정, 승급 제도, 전설적인 고급마법 선생, 아늑한 비밀 공간, "한 층 위의 더 높은 마법"이라는 동경.
3. **강자들의 서사 (히어로 킬러의 '기법')** — 개성 강한 다수의 강자, 반전으로 풀리는 과거사, 초반엔 그들에게 업혀가고 후반엔 그들을 넘어서는 성장 곡선, 그리고 (스토리 확정 후) 막을 수 없는 존재가 다가오는 공포.

## 2. 엔진 & 개발 워크플로우

**결정: Godot 4.x + GDScript.** "웹으로 개발 후 유니티 이식" 안은 폐기 (이식=전면 재작성, 시간 배분이 정반대).

### 개발 루프 (사지방 제약 하)
1. **Claude Code(웹)** 에서 로직·시스템·레벨 데이터 작성 → git 커밋/푸시
2. **사지방 PC**: 포터블 Godot(설치·관리자권한·cmd 불필요) + 브라우저에서 repo ZIP 다운로드 → 열어서 **F5로 직접 플레이·손맛 확인**
3. 관찰한 버그/손맛을 Claude Code에 텍스트로 피드백 → 수정 → 반복
4. 클라우드에서는 **headless Godot + GUT/gdUnit4 자동 테스트**로 회귀 방지
5. **휴가(집)**: 컨트롤러 테스트, 풀 빌드, Steam 업로드(GodotSteam GDExtension — zip 드롭인, 터미널 불필요)

### 헷지 (나중에 마음 바뀔 경우 대비)
- 레벨/스탯/대사 데이터는 JSON/CSV 등 **엔진 중립 포맷**으로 유지
- 엔진 종속 코드는 자체 시스템 레이어 뒤로 격리
- 아트/사운드 원본(PNG/Aseprite/WAV)은 어차피 완전 이식 가능

## 3. 마법 체계 — "전공제" (v3, 확정 방향)

### 3.1 설계 목표
- **직관성**: 불/물/얼음처럼 보자마자 이해되는 원소
- **아르피아와의 차별**: 아르피아 = *태생 종족 고정, 평생 한 원소*. 우리 = **학교에서 선택한 전공** + 나머지도 제한적으로 습득 가능
- **메트로베니아 결합**: 마법이 이동·퍼즐 열쇠를 겸함
- **1인 개발 스코프**: 시스템 재사용 극대화

### 3.2 세 개의 축

**① 이동술 (공용 — 메트로베니아의 척추)**
대시, 이단점프, 벽타기 등 핵심 이동기는 **원소와 분리된 공용 '이동 마법' 과목**으로 배운다.
- 이유: 전공별로 핵심 이동기가 갈리면 레벨 디자인이 전공 수만큼 분기되어 1인 개발이 불가능해짐. 필수 진행 게이트는 전부 공용 이동술로만 잠근다.
- 할로우 나이트처럼 5~6개 내외, 영구 획득, 습득 순서가 곧 지역 개방 순서.

**② 원소 기초 (공용 — 퍼즐 열쇠)**
모든 학생은 정규 4원소의 **기초 단계(등급 상한 D)** 를 수업으로 배울 수 있다.
- 각 원소의 기초 주문이 **월드 상호작용 열쇠**를 겸함: 불=덩굴/밧줄 태우기·화로 점화, 물=수반 채우기·불 끄기, 땅=스위치 누르기·매설로 개방, 바람=풍차·물체 날리기.
- 기초가 공용이므로 어떤 전공을 골라도 필수 퍼즐 진행이 막히지 않는다.

**③ 전공 (선택 — 전투 정체성과 깊이)**
주인공은 정규 4원소 중 하나를 **전공**으로 선택한다. 전공만이:
- 랭크 상한 **SSS**까지 수련 가능 (고급 주문, 오의급 마법)
- 해당 원소의 **고급마법 선생(원소 마스터)** 사사 가능
- 마나 효율 최상. 비전공 원소는 시전 코스트 페널티(수치는 추후 튜닝)
- 시각적 정체성(로브·이펙트 색 등)과 전공 전용 **비밀길/숨겨진 방** 소수 (필수 진행 아님 — 회차 유도용, 스코프 작게)

※ 부전공 제도는 **제거** — 아래 모험 마법이 빌드 다양성 역할을 대체 (제도 단순화).

### 3.3 원소 3계층 구조 (확정 방향)

**1) 학교 정규 전공 4종 (플레이어블): 불 / 물 / 땅 / 바람**
- 가장 직관적인 고전 4원소만 정규 커리큘럼. 전공 트리 비용 6→4로 절감.
- 주문 골격(투사체/설치/버프/광역)은 코드 재사용, 원소별 데이터·이펙트만 교체 (스컬의 데이터 주도 교훈).

**2) 모험 마법 (비정규 — 탐험 중 습득): 얼음 / 번개 (+ 특수계 1~2 후보, 스토리 확정 후)**
- 학교가 가르치지 않는 마법을 **모험 중 만난 존재·장소·스승에게** 배운다 (아르피아 지하실 코볼트의 "교실 밖에서 배우는 마법" 감성을 시스템으로 확장).
- "커리큘럼 밖에 더 넓은 마법이 있다"는 동경·신비 연출 (아르피아의 '열리지 않는 3층' 정서).
- **전공과 무관하게 모든 플레이어가 공통 획득** → 필수 진행 게이트로 사용 가능. 중후반 월드의 메트로베니아 열쇠 담당 (초반 월드 = 정규 4원소 기초 + 이동술).
- 전공 트리보다 작은 큐레이션된 주문 세트 (원소당 소수 주문 + 이동/퍼즐 능력).
- 빌드 정체성 = "전공 선택 × 어떤 모험 마법을 얼마나 팠는가" (부전공 대체).

**3) NPC 전용 속성**
- 일부 강자·보스는 플레이어가 끝내 배울 수 없는 속성을 사용. "능력=성격" 원칙(§6)의 핵심 무대.
- 감정 시 속성명 자체가 `???`로 깨져 나오는 존재 = 신비·공포 연출을 시스템이 공짜로 제공.

### 3.4 전공 선택 타이밍 (유력안)
1막 = 예과(무전공). 전 원소 기초를 수업으로 체험 →
**1막 클라이맥스 = 전공 선택식** (첫 승급과 겸함, 의식으로 연출).
- 장점: 정보 없는 캐릭터 생성 화면 선택이 아니라, 직접 써보고 고르는 선택. 학교물다운 서사 비트.

### 3.5 승급 제도
- 이름 붙은 랭크 사다리 (명칭 새로 작명 — 아르피아의 견습/초보/숙련/마도사/대마도사/현자 금지)
- 승급 조건 = **XP가 아니라 시험/시련(스킬 체크, 보스전 포함)**. 승급은 의식(ceremony)으로 연출
- 승급이 게이팅하는 것: 배울 수 있는 주문 등급, 감정 가능 범위(§4.2), 출입 가능 구역, (부)전공 개방 등

## 4. 스탯 & 감정 시스템

### 4.1 스탯 구성 (확정 방향)
기본 4스탯 + 속성 블록, **전부 랭크제(F–E–D–C–B–A–S–SS–SSS, 규격 외 EX)**. **표시 레이어(화면의 랭크)와 전투 레이어(엔진 수치)는 분리** — 연출은 화려하게, 전투 영향은 소프트하게.

| 스탯 | 표시 | 전투 영향 (소프트, 캡 있음) |
|---|---|---|
| **힘** | 랭크 | 지팡이/물리 타격 피해 소폭 |
| **마나** | 랭크 | 마법 자원 풀 크기, 시전 지속력 |
| **속도** | 랭크 | 공격/시전 속도 소폭 (**이동 속도는 건드리지 않음** — 손맛 고정) |
| **맷집** | 랭크 | HP(마스크 단위, 소량·이산적), 경직 저항 |
| **속성** | 전공 원소 + 랭크 게이지 (게이지 = 다음 랭크까지 진행도) | 해당 원소 주문 위력/지속 — **시트의 시그니처 블록** |
| **통찰** | 랭크 | 감정 가능 범위. 전투 버프 없음 (순수 표현 레이어) |

- **랭크제 페이싱**: 랭크 상승은 굵고 드문 이벤트(D→C가 하나의 사건). 상승 출처는 퀘스트 보상·시련·희귀 아이템 등 **의미 있는 출처만** — "파밍 금지" 원칙(§4.3)과 맞물림. 내부적으로 랭크는 소수의 이산 단계로 엔진 수치에 매핑 (밸런스 상태 수가 적어 1인 개발에 유리).
- 퀘스트지상주의 가드레일: 그쪽의 5스탯 세트(힘/속도/맷집/**잠재력/두뇌**) 전체 복제 금지 → 잠재력·두뇌 대신 **마나·속성·통찰**로 우리 것이 됨. 랭크 사다리도 F~SSS+EX(장르 공용 문법)까지만 — 그쪽 특유의 확장 꼬리(SR/SSR/UR/LR/MR/X/XX/XXX/DX)와 "측정불가" **명칭** 금지 (감정 한계는 랭크명이 아니라 '감정 실패' 연출로).

### 4.2 감정(Appraisal) — 강자를 멋있게 만드는 장치
- 학교에서 배우는 감정 마법. 대상의 스탯 시트를 열람.
- **약한 상대**: 깔끔한 시트 + 약점/속성 힌트 (메트로이드 스캔처럼 도감 축적, 탐험 보상)
- **압도적 강자**: 감정이 **실패**한다 — 스탯이 `██████`로 깨지거나, "그릇이 상대의 깊이에 미치지 못한다" 한 줄. **숫자를 보여주지 않는 것이 어떤 숫자보다 강해 보인다.** 밸런스 비용 0 (순수 UI/연출).
- 통찰·승급이 오르면 읽을 수 있는 범위가 넓어짐 → 1막에서 `???`였던 교장의 시트가 종반에 비로소 읽히는 순간 = 성장의 가시화.
- 스탯 시트 예시:

```
── 학생부 · 감정 ──────────────      ── 감정 ───────────────────
(주인공)          2급 마도생          고급 화염술 교수 《????》
전공: 불   ██████░░░░  B             전공: 불  ██████████  SSS
힘   C       마나  B                 힘  S+   마나  ⚠ 감정 실패
속도 C       맷집  D                 속성: ??? — 그릇이 부족하다
통찰 C (감정 범위: 2급 이하)
```

### 4.3 반드시 지킬 안티패턴 (리서치 경고 — 기획 전반에 적용)
1. **적 레벨 스케일링 / 데미지 스펀지 금지.** 보스는 "깔끔한 히트 몇 방"에 죽는다. 변수는 스탯이 아니라 플레이어 실력.
2. **레벨 게이팅 금지.** 벽은 "레벨 20 찍고 와"가 아니라 능력/원소 열쇠로 잠근다.
3. **갈아서 뚫리는 벽 금지.** 반복 잡몹 파밍 XP 최소화 — 성장은 퀘스트/수업/탐험/보스에서. (파밍이 통하면 플레이어는 실력 대신 파밍을 택하고 재미가 죽는다 — 블러드스테인드의 실패)
4. **승급은 XP 임계치가 아니라 시험(스킬 체크)으로.** 파워 획득 시점을 개발자가 통제.
5. **퍼센트 수프 금지.** 모든 업그레이드 효과는 "+7%"가 아니라 즉시 이해되는 것으로 (HN 부적 원칙).
6. **표시 숫자와 엔진 숫자 분리.** 보스의 연출용 "9999"를 실제 HP에 물리지 않는다.
7. **스킬 좋은 저스탯 플레이어가 이길 수 있어야 한다.** 플레이테스트에서 지켜야 할 기능으로 취급 (세키로 1공력 클리어 정신).

## 5. 맵/월드 구조 원칙

- **골격**: 따뜻한 학교 허브 → 개성 있는 지역들의 고리 → 봉인된 후반 변경지대 (아르피아의 지형 감성 + HN의 유기적 연결)
- **지역 개성은 싸게**: 색 + 음악 + 고유 적 1종 + 이동 트릭 1개 = 지역 하나의 정체성 (HN 원리)
- **지도 그리기 시스템 채택**: 새 지역은 지도 없이 진입 → 지역 내 지도상인/미완성 지도 입수 → 탐험으로 채움 → 현재 위치 표시는 비용/장비로 옵션화
- **루프형 맵 그래프**: 막다른 트리가 아니라 되돌아오는 루프 — 백트래킹이 지름길 발견이 되게
- **벤치식 거점**: 저장 + 지도 갱신 + (부)전공/장비 재구성 지점. 패스트트래블은 월드가 충분히 커진 뒤 개방
- **아르피아 감성의 원리 차용** (카피 금지): "숨겨진 아랫세계 + 작은 존재를 도우면 마법을 얻는" 아늑한 비밀 공간 / "전투가 아닌 길찾기 도전"인 미로 지역 1곳
- **비전투 다양성**: 추격, 장애물, 정밀 플랫포밍 챌린지 룸(선택 콘텐츠로 격리), 어둠/매복 연출 — 전부 기존 이동 엔진 재사용으로 구현

## 6. 캐릭터/서사 원칙 (스토리는 미정 — 기법만 확보)

히어로 킬러에서 **기법만** 가져온다 (이름·능력·전제 복제 금지):
1. **정점 계층에 '자격 규칙'을 부여** — 단순 "최강"이 아니라 정의가 있는 계층. 규칙을 어기는 자가 즉시 흥미로워진다.
2. **능력 = 성격** — 마법의 '감각'이 그 인물의 심리를 대변하게 설계.
3. **대비쌍 배치** — 강자는 옆 캐릭터가 조명할 때 강해 보인다. 단독 등장 금지.
4. **과거사는 정보가 아니라 반전으로** — 모든 서사 픽업은 "아 그래서 그랬구나"를 줘야 한다.
5. **지형/조건부 우위** — 경직된 파워랭킹을 가위바위보로 풀고, 보스 레벨디자인 레버로 활용.
6. **성장 곡선**: 초반 = 고급마법 선생들이 압도적으로 매력적(동행 파워판타지) → 후반 = 그들을 넘어서는 것이 카타르시스. 감정 시스템(§4.2)이 이 곡선을 UI로 뒷받침.

공포(진격의 거인 땅울림의 '형태'만): 느리고 확실하게 다가오는 전선, 안전지대에 숨겨진 정체, 파워랭킹 무효화, 공감 가능한 근원, 카타르시스 거부. → **스토리 확정 시 재논의.**

## 7. 스코프 가드레일 (1인 · 2~3년)

- **수직 슬라이스 먼저**: 지역 1개를 출시 퀄리티로 (최종 아트/사운드, 보스 1, 이동기 게이트 1, 15~20분). 재미 검증 전에 시스템 확장 금지.
- 1인 개발을 죽이는 순서: ① 맵 비대 ② 메커닉 난발 ③ **아트 병목(진짜 크리티컬 패스는 애니메이션)** ④ 재사용 없는 수제 제작

- 마케팅: 스팀 페이지 조기 개설, 한국 인디 대회(GIGDC·BIC·네오위즈 퀘스트) 출품, 넥스트페스트는 위시리스트 모멘텀 생긴 뒤에 (증폭기지 생성기가 아님).
