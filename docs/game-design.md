## 1. 컨셉

> **할로우 나이트의 탐험 × 마법학교의 낭만 × 스컬의 스타일리시 전투 × 시스템 웹툰의 성장 가시성.**
> 마법학교를 허브로 넓고 유기적인 세계를 탐험하며, 마법을 배우고 몸에 새겨 승급하고,
> 압도적 강자들의 서사를 만나다가 — 끝내 그들을 넘어서는 이야기.

### 네 개의 기둥
1. **탐험 (할로우 나이트)** — 유기적으로 얽힌 맵, 직접 그려나가는 지도, 능력으로 재개방되는 길, 지형지물을 활용하는 진행. 적은 물량이 아니라 **개체** — 한 마리 한 마리가 상대다.
2. **마법학교 감성 (아르피아의 '느낌')** — 수업과 모험으로 마법을 배우는 여정, 승급 제도, 전설적인 선생, 아늑한 비밀 공간, "한 층 위의 마법"이라는 동경.
3. **스타일리시 전투 (스컬의 '감각')** — 쿨 없는 화려한 다단 기본기 + 굵직한 스킬. 난사가 아니라 리듬 — 손은 단순하고 화면은 화려하게.
4. **강자들의 서사 (히어로 킬러의 '기법')** — 개성 강한 강자 앙상블, 반전으로 풀리는 과거사, 초반엔 업혀가고 후반엔 넘어서는 곡선.

## 2. 엔진 & 개발 워크플로우

**Godot 4.7 + GDScript 확정.** 모든 곳(사지방/집)에서 4.7로 통일.

### 개발 루프 (검증 완료)
1. **Claude Code(웹)**: 씬(.tscn)·스크립트(.gd)·데이터(JSON)를 텍스트로 작성 → 커밋/푸시 (에디터 조립까지 완결된 프로젝트를 만든다)
2. **사지방**: ZIP 다운로드(또는 채팅 첨부) → 포터블 Godot Import → **F5 → 플레이 → 텍스트 피드백**
3. 클라우드 검증: gdparse/gdlint + .tscn 정합성 린트 + (월드) 그래프 BFS 검증 — 커밋 전 자동 점검
4. **휴가(집)**: 컨트롤러 테스트, 풀 빌드, Steam 업로드(GodotSteam)
- 4.7 교훈: **씬 파일은 정적 구조만, 동적 조립은 코드에서** (노드 경로 조회 취약). 로드 실패 폴백 + `[진단]` 출력 패턴 유지.

### 헷지
- 레벨/스탯/대사 데이터는 JSON/CSV 등 엔진 중립 포맷 (월드맵이 이미 이 방식)
- 엔진 종속 코드는 시스템 레이어 뒤로 격리 / 아트·사운드 원본은 완전 이식 가능

## 3. 마법 체계 — "배우고, 새기고, 넘어선다"

### 3.1 설계 목표
- **직관성**: 보자마자 이해되는 원소 (불/얼음/바람)
- **아르피아와의 차별**: 태생 고정이 아니라 **배움과 선택**으로 넓혀가는 마법
- **메트로베니아 결합**: 마법이 이동·퍼즐 열쇠를 겸함
- **1인 스코프**: 수집은 넓게, 장착은 좁게 (각인) — 시스템 재사용 극대화

### 3.2 마법의 세 갈래 (학습 구조 — 2026-07-17 개정)

**① 정규 속성 마법 — 불 / 얼음 / 바람 (선생에게 배움)**
- **초급 마법**: 요건(수강 자격·간단한 과제)을 채우면 **수업**으로 배운다. 전원 이수 가능 — 기초 주문은 월드 상호작용 열쇠를 겸함(불=태우기·점화, 얼음=얼리기·물길 굳히기, 바람=날리기·풍차).
- **고급 마법**: 수업만으로는 못 배운다 — **해당 마법의 주문서/마법서를 구해 와야** 선생이 전수한다. 주문서 입수에는 **랜덤성**이 있다: 어떤 퀘스트를 받았는가, 어느 지역을 탐험했는가에 따라 이번 회차에 손에 들어오는 주문서가 달라진다 (같은 회차라도 플레이어마다 빌드가 갈리는 장치).
- 마도서는 물건이다: 도서관 등록, 달시장의 수상한 마도서, 던전 깊은 곳에 그냥 꽂힌 책(순수 탐험 보상)도 존재.

**② 그 외 마법 (지역·특수) — 모험에서 배움**
- 정규 3속성 밖의 마법(태양·번개·어둠·대지 등)은 **랜덤한 퀘스트/이벤트/방문 지역**을 통해 습득한다. 지역당 1~2개 — 습득량 자체가 총량 통제 장치.
- 전공·속성 무관하게 모두 획득 가능 → 필수 진행 게이트로 사용 가능.
- 빌드 정체성 = "무엇을 배워서 무엇을 새겼는가."

**③ 이동 마법 — 메트로베니아의 척추 (개정: 각인칸 차지)**
- 세계의 하드 게이트는 이동 마법이 연다: 지상 질풍보(시작) → 영창 부유(시작) → 공중 질풍보 → 벽차기 질주 → 발판 각인 → 바람 타기 → 물잠 → 기류 승월 (개방 순서 = 월드 진행 순서, `docs/world-map.md`)
- **이원화**: 같은 기능의 이동술을 ⓐ**바람 계열 수업**으로 배울 수 있고 ⓑ**모험 중 고유 이동 마법**으로도 얻을 수 있다. ⓑ가 상위호환 — **각인칸을 덜 차지하거나(0~1칸) 더 시원하게 움직인다** (모험 보상의 메리트).
- **이동 마법도 각인칸을 차지한다** (개정 — 이동 빌드 vs 전투 빌드의 긴장). 단, 진행 불가 방지 가드레일 필수: **유력안 = 이동 전용 각인칸 1~2개 분리** (전투칸과 별도 — 필수 게이트가 잠기는 소프트락 방지). 밸런스는 §11-4.
- HN 회피: 크리스탈 하트식 차지 대시·그림자 망토식 무적 통과 미채용. 이름·연출은 시전 언어(문양·각인·영창).

### 3.3 각인(刻印) — "아는 마법이 아니라, 새긴 마법으로 싸운다"
> 마법은 배우는 것만으로는 쓸 수 없다 — 마나 회로에 **각인**해야 하며, 몸이 품을 수 있는 각인 수는 유한하다.

- **장착 가능 개수 = 몸에 새길 수 있는 각인 수.** 도감(수집)은 넓게, 장착은 좁게.
- 각인칸 확장 출처: **승급**(§7.4), 일부 펫 스킬(§8.2), 희귀 보상.
- **각인 교체는 거점에서만** — 빌드 선택이 '결심'이 되게.
- **생활 마법 예외**: 배운 마법의 퍼즐/월드 상호작용 버전(태우기·얼리기 등)은 각인과 무관하게 상시 사용 — "문 열려고 거점 가서 스왑"하는 백트래킹 지옥 방지. 각인은 전투(+이동) 성능만 관리.
- 세계관 부수 효과: 그릇이 유한하니 마법사들은 한 우물을 판다.

### 3.4 전공제 (기존 확정 — 신학습구조와의 결합 세부는 §11-3)
- 주인공은 정규 3속성 중 하나를 **전공**으로 선택 (1막 클라이맥스 = 전공 선택식, 첫 승급과 겸함 — 직접 써보고 고르는 선택).
- 전공 우대는 **효율**: 마나 효율·쿨타임 최우대 + 고급마법 선생(속성 마스터) 사사 + 전공 라인의 성장(§6.6). 데미지 우대는 소폭(10~15%)까지만 — 지역 마법 조합의 재미를 죽이지 않기 위해.
- 기본 공격의 속성·이펙트 = 전공 속성 (전공 선택식에서 지팡이에 속성이 깃드는 연출).

## 4. 스탯 & 감정

### 4.1 스탯 (확정)
기본 4스탯 + 속성 블록, 전부 **랭크제 (F–E–D–C–B–A–S–SS–SSS, 규격 외 EX)**.

| 스탯 | 전투 영향 |
|---|---|
| **힘** | 기본 공격 피해 |
| **마나** | 마나 풀 크기·회복 효율 |
| **속도** | 공격/시전 속도 (**이동 속도는 불변** — 손맛 고정) |
| **맷집** | HP(마스크 단위), 경직 저항 |
| **속성** | 전공 원소 랭크 — 해당 속성 마법 위력 |
| **통찰** | 감정으로 읽는 정보의 깊이 (전투 영향 없음) |

- **랭크는 실효가 있다** — 데미지·공속 등을 실제로 조절한다. 단 **소프트하게**: 차이가 심하지 않게 캡을 두고, **플레이 실력이 언제나 더 중요**하다 (스킬 좋은 저스탯 플레이어가 이길 수 있어야 함 — 플레이테스트 지표).
- **표시 레이어와 엔진 레이어 분리**: 화면의 랭크는 화려하게, 엔진 수치는 이산 단계 소수로 매핑 (밸런스 상태 수 관리).
- **랭크 상승은 굵고 드문 사건** — 상승 순간 **스탯 그래픽이 극적으로 멋있게 변한다** (퀘스트지상주의의 등급 연출 원리 — 표면 카피 금지). 출처는 승급·시련·과제·희귀 보상 등 의미 있는 것만.

### 4.2 감정(Appraisal)
- 기본 소양인 감정 마법 — **대상 제한 없음. 아무리 강한 존재라도 감정은 무조건 성공한다** (감정 실패·예절·범위 제한 설정 전면 폐기 — 2026-07-17).
- 강자의 압도감은 **읽힌 시트 그 자체**가 만든다: SSS와 EX가 줄지어 박힌 스탯, 빼곡한 각인 목록 — 숫자가 공포가 되게 설계.
- 감정 = 도감 축적·약점 힌트(탐험 보상) + 통찰 랭크가 오르면 읽는 정보가 깊어짐(약점·행동 패턴 등).

### 4.3 안티패턴 (리서치 경고 — 전 기획 적용)
1. 적 레벨 스케일링/데미지 스펀지 금지 — 보스는 깔끔한 히트 몇 방에 죽는다
2. 레벨 게이팅 금지 — 벽은 이동 마법(하드)과 적의 강함(소프트)으로만
3. 갈아서 뚫리는 벽 금지 — 반복 파밍 XP 최소화
4. 승급은 수치 임계가 아니라 **스탯 조건 + 미션(스킬 체크)** 으로
5. 퍼센트 수프 금지 — 업그레이드는 즉시 이해되는 것으로
6. 표시 숫자와 엔진 숫자 분리
7. 스킬 좋은 저스탯 플레이어가 이길 수 있어야 한다

## 6. 전투 시스템 — "스타일리시하되, 난사는 없다"

### 6.1 조작 골격 (게임 내내 고정)
| 층 | 내용 | 제한 |
|---|---|---|
| **기본 공격** | 지팡이 다단 휘두름 + 전방 마력 투사 (§6.2) | 쿨 없음 / **마나 수급원** |
| **스킬 (각인 마법)** | 새긴 마법들 — 굵직한 한 방·유틸 | **쿨타임 + 마나 소모** |
| 생활 마법 | 퍼즐·월드 상호작용 | 각인 무관 상시 |
| 이동 마법 | 대시·벽차기 등 (§3.2-③) | 각인 (이동 전용칸 유력) |

- 버튼은 게임 내내 늘지 않는다. 복잡성은 거점에서의 각인 선택(머리)에만 있고 손은 단순하다.
- **스킬 난사 금지 원칙 유지**: 쿨과 마나가 이중으로 잠근다. 스킬은 문장이 아니라 마침표.

### 6.2 기본 공격 — "휘두르는 대로 마법이 나간다" (2026-07-17 개정)
- **정의**: 지팡이를 **여러 번 휘두르는 다단 연격** — 휘두름 하나하나마다 전공 속성의 마력이 **전방으로 뻗어 나간다**. 단발 궤적이 아니라 화려한 연속기 (비주얼 레퍼런스: **메이플스토리 팬텀의 얼티밋 드라이브** — 연속 휘두름에서 마법이 물 흐르듯 쏟아지는 그림. 표면 카피 금지, '다단 전방 투사'라는 원리만).
- **스컬식 감각**: 기본 공격만으로도 화면이 살아 있는 스타일리시함. 콤보 마지막 타는 크고 시원하게.
- **가드레일 (유지)**:
  - **사거리는 근접~단거리로 제한** — 마력이 나가되 멀리 날아가는 탄이 아니다. 뒷걸음 원거리 사격이 최적해가 되는 순간 전투가 납작해진다 (거리 조절의 긴장 = 전투의 심장).
  - 궤적·판정·프레임은 전공 무관 동일 (모션 1벌 + 속성 이펙트 교체) — 전공별 차이는 색·입자·미세 라이더만.
  - 강철 검처럼 그리지 않는다 — 마력은 반투명한 원소 그 자체, 지팡이가 항상 출처로 보이게.
  - **성장 금지**: 기본 공격은 위력 티어 상승 없음 — 새로움은 전부 마법(각인·승급)에서. 단 속성 랭크 임계마다 **외형과 피니시가 화려해진다** (기계적 캡, 시각적 성장).
- **타이밍**: 별도 박자 입력 없음 — HN 문법 그대로, 적의 패턴을 읽고 열린 윈도우에 때린다.

### 6.3 자원 — 마나 충전식 (확정)
> "시전은 모은 마나로 한다. 마나는 가만히 있어도 차오르고, 벤 자리에서 더 크게 거둬들인다."

- **자동 회복(소량) + 타격 수급(대량)** — 공격적인 플레이가 마법의 연료. 스킬 무한 돌리기는 마나가 잠근다.
- 회복은 마나와 분리 (확정): **횟수제 정수병, 거점에서만 충전** — 거점에서 멀어질수록 잔여 병 수가 원정의 카운트다운.

### 6.4 잔광(殘光) — 전투 시그니처 (유지)
> 마법을 시전하면, 그 속성의 여운이 기본 공격에 몇 타(기본 3타) 동안 남는다.

- 번개 마법을 쓰면 다음 연격이 번개를 두르고, 얼음을 쓰면 서리의 연격이 된다 — 기본 상태는 전공 속성.
- 목적: ①치고-쏘고-치는 위빙 리듬 ②마법→근접 역방향 피드백이 있는 왕복 루프(HN과 다른 우리 지문) ③각인 조합의 재미가 기본기 손맛까지 확장.

### 6.5 마법의 역할 분담 (유지)
- **전공 마법 = 효율** — 자주, 가볍게 쓰는 주력 리듬
- **지역/특수 마법 = 결정력** — 코스트 무겁고 강력, "언제 꺼낼까"의 재미
- **화려함 도징**: 평시 화면은 절제, 스킬이 터지는 순간만 최대 연출 (기본기가 화려해진 만큼 스킬 순간은 한 단계 더 위로)

### 6.6 성장 표현 (유지 + 마력석 연동)
- **전공 주력 마법은 교체되지 않고 성장한다** — 같은 마법이 승급·수련·**마력석 강화**(§8.1)로 규모·형태·부가효과가 진화. "첫 수업의 그 마법이 끝까지 함께 자라 오의가 된다."
- 지역/특수 마법은 습득형 (성장 트리 없음 — 총량 통제. 마력석 강화는 소폭 허용 — §11-5 튜닝).

### 6.7 인카운터 설계 — "물량이 아니라 개체" (2026-07-17 개정)
- **잡몹 물량전 지양**: 메이플/스컬의 잡몹맵 같은 다수 섬멸이 아니다. **소수 정예 개체를 하나하나 상대하며** 나아간다 — HN의 배치 감각.
- **지형지물이 전투의 절반**: 좁은 발판, 낙차, 매달린 구조물, 지역 기믹(램프 반경·낙뢰·거울 빛)이 인카운터에 결합 — 같은 적도 지형이 다르면 다른 싸움.
- **공용 아키타입 8종** (행동 골격): ①보행 근접 ②원거리 사수 ③비행 급습 ④방패/정면 방어 ⑤돌진 자폭 ⑥소환/버프 지원 ⑦매복/지형 의태 ⑧중장 엘리트(미니보스 겸용). `아키타입 × 지역 스킨 × 속성 라이더 × 파라미터` = 체감 25~35종, 고유 스프라이트 12~16벌 억제.
- **원칙**: 모든 공격에 읽히는 예비 동작 / 새 적의 첫 등장은 안전한 방에서 / 속성 약점은 소프트하게 / 적의 강함이 소프트 게이트 역할(강한 지역의 적은 실력으로만 조기 돌파 가능).
- **보스는 별도 정성 설계** — 지역 기믹의 졸업시험.

### 6.8 사망/리스크 — "기록의 리스크" (확정·단순화)
> 죽음은 아무것도 빼앗지 않는다 — 마법도, 돈도. 대신 **직전 세이브 이후의 여행 '기록'이 소실**된다.

- 죽으면 마지막 거점(세이브)에서 부활, 완전 회복, 적 리스폰. 각인·마법·재화 무손실.
- 소실되는 것: 세이브 이후의 지도 스케치·도감 메모·이야깃거리 (젖어 번진 수첩 연출). *"기록은 거점에서 정리해야 비로소 내 것이 된다."*
- 리스크 3겹: ①정수병 잔량 ②거점 간격(초반 촘촘, 후반 성김 — 보스 앞 필수) ③미정리 기록.
- 즉사 지형(가시·낙사) = 사망 아님: 소량 피해 + 직전 발판 복귀.
- "죽음이 두려운" 게임이 아니라 **"되돌아가는 게 아까운"** 게임.

### 6.9 게임필 체크리스트 (수직 슬라이스 최우선)
입력 버퍼 / 코요테 타임 / 캔슬 창 / 히트스톱 / 짧은 선딜 / 착지·피격 경직 최소화. 이동 속도는 스탯 영향 금지. **이 영역은 개발자 본인의 손 튜닝이 최우선** — AI가 대신 못 하는 유일한 영역.

### 6.10 난잡함 방지 (요약)
①버튼 고정 ②생활 마법은 각인 밖 ③각인 교체는 거점만 ④총 습득 마법 20~25 / 동시 장착 = 각인칸(3~6 예상, §11-4) ⑤스킬은 쿨+마나 이중 잠금 — "HN보다 딱 한 겹 복잡한" 지점 유지.

## 7. 학교 콘텐츠 루프

### 7.1 금지 3원칙 (유지)
달력 시뮬 금지(수업은 내가 갈 때 기다린다, missable 없음) / 메뉴 클릭 수업 금지(수업은 반드시 플레이) / 컷신 복도 금지.

### 7.2 수업 = 3단 플레이 (유지)
**이론(1~2분, 선생의 개성) → 실습(챌린지 룸 1개를 전 수업이 재사용) → 과제("배운 것을 세계에서 증명해 와라").** 과제 완료 = 마법 습득 확정·성장 단계·스탯 랭크 상승의 출처.

### 7.3 마법 습득 경로 (2026-07-17 개정 — §3.2와 동일)
| 경로 | 대상 | 방식 |
|---|---|---|
| 수업 (요건 충족) | 정규 초급 | 이론→실습→과제 |
| **주문서 전수** | 정규 고급 | 주문서/마법서를 구해 오면 선생이 전수 — **입수처에 랜덤성**(퀘스트·지역에 따라 다름) |
| 모험 습득 | 지역·특수 마법 | 랜덤한 퀘스트/이벤트/지역에서 |
| 개인 교습 | 오의·비전 | 선생 신뢰 라인 (은거 선생 포함) |

### 7.4 승급 (2026-07-17 개정)
- **조건 = 특정 스탯 도달 + 특정 미션 달성** (예: 지정 과업, 누군가와 대련하여 승리 — 스킬 체크). XP 임계치 아님.
- **보상 = 각인칸 +1** + 상위 수업 개방 + 출입 허가 등. 승급은 의식(ceremony)으로 연출.
- 임시 명칭: 예과생 → 4급~1급 마도생 (정식 작명 추후).

### 7.5 의뢰 게시판 (유지)
마을·지역의 부탁 = 로컬 스토리(60%)의 공식 입구. 의뢰 평판 → 상점 할인·특수 수업 추천서 등 소소한 특전.

### 7.6 교수진 2계층 (유지)
담당 교수(상주 — 초급 수업·과제·승급 추천) + 고급마법 선생(속성 마스터 — 일부는 세계에 은거: 가마 마을의 화염술사, 부유군도의 바람 은자). 개인 교습은 모든 선생에게 존재(분량 차등).

### 7.7 허브 인력 (유지)
학교로 돌아올 이유 상시 2~3개: 각인 재구성 + 기록 정리 + 게시판 갱신 + 진행 중 수업 + 급식·기숙사 소극.

### 7.8 스코프
1회차 체감 수업 13~16개 (정규 초급 3 + 전공 라인 3~4 + 이동 계열 4~6 + 교양 2~3). 챌린지 룸 1개 재사용, 과제·의뢰는 데이터 양산.

## 8. 경제·펫·조력자

### 8.1 이중 통화 (유지 + 강화 연동)
| | **화폐** | **마력석** |
|---|---|---|
| 정체 | 세상의 돈 | 마나가 응결된 광석 — 거인의 광산의 산물 |
| 획득 | 의뢰·퀘스트·판매 | **탐험** — 광맥·숨은 방·보스 (잡몹 파밍 없음) |
| 쓰임 | 생활·편의 (소비품·곤돌라 요금·지도) | **성장·마법: 스킬 강화, 일부 마법 습득/전수 비용, 정수병 확장, 각인·승급 준비물** |

- **돈으로는 강해질 수 없다** — 파워는 마력석+과제의 영역.
- **비대칭 환전**: 마력석→화폐 상시 / 화폐→마력석은 **제한적** (달시장 — 보름마다, 한정 수량, 비싼 값).

### 8.2 펫 (확정 — 효과 풀 확장)
- 모험 중 인연으로 영입, **동반 1마리** (교체는 거점).
- **펫 스킬 = 공격형 또는 패시브형 1개+α.** 후보 풀: 각인칸 +1 / 모든 스킬 1단계 강화 / 펫 전용 마법 1개(예: 펫이 쓰는 불꽃) / **펫과 융합해 변신 후 스킬 사용** / 짧은 무적기 / 어둠 밝히기 / 마력석 감지 / 사망 시 기록 일부 보호. ※강력 효과(각인칸+1, 무적, 융합)는 후반 배치 + 밸런스 주의(§11-5).
- 펫 스킬은 자동 발동 또는 기존 키 공유 — 신규 버튼 금지. 유대 성장(원리만 차용). 스코프 4~6종.

### 8.3 조력자 (방향 확정)
- **펫과 유사한 동반 시스템**으로 설계 — 강자/동료가 일정 구간 동행하며 패시브+시그니처 스킬 1개를 빌려준다.
- 구체 설계는 미션 콘텐츠와 함께 (동행 구간·지휘 조작·서사 결합은 스토리 확정 후).

## 9. 스코프 가드레일 (1인 · 2~3년)

## 11. 미결 질문 (다음 논의 대상)

1. **다회차(로그라이크) vs 성장식(RPG)** — 유저 고민 중. 현재 기획의 기본 가정은 성장식(메트로베니아 표준). 주문서 입수 랜덤성(§3.2)은 어느 쪽이든 성립하지만, 다회차 채택 시 사망 리스크·각인·월드 개방 구조의 재설계 필요. **결정 전까지 성장식 기준으로 개발.**
2. **물→얼음 교체의 파장** — 정규 속성이 불/얼음/바람이 되면서: ⓐ기초 퍼즐 열쇠의 재정의(물의 역할 → 얼리기/녹이기로 흡수?) ⓑ**종의 계곡(지역 속성 '얼음')과의 중복** — 지역 마법 재배치 필요 ⓒ정수장·가마 마을 등 물 기초를 쓰는 방 게이트 조정 ⓓ기본 공격 시각(물결→서리). 맵 데이터는 결정 후 일괄 반영.
3. **전공제 × 신학습구조 결합 세부** — 고급 마법(주문서 전수)이 전공 속성 한정인지 3속성 전부인지 / 전공 선택식 타이밍과 초급 수업의 관계.
4. **이동 마법 각인 밸런스** — 이동 전용 각인칸 분리(유력) vs 통합 슬롯 / 총 각인칸 수(시작 2~3 → 최종 5~7?) / 모험산 이동 마법의 상위호환 폭.
5. 수치 튜닝 일체 — 각인칸·쿨·마나·잔광 타수·스탯 캡·펫 강력 효과 (수직 슬라이스에서).
6. 아트 방향 — 기준 해상도·캐릭터 크기·타일 크기 (비교안 제시됨: 480×270 추천 — 결정 대기).
7. 승급 랭크·세계 고유명사 정식 작명 일괄.
8. 조력자 구체 설계 (미션 콘텐츠와 함께).
