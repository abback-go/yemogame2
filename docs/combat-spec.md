# 전투 코어 스펙 v0.1 — 얼음/창 트라이얼 슬라이스 (구현 사양)

> 2026-07-19 작성 (advisor). 기획서 §6.1·§6.2·§6.3·§6.7·§9.1의 구현 사양.
> **범위**: 얼음 속성 / 창 무기 **하나만**. 그레이박스(도형 + 주스). 손맛 검증용 트라이얼.
> **수치는 전부 시작값 — 유저 F5 손 튜닝으로 확정. 모든 튜닝값은 `@export`로 노출**(인스펙터 슬라이더).
> 목표 검증: *"창 근접 다단 손맛(파고드는 lunge) + 마나 루프 + 스킬 2종 마침표 + 주스 + 마법 가시성"* 이 재미있는가.

## 0. 설계 기둥 (어기지 말 것)
1. **창 = 파고드는 공격형(lunge rushdown)** — 찌를 때마다 전진, 대시·점프로 캔슬해 계속 붙는다. 긴 리치 + 기동성.
2. **마법 가시성 (유저 요건 2026-07-19)** — 무기·스킬이 **물리 타격이 아니라 마법으로 읽혀야** 한다. 그레이박스에서도:
   - 창 = **반투명·발광하는 냉기 형상**(강철 실루엣 금지 — §6.2). 매개체(마도구/촉매 = 손 위치)가 항상 출처로 보이게.
   - 기본 공격조차 찌를 때 **서리 궤적/파편 파티클**을 남겨 "냉기 창으로 찌른다"로 읽히게.
   - 스킬 발동 = **마법진/룬 문양 순간 표시**(시전 텔) + 냉기 이펙트 — "영창하는 마법"의 언어.
3. **손은 단순** — 버튼 3개(J/K/L) 고정. 복잡성은 리듬·거리 판단에.
4. **데미지 스펀지 금지**(§4.3) — 적은 2~4타에 죽는다. 읽히는 예비동작 필수(§6.7).

## 1. 키 배치 (기존 이동 키와 비충돌, 리매핑 가능 — §9.1)
| 키 | 동작 |
|---|---|
| **J** | 기본 공격(얼음 창 다단 콤보) |
| **K** | 스킬1 — 관통 서리창 |
| **L** | 스킬2 — 빙정 폭발 |
- 이동 키(←→↓ / Z·Space / C·Shift / X / A / D / F·R·Esc)는 movement-spec v2.1 그대로 유지.

## 2. 기본 공격 — 얼음 창 3타 lunge 콤보
전공(얼음) 속성이 형상화한 **긴 창**으로 파고들며 찌르는 다단. 쿨 없음, 타격이 마나 수급원.

| 타 | 선딜 | 판정 | 후딜 | 리치(px) | 런지 전진(px) | 넉백 | 마나 수급 | 데미지 |
|---|---|---|---|---|---|---|---|---|
| 1타 (빠른 찌르기) | 0.08s | 0.06s | 0.12s | 64 | 40 | 소 | +3 | 1 |
| 2타 (빠른 찌르기) | 0.07s | 0.06s | 0.12s | 64 | 40 | 소 | +3 | 1 |
| 3타 (크게 내지름) | 0.12s | 0.08s | 0.22s | 88 | 80 | **대** | +5 | 2 |

- **히트박스 = 얇고 길게**(창 정체성): 세로 ~24px, 가로 = 리치. 바라보는 방향으로 뻗음.
- **런지**: 각 타 판정 순간 전방으로 짧게 전진(위 표). 공중에서도 가능(공중 런지 = 수평만, 소량).
- **콤보 입력창**: 후딜 중 다음 입력 버퍼 0.25s. 마지막 입력 후 0.5s 무입력이면 콤보 리셋(1타로).
- **캔슬**: 판정 프레임 이후 **대시·점프로 캔슬 가능**(기동 전투 — 붙었다 빠지는 리듬). 스킬로도 캔슬 가능.
- **마법 가시성**: 창 도형은 반투명 하늘색 + 발광, 찌를 때 창 끝에 서리 파편 파티클. 3타는 냉기 폭발 궤적을 크게.
- **성장 훅(미구현, 주석만)**: 속성 랭크 임계마다 외형·피니시 강화(§6.2) — 이 슬라이스는 기본 티어만.

## 3. 스킬 2종 (얼음 · 쿨타임 + 마나 · "마침표" 역할 · 시전 텔 필수)
### 스킬1 — 관통 서리창 (K) : 원거리 돌진 결정타
- **동작**: 시전 텔(마법진 flash 0.15s) → 전방으로 짧게 돌진(140px / 0.2s)하며 **긴 얼음 창을 내질러 직선 관통**. 경로의 모든 적 타격 + **빙결 슬로우(이동·공속 40%, 2s)**.
- 리치(관통 판정) 160px, 데미지 3, **쿨 6s / 마나 20**. 돌진 중 짧은 경직 감소(약한 밀림 저항).
- *컨셉: 거리를 좁히며 꽂는다 — 창의 리치를 결정타로.*

### 스킬2 — 빙정 폭발 (L) : 근접 AoE 컨트롤/탈출
- **동작**: 시전 텔(발밑 마법진 0.18s) → **주변 반경 90px 냉기 폭발**. 적 밀치기(넉백) + **짧은 빙결 스턴 0.6s**.
- 데미지 2, **쿨 9s / 마나 30**. 군집 정리·위기 탈출용.
- *컨셉: 근접에서 숨 돌리는 마침표.*

- 두 스킬은 **자동 발동 아님**(전용 키). 마나 부족·쿨 중이면 발동 불가(불발 피드백 = 짧은 흔들림/사운드 훅).

## 4. 마나 루프 (기존 이동 마나 위에 전투 얹기)
- 마나 풀 **100** / 회복 지상 20·초, 공중 6·초 (movement-spec 그대로).
- **기본 공격 타격당 수급**(위 표 +3/+3/+5) — 3타 풀히트 = +11.
- 스킬 소모: 스킬1 -20, 스킬2 -30.
- 검증 목표: *"치고(기본기로 벌고) → 쏘고(스킬로 쓰고) → 치는"* 왕복이 자연히 도는가. 이동 마나와 공유 풀(공중 곡예 vs 스킬의 자원 경쟁).
- 체력/정수병은 이 슬라이스 **최소만**: 체력 5 마스크(기존), 적 접촉·피격에 감소, 0이면 리스폰(F 리필 포함). 정수병 회복 시스템은 생략.

## 5. 더미 적 3종 (조작감 검증 최소 — §6.7 아키타입 기반)
| 적 | 행동 | HP | 공격 | 텔레그래프 |
|---|---|---|---|---|
| **허수아비** | 정지 | 사실상 무한(피격 반응만, 죽어도 즉시 리스폰) | 없음 | — |
| **근접 워커**(①보행 근접) | 플레이어로 느리게 이동 60px/s | 3 | 근접 짧은 찌르기(접촉 시) 1 마스크 | 공격 전 0.5s 정지+예비 모션 |
| **원거리 사수**(②원거리 사수) | 정지 or 저속 40px/s, 거리 유지 | 2 | 느린 투사체 180px/s, 2s 주기 | 발사 전 0.6s 조준 모션 |
- 전부 **읽히는 예비동작**, HP 낮게(스펀지 금지). 피격 시 넉백·히트스톱·서리 파편 반응.
- 허수아비 = 순수 타격감/콤보/히트스톱 확인. 워커 = 리듬·창 리치·거리 조절. 사수 = 부유(시그니처)·대시 회피.

## 6. 공용 주스/필 레이어 (전투 + **이동에도 즉시 적용**)
> 앞서 진단한 이동 밋밋함(주스 0)을 여기서 함께 해소. 이동(착지·대시·벽차기)에도 같은 프리미티브 적용.

| 요소 | 트리거 | 시작값(@export) |
|---|---|---|
| **히트스톱** | 타격 프레임 | 일반타 0.04s / 3타·스킬 0.09s. unscaled 타이머로 복귀 |
| **화면 흔들림** | 타격·스킬·착지 | trauma 모델: 일반타 +0.2 / 3타·스킬 +0.4 / 착지 +0.15, 감쇠. max_offset 12px |
| **스쿼시/스트레치** | 점프·착지·대시·공격 순간 | 점프 세로 늘림 / 착지 가로 납작 / 찌를 때 창 방향 늘림. tween 0.08~0.12s |
| **파티클** | 창 타격(서리 파편)·대시/착지(먼지)·스킬(냉기 폭발) | 도형 파티클, 얼음=하늘색/흰색 |
| **카메라 룩어헤드** | 이동 속도 기반 | 진행 방향으로 최대 40px 리드, lerp 부드럽게 |

- 히트스톱은 짧은 게임 정지(또는 `Engine.time_scale` 급감) + **unscaled 타이머**로 복귀 — 상시 로직이 안 멈추게 주의.
- 주스 강도 전부 `@export` (과하면 유저가 슬라이더로 줄임).

## 7. 씬 구성 / 통합
- **새 전투 아레나**: `godot/scenes/combat_arena.tscn`(정적 최소 구조: 루트 + 스크립트) + `godot/scripts/combat_arena.gd`. **평지 원룸 + 발판 2~3개**(부유·대시 회피용 낙차 약간). 3종 적 배치.
- **런처 메뉴에 추가**: `launcher.gd`/`launcher.tscn`에 `[3] 전투 아레나` 항목.
- **player.gd 확장**: 공격 상태머신(콤보) + 스킬 2종(쿨+마나) + 마나 수급/소모 + 주스 훅. 기존 이동 로직·마나 시스템 재사용.
- **적 스크립트**: `godot/scripts/enemies/`(허수아비·워커·사수) — 런타임 조립.
- **HUD 확장**: `debug_hud.gd`에 스킬 2종 쿨다운 표시 + (선택)콤보 카운터 + 키 안내(J/K/L) 추가. 마나 바 재사용.

## 8. 구현 제약 (레포 규칙 — 반드시 준수)
- **Godot 4.7 런타임 조립**: 노드는 전부 코드 생성, `$경로` 조회 금지, 참조는 메서드 주입(`set_zones` 패턴 참고). 씬 파일은 정적 최소 구조(루트+스크립트)만.
- 한국어 UI = **SystemFont**(`["Malgun Gothic","맑은 고딕","NanumGothic","Noto Sans KR"]`), 로드 실패 폴백 + `[진단]` print/push_warning 패턴 유지.
- **gdlint 한 줄 100자 제한**, gdparse 통과.
- 모든 튜닝 상수 `@export`(또는 `@export_range`) — 인스펙터에서 코딩 없이 조절.
- 데미지·수치는 표시 레이어와 분리해도 되나, 이 슬라이스는 단순 정수로 시작.
