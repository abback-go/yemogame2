# 튜토리얼 오프닝 콘티 (개고 v2 — 유저 검토 대기)

> story-track.md §1.3 확정 비트의 장면 단위 콘티. **승인 후 구현**(승인 전 코드 반영 금지).
> 연출 원칙: 대사 = **월드 내 말풍선 + 짧은 컷씬풍 연출 + 타자기**(§2.5-7) / 조작 안내 = **토스트(조작 프롬프트만)** / 설정 설명 0문장.
> 목표 분량: 첫 실행 **5~8분**. 현재는 콘티(대사·비트) 확정용 — 구현·비주얼은 유니티 착수 시(Track 1 경험 후).

---

## 0. 대사 원칙 (산나비 급 — 이 게임 전체 대사의 기준선)

> 유저 지시(2026-07-22): 톤을 '산나비' 수준으로. **똑같이 쓰라는 게 아니라 그 급의 건조함·밀도.**

**피할 것 (= "AI 톤"):**
- ❌ **의미를 대신 읽어주기** — "이거 하나면 다들 겨울을 난다"처럼 사물의 가치·주제를 대사가 설명함(폐기된 구 대사).
- ❌ 화면에 보이는 걸 말로 중계 / 감정을 이름 붙여 말함("무서웠다", "소중해").
- ❌ 주제·설정을 읊는 캡션식 시적 대사. 배경 설명 대사.
- ❌ 누나의 **품평 발화**("배짱은 사줄 만하군" 류) — §1.4 금지.

**노릴 것 (= 산나비 급):**
- ✅ **거래하듯 짧게.** 묻고 답하는 리듬. 정보는 필요한 만큼만.
- ✅ **서브텍스트** — 중요한 건 말하지 않은 쪽에 둔다.
- ✅ 구체적·즉물적·그 순간의 말. 드라이한 농담/냉소 허용.
- ✅ **정점에서 절제** — 감정이 터질 자리에 오히려 한 음절만(누나의 균열 = "…아." 하나).
- ✅ **인물별 목소리 분리**: 브로커=지친 냉소 / 주인공=삐딱한 거리 실무형(짧지만 벙어리는 아님) / 누나=오만한 장난기의 귀족(가볍게 놀리되 짧고 건조) / 경비대장=거친 현장.

주인공은 말을 아끼되 **벙어리는 아니다** — 짧고 건조한 실무형에, 가끔 냉소 섞인 한 문장(거리에서 굴러 온 티). 값·전투·안전을 묻고, 귀족·허세엔 삐딱하게 받아친다.
누나는 **표면이 오만한 장난**(그를 갖고 노는 가벼운 놀림) — 단 여전히 짧고 건조, 오글 금지. 정점(마도구 균열·패배)에선 놀림기를 접고 절제로 때린다.

## 1. 씬 목록 (6씬)

| # | 장면 | 배우는 것 | 길이 |
|---|---|---|---|
| 1 | 하층가 잠입 | 이동·점프 | ~90초 |
| 2 | 발각·도주 | 대시(시작 보유 체술) | ~60초 |
| 3 | 막다른 골목 | **A 마력 덩어리(baseline)** + 경비대장 미니보스 | ~90초 |
| 4 | 그녀의 차단 | (연출) | ~30초 |
| 5 | 핸디캡 결투 | 회피·타이밍·전투 리듬 | 2~4분 |
| 6 | 정산 → 학교 | (연출) | ~30초 |

**전제(story-track §1.3·§1.2 확정):**
- 주인공 = **뒷골목 청부업자**(연민의 부랑아 아님). 동기 = **받은 의뢰**(굶음·식구들 폐기).
- **'잘못된 의뢰' = 장전된 총**: 익명의 두둑한 의뢰인 + "호위 하나"의 정체 → 미해결로 심는다(누나 진짜 이유 연결 가능성만, 확정 금지).
- 튜토리얼 전투 = **baseline만**: 투박한 마력 덩어리 + 체술(대시). **마나 드레인 마법은 미습득**(입학 후 학교 첫 수업에서 배움).
- 대시 = **육체(시작 보유)** — 각성 연출 없음.
- 누나 = 마도구를 **운반하던 중**(교수 업무 — 중립 설정, 심층 의미 없음).

## 2. 씬별 콘티 (대사 전문)

### 씬1 — 하층가 잠입 (이동·점프)
- **무대**: 밤·비 그친 하층가 뒷골목과 지붕. 낮은 채도, 창문 불빛 몇. (신규 소구역 — 정본 월드맵 밖.)
- **콜드 오픈(말풍선, 조작 잠금 짧게)** — 브로커가 어둠 속에서 일감을 넘긴다. 얼굴은 안 보임(실루엣).

  | 화자 | 대사 |
  |---|---|
  | 브로커 | "마차 한 대, 상자 하나. 빼 오면 끝이야." |
  | 주인공 | "경비." |
  | 브로커 | "몇 명. 호위가 하나 더 붙는대." |
  | 주인공 | "하나면 쉽지." |
  | 브로커 | "……글쎄." |
  | 주인공 | "의뢰인은." |
  | 브로커 | "선금이 이만큼인데, 그런 걸 왜 물어." |

  → *장전된 총 2개*: "……글쎄"(삼켜진 경고) / "그런 걸 왜 물어"(익명의 큰손). 설명 0.
- **흐름**: 지붕에서 시작 → 차양·난간을 밟아 골목으로 하강 → 보관 마차의 궤짝 = **마도구** 도달 → 획득.
- **획득 순간(말풍선 1줄)** — 주인공: `"…고작 이거."` (극빈의 눈엔 값이 안 보임 = 계급 아이러니의 밑밥. 이게 평생 빚이 될 물건.)
- **마도구**: 발광 도형 + 라벨 `?`(정체 미정 = 떡밥). 그가 아는 건 "값이 크다"뿐.
- **조작 토스트(프롬프트만)**: `←→ 이동 · Z 점프`.
- **실패**: 낙사 없음. 시간 제한 없음.

### 씬2 — 발각·도주 (대시)
- **트리거**: 획득 직후 경보(플래시+종소리). 경비가 쏟아지고 **경비대장이 추격**(잡을 순 없는 속도 — 단 멈추면 따라잡혀 피격).
- **앰비언트(말풍선 1줄)** — 경비: `"도둑이야! 거기 서!"` (현장의 외침 — 주제 캡션 아님, OK.)
- **코스**: 바닥 갭·낮은 장애물. 첫 갭 앞 토스트 `C 대시`. **각성 연출 없음**(늘 쓰던 몸놀림).
- **주인공 대사 없음** — 추격은 액션이 전달.
- **실패**: 갭 낙하 시 바로 아래서 재시도(사망 아님).

### 씬3 — 막다른 골목 (마력 덩어리 baseline + 경비대장 미니보스)
- **무대**: 도주 끝, 높은 담의 막다른 골목. 추격해온 **경비대장**이 입구를 막음 — 1:1.
- **대면(말풍선)**:

  | 화자 | 대사 |
  |---|---|
  | 경비대장 | "막다른 길이야, 꼬마. 상자 내려놔." |
  | 주인공 | "내려놓으면 곱게 보내주기라도 하고?" |

  → 주인공의 첫 자기표현 = 짧은 거절 + 태도. 훈계 없음.
- **발현 연출**: 궁지 → 손에 발광 덩어리 응축(화면 반 박자 정지) → 토스트 `A — 마력 덩어리`. (드레인 아님 — 그냥 투박한 근접 타격.)
- **전투 — 경비대장(중간보스급, "잡는 맛")**: 잡몹 아님. 텔레그래프 명확한 2패턴(① 곤봉 내려찍기 — 바닥 충격파 / ② 잡기 돌진 — 잡히면 큰 피해), HP 중간(덩어리 8~12타). 대시 회피 + 치고 빠지기를 여기서 몸에 익힘. brute 계열 변형.
- **격파(말풍선 1줄)** — 경비대장(주저앉으며): `"…길바닥 쥐새끼가."` (계급 조롱 — 그가 진 게 '거리 것'이라는 게 분함. 주제를 밑에 깖.)
- **실패**: 사망 시 씬3 시작부터 재시작.

### 씬4 — 그녀의 차단 (연출 ~30초, 조작 유지)
- 담을 넘으려는 순간 — **골목 출구에 그녀가 서 있다**(우아한 실루엣, 조각상처럼 미동 없음).
- **실력 차 1차 시연(무언)**: 손짓 하나 — 그의 품에서 마도구가 **떠올라 그녀 손으로.** 그녀는 그것을 **결투장 옆 궤짝 위에 올려둔다**(싸움 내내 화면에 보임 = 긴장 장치).
- **대사(말풍선·타자기. 누나 = 건조·경제적. 품평 금지)**:

  | 화자 | 대사 |
  |---|---|
  | 누나 | "경비대장까지 눕히고 왔네. 바쁜 밤이야." |
  | 누나 | "그건 학교 물건인데." |
  | 누나 | "도망칠 구멍은 없고." |
  | 누나 | "그냥 데려가긴 재미없으니까 — 내기할까?" |
  | 누나 | "여기서 날 한 발짝이라도 움직이게 만들면, 네가 이긴 거야." |
  | 주인공 | "이기면 뭘 주는데." |
  | 누나 | "평생 손에 물 안 묻히고 살게 해줄게." |
  | 주인공 | "…귀족 말은 반만 믿으랬는데." |
  | 누나 | "그럼 반만 믿든가. 어차피 선택지도 없잖아?" |

  → 누나 = **오만한 장난**(가볍게 놀리되 짧고 건조 — 품평·과장 금지 §1.4): "바쁜 밤이야"=감탄 아닌 귀찮음 처리 / "선택지도 없잖아?"=패를 다 쥔 걸 놀리듯. 주인공 = 삐딱한 거리 냉소("반만 믿으랬는데")로 받아침 — 준-과묵이되 벙어리는 아님. ※ 상품 = **호화 생활**(마도구 아님 — v3: 마도구는 파손 후 빚).

### 씬5 — 핸디캡 결투 (보스전 — 오프닝의 심장)
- **보스**: 그녀. **완전 고정**(이동 0). EnemyBase 기반, `auto_respawn=false`. 무기 = 덩어리 A + 대시.
- **P1 핸디캡 페이즈(HP 100→30%)**:

  | 패턴 | 내용 | 가르치는 것 |
  |---|---|---|
  | 견제탄 | 손끝에서 느린 유도탄 1~2발(긴 텔레그래프) | 대시 회피 |
  | 바닥 룬 | 발밑 경고 룬 → 1박자 후 폭발 | 위치 이탈 |
  | 반격 장막 | 주기적 전면 장막(피격 시 튕겨남) — 장막 중 공격 금지 | 타이밍(치고 빠지기) |

  - 접근→몇 대→빠지기 리듬. **"통한다"는 감각**이 목표. 대사 없음(액션).
- **게이지의 정의**: 표시는 HP바지만 픽션상 그녀의 **'여유'** — 그는 그녀를 위협한 적이 없다(§1.3 봐준 것 확정). 그의 성취 = 몰아붙여 사고를 만들고 내기를 **기술적으로** 이긴 것.
- **P2 스크립트(게이지 30% 도달 순간)**:
  1. **사고**: 맹공 중, 장막에 튕긴 유탄이 궤짝 위 **마도구를 스침** — `쩍`(금 가는 소리), 화면 반 박자 정지. (책임은 난장 속에 모호 — 의도된 모호함.)
  2. **균열(말풍선 1음절)** — 누나: `"…아."` (지루하던 목소리가 **처음으로** 흔들림. **왜 이 물건에 이렇게 반응하는지는 밝히지 않는다** = 진짜 이유 씨앗 §1.4.)
  3. 그녀가 — 분노로 — **딱 한 발** 내딛음(`쿵` 화면 흔들림. 분노는 표정 아니라 이펙트·무게로. 자기 규칙을 스스로 깬 순간).
  4. 한 수(화면을 채우는 발광 — 회피 불가 연출) → 강제 다운(**조작 잠금 최대 3초**). 사망 아님(체력 바닥 보정).
- **실패**: P1에서 죽으면 결투 시작부터 즉시 재시작.

### 씬6 — 정산 → 학교 (연출 ~30초) — "이기고도 청구서"
- **대사(말풍선·타자기. 이 게임 최다 대사 장면, 이후 다시 침묵)**:

  | 화자 | 대사 |
  |---|---|
  | 누나 | (냉정 회복, 반 박자) "…졌네." |
  | 누나 | "약속은 지켜. 학교로 와. 먹고사는 건 거기서 해결돼." |
  | 주인공 | "…학교?" |
  | 누나 | (깨진 마도구 흘긋) "저건 별개야. 값은 네가 갚고." |

  → 계급 아이러니 2겹이 대사에 실림: **① 이긴 건 그인데 청구서도 그의 것**("값은 네가 갚고") / **② 그가 상상한 '호화'와 그녀의 '호화'가 어긋남** — 주인공의 `"…학교?"` 한마디가 *상품이 숙제였다*를 설명 없이 친다.
- **버튼**: 그녀는 돌아선다. 더는 말 없음. 페이드 → **학교 정문(hub_plaza)**. (지리 이동은 페이드가 처리.)
- **정산 결과**: 신분 = **학생**(시종 아님) + 호화 후원(내기 이행) + **마도구 빚**(별개 청구).

## 3. 구현 메모 (승인·유니티 착수 후)
- 씬1~6 = 오프닝 존: 잠입 방 + 도주 방 + 막다른 골목(경비대장) + 결투장(보스방).
- 재사용 매핑(참고, 구 godot 자산 기준): 경비대장=brute 계열 변형 / 보스=EnemyBase(고정) / 연출=타이머+조작잠금+Juice / 대사=말풍선+타자기.
- 신규 필요: P2 연출 시퀀서(간단 타임라인), 추격 경비 AI(잡지 않음), 콜드 오픈 브로커 실루엣.
- **P2 연출 타이밍·"억울하지 않은 패배" 감각은 실행 튜닝 항목** — 초기값 넣고 조정.

## 4. 미정 (이 콘티가 건드리지 않는 것)
- 누나 이름·외형·표정 연출(진짜 이유 확정 후) / 마도구 정체(떡밥) / 의뢰인 정체(장전된 총 — 확정 금지).
- 식구들·길거리 친구들은 **중반 에피소드**에서(§1.6) — 튜토리얼에 등장 안 함.
- 학생 생활·'청구서 정산' 호출 연출(학교 도착 이후, 접점 채널 미확정 §1.4).
- 조작 키(Z/C/A 등)는 placeholder — 유니티 착수 시 확정.
