# 튜토리얼 오프닝 콘티 (초안 — 유저 검토 대기)

> story-track.md §1.3 확정 비트의 장면 단위 콘티. **승인 후 구현** (승인 전 코드 반영 금지).
> 원칙: 게임-네이티브(§2.5-7 — 컷씬·텍스트 벽 금지, 조작 안내는 토스트 한 줄), 설정 설명 0문장.
> 목표 분량: 첫 실행 기준 **5~8분**. 그레이박스(§9.1) — 연출은 도형·이펙트·카메라로.

## 0. 전제 (확정 사항 요약 + 이 콘티의 제안 2개)

**확정(story-track §1.3 v3)**: 절도→핸디캡 **내기** 결투(상품=호화로운 생활)→난장 속 마도구 파손→그녀가 **분노로 한 발**→한 수 패배→내기 이행=**학생 입학·호화 후원** + **마도구 값=빚**(별개 청구) / 표면 톤=오만한 채권자 / 그녀 이름·표정 연출은 보류(진짜 이유 미정) / 절도 동기 = **길거리 식구들**(구체화는 추후, 신파 절제).

**이동기의 서사 정리(2026-07-20 유저 확정)**: 시작 보유 = 달리기·점프·**대시(육체 — 길거리 체술,
각성 아님)**. 입학 후 = **마력 대시로 업그레이드** + 이단점프·벽달리기·부유 등 **이동 마법은 전부
학교 수업에서 습득**(→ "마법을 배우는 감성" 담당, 기존 오브식 튜토리얼 폐기).
기계 매핑(제안): 육체 대시=dash_ground 시작 ON / 마력 업그레이드=dash_air+거리 증가.
마나 비용 구분(육체 대시=무마나?)은 밸런스 단계에서 결정.

**제안 ② 그녀가 거기 있던 이유(표면)**: 학교로 **마도구를 운반하던 중** (교수 업무). 심층 의미 없음 —
"진짜 이유" 공란과 무관한 중립 설정.

## 1. 씬 목록 (6씬)

| # | 장면 | 배우는 것 | 길이 |
|---|---|---|---|
| 1 | 하층가 잠입 | 이동·점프 | ~90초 |
| 2 | 발각·도주 | 대시 활용(시작 보유 체술) | ~60초 |
| 3 | 막다른 골목 | **A 덩어리(첫 발현)** + 경비대장 미니보스 | ~90초 |
| 4 | 그녀의 차단 | (연출) | ~20초 |
| 5 | 핸디캡 결투 | 회피·타이밍·전투 리듬 | 2~4분 |
| 6 | 빚·계약 → 학교 | (연출) | ~30초 |

## 2. 씬별 콘티

### 씬1 — 하층가 잠입 (이동·점프)
- **무대**: 밤의 하층가 뒷골목·지붕(신규 소구역 — **정본 월드맵 밖**, 정본 무수정). 낮은 채도 그레이박스,
  창문 불빛 몇 개.
- **흐름**: 지붕에서 시작 → 골목으로 내려가며 이동·점프 코스 → 보관 마차/궤짝의 **마도구**에 도달 → 획득.
- **식구들 씨앗(절제)**: 시작 직후 딱 한 컷 — 잠든 아이들 옆을 지나며 토스트 한 줄:
  `"이거 하나면 다들 겨울을 난다."` (대사창 없음. 이 한 줄이 동기 전부.)
- **마도구**: 발광 도형 + 이름 없는 라벨(`?`). 정체 미정 = 떡밥 유지. 그가 아는 건 "값이 어마어마하다"뿐.
- **안내**: 토스트 2개만 — `←→ 이동 · Z 점프`, 획득 시 `손에 넣었다 — 이제 빠져나간다`.
- **실패 처리**: 낙사 없음(바닥 안전). 시간 제한 없음.

### 씬2 — 발각·도주 (대시 — 시작 보유 체술)
- **트리거**: 획득 직후 경보(화면 플래시+소리) → 경비들이 뒤에서 추격(따라오지만 잡지는 못하는 속도).
- **대시 안내**: 도주로의 첫 갭 앞에서 토스트 한 줄 — `C 대시`. **각성 연출 없음** — 대시는 그가
  길에서 늘 쓰던 몸놀림(유저 확정: 육체 대시=시작 보유, 마력 대시=입학 후 업그레이드).
- **코스**: 갭·낮은 장애물·낙하 — 대시 리듬을 몸으로 익히는 구간.
- **실패 처리**: 갭 낙하 시 바로 아래서 재시도(사망 아님).

### 씬3 — 막다른 골목 (덩어리 첫 발현 = A 학습 + 첫 미니보스)
- **무대**: 도주 끝, 높은 담의 막다른 골목. **경비대장**이 입구를 막음(추격 경비들은 뒤로 빠짐 — 1:1).
- **발현 연출**: 몸싸움 궁지 → 손에 발광 덩어리 응축(화면 반 박자 정지) → 토스트 `A — 마력 덩어리`.
- **전투 — 경비대장 (중간보스급, 유저 확정 "잡는 맛")**: 잡몹 아님. 텔레그래프 명확한 2패턴
  (예: ① 곤봉 내려찍기 — 바닥 충격파 ② 잡기 돌진 — 잡히면 큰 피해), HP 중간(덩어리 8~12타 감각).
  첫 전투지만 만만하지 않게 — 대시 회피+치고 빠지기를 여기서 몸에 익힘. brute 계열 변형으로 구현.
- **실패 처리**: 사망 시 씬3 시작부터 재시작(빠른 리트라이).

### 씬4 — 그녀의 차단 (연출 ~20초, 조작 유지)
- 담을 넘으려는 순간 — **골목 출구에 그녀가 서 있다** (우아한 실루엣, 조각상처럼).
- **실력 차 1차 시연**: 손짓 하나 — 그의 품에서 마도구가 **떠올라 그녀 손으로.** 그녀는 그것을
  **결투장 옆 궤짝 위에 올려둔다** (상품이 아니라 '회수한 짐' — 그러나 싸움 내내 화면에 보임 = 긴장 장치).
- **대사(초안, 3줄 — 화법: 건조·담백·짧게. 연설조·품평·과장 금지)**:
  - 그녀: `"…그거, 꽤 비싼 건데."` (위협도 훈계도 아닌 무심한 사실)
  - 그녀: `"내기 하나 하자. 내가 이 자리에서 한 발이라도 움직이면, 네가 이긴 거다."`
  - 그녀: `"이기면 — 평생 먹고살 걱정은 없을 거다."` (제안이 아니라 통보. 부랑아에게 정확히 꽂히는 상금)

### 씬5 — 핸디캡 결투 (보스전 — 오프닝의 심장)
- **보스**: 그녀. **완전 고정**(이동 0). EnemyBase 기반 신규, `auto_respawn=false`.
- **P1 핸디캡 페이즈** (그녀 HP 100→30%):
  | 패턴 | 내용 | 가르치는 것 |
  |---|---|---|
  | 견제탄 | 손끝에서 느린 유도탄 1~2발(긴 텔레그래프) | 대시 회피 |
  | 바닥 룬 | 플레이어 발밑 경고 룬 → 1박자 후 폭발 | 위치 이탈 |
  | 반격 장막 | 주기적 전면 장막(피격 시 튕겨남) — 장막 중 공격 금지 | 타이밍 읽기(치고 빠지기) |
  - 플레이어 무기 = 덩어리 A + 대시. 접근→몇 대→빠지기 리듬. **"통한다"는 감각**이 목표.
- **게이지의 정의**: 표시는 보스 HP바지만 픽션상 그녀의 **'여유'** — 그는 그녀를 위협한 적이 없다
  (봐준 것 확정, story-track §1.3 v3). 그의 성취 = 몰아붙여 사고를 만들고 내기를 기술적으로 이긴 것.
- **P2 스크립트 (게이지 30% 도달 순간)**:
  1. **사고**: 그의 맹공 속, 장막에 튕긴 유탄이 궤짝 위 **마도구를 스침** — 쩍(금 가는 소리),
     화면 반 박자 정지. 그녀의 침묵. (책임은 난장 속에 모호 — 의도된 모호함)
  2. 그녀가 — **분노로 — 딱 한 발** 내딛음 (쿵 — 화면 흔들림. 분노는 표정이 아니라
     이펙트·속도·무게로 표현. 자기가 건 규칙을 스스로 깬 순간 = 그녀에게도 작은 흠집)
  3. 대마법 (화면을 채우는 발광 — 회피 불가 연출) → 강제 다운 (**조작 잠금 최대 3초**)
- **사망 처리**: P1에서 죽으면 결투 시작부터 즉시 재시작(로딩 최소).
- **F5 튜닝 항목(구현 후 유저 몫)**: P1 길이(지루하면 짧게), P2 진입 타이밍, "억울하지 않은 패배" 감각.

### 씬6 — 내기 정산 → 학교 (연출 ~30초) — "이기고도 청구서"
- **대사(초안, 4줄 — 이 게임 최다 대사 장면, 이후 다시 침묵. 화법: 건조·담백)**:
  - 그녀: (냉정 회복, 반 박자) `"…졌네."` (담백한 인정 — 강자의 여유. "네 승리다" 선언조 폐기)
  - 그녀: `"약속은 지킨다. 학교로 와. 먹고사는 건 거기서 해결된다."` (그가 꿈꾼 호화=빵과 침대,
    그녀의 호화=학교. 계급 단절 조크 유지)
  - (그의 대사 없음 — 일어나서 눈을 부라리는 것으로 대체. 침묵 = 그의 캐릭터)
  - 그녀: (깨진 마도구를 흘긋) `"저건 별도다. 네가 갚아."`
- **정산 결과**: 신분 = **학생**(시종 아님) + 호화 후원(내기 이행) + **마도구 빚**(별개 청구).
- **전환**: 페이드 → **학교 정문(연속 월드 hub_plaza)** 도착. 지리 이동 과정 생략(페이드가 처리).
  이후 기존 연속 월드 진행(수업·각인·전투 구역).

## 3. 구현 메모 (승인 후)
- `world_room` 통합: 씬1~6 = 오프닝 존 신규 방 3~4개 + 보스방. 기존 op_start/op_hall(오브 2방) **대체**.
- 재사용: 경비대장=brute 계열 변형(중간보스) / 보스=EnemyBase / 연출=타이머+조작잠금+Juice.
  (대시 각성 삭제 — 시작 킷 포함으로 오브 부여 불필요)
- 신규 필요: 스크립트 페이즈(P2) 연출 시퀀서(간단한 타임라인), 추격 경비(잡지 않는 AI).
- 검증: gdparse·gdlint + 크로스파일 수동 대조. **P2 연출 타이밍은 F5 없이 확정 불가** — 초기값으로 넣고 튜닝.

## 4. 미정 (이 콘티가 건드리지 않는 것)
그녀 이름·외형·표정 연출(진짜 이유 확정 후) / 마도구 정체(떡밥) / 식구들 구체화(중반 에피소드에서) /
하층가↔협곡 학교 지리 정합(정본 월드맵 개편 시) / 학생 생활·'청구서 정산' 호출 연출(학교 도착 이후,
접점 채널 제안은 story-track §1.4 — 미확정).
