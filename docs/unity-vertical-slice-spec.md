# 성창(聖槍) — Unity 수직 슬라이스 핸드오프 명세서 v1.1

> **컨셉:** 창(槍) 근접 액션 + 신성력, 인간계 메트로바니아. 기획서: [`specs/2026-08-07-holy-spear-design.md`](specs/2026-08-07-holy-spear-design.md)
> **목적:** 유니티로 본격 제작 전, **맵 1개('인간계 강림지') + 창술 공격 + 이동기(창대 도약 포함)**를
> **"타격감 좋게 60%"** 로 완성해 **필(feel) 검증**을 끝내는 수직 슬라이스.
> **성공 기준 단 하나:** *"유니티에서 이게 할로우 나이트/산나비처럼 느껴지는가?"*
>
> **필 = 90% / 콘텐츠 = 최소.** 60%를 얇게 펴지 말고 이동감·타격감·카메라에 몰빵.
> 물리 상수는 웹 프로토타입에서 **검증 완료**된 값. 타격감(juice) 값은 **권장 시작값 → 유니티에서 미세튜닝**.

---

## 0. 이 문서 사용법 (유니티 MCP에게)

이 문서는 **결정론적 명세**다. 스스로 설계·추측하지 말고 아래 수치·구조를 **그대로 구현**하라.
- 값이 명시된 곳: 그 값을 쓴다.
- "튜닝" 표시된 곳: 명시된 시작값으로 구현하되, 인스펙터에 노출해 조정 가능하게.
- 구현 순서는 **§14 빌드 순서서**를 따른다. 각 단계마다 **§15 합격 기준**으로 자체 검증 후 다음 단계로.
- 모든 이동/물리 수치는 **커스텀 캐릭터 컨트롤러**로 재현한다. **Rigidbody2D 기본 물리 사용 금지**(필 재현 불가).

## 1. 슬라이스 범위 (In / Out)

**포함 (In):**
- 커스텀 캐릭터 컨트롤러: 달리기·가변점프·코요테·점프버퍼·낙하
- 이동기 4종: **대시 · 이단 강림(이중점프) · 벽슬라이드/벽점프 · 창대 도약(pole vault, 시그니처)**
- 공격 1종: **창술 3타 콤보**(찌르기→올려베기→회전 쓸기) + **창 강화(신성력)** — 타격감 검증용
- 맵 1개: **'인간계 강림지'** 수직 슬라이스(§10)
- 몹 2종(타락한 것, 단순 순찰 + 접촉 데미지) — 타격감 시험 대상
- **타격감/juice 풀세트**(히트스톱·셰이크·넉백·파티클·데미지넘버·히트플래시)
- 팔로우 카메라(스무딩·룩어헤드·데드존)

**제외 (Out) — 이 슬라이스에서 하지 않음:**
- 빛의 창 투척·정화·심판 등 나머지 신성기(선택 스트레치, §6.5)
- 스킬트리·퀘스트·대화·UI 메뉴·세이브
- 최종 아트/애니메이션(플레이스홀더로 진행, 규격만 확정 §13)
- 오디오(훅만 남김)·다른 존·보스

## 2. 유니티 프로젝트 셋업

- **엔진:** Unity 6 LTS (6000.x). 2D 템플릿.
- **렌더:** URP 2D (2D Renderer). 픽셀아트 대비 **Pixel Perfect Camera** 컴포넌트 사용.
- **물리 타임스텝(중요):** `Project Settings → Time → Fixed Timestep = 0.0083333` (120 Hz).
  컨트롤러 로직은 `FixedUpdate`에서 실행, 렌더는 보간(interpolate).
  - 대안(권장): 자체 고정 누산기(fixed accumulator)로 `DT = 1/120` 스텝을 돌리고 렌더 보간.
- **입력:** Input System 패키지(신규) 또는 레거시 — §12 매핑대로.
- **레이어:** `Player`, `Enemy`, `Ground`, `OneWay`, `Wall`, `Hitbox`, `Hurtbox`.
- **콜리전 매트릭스:** Hitbox↔Hurtbox만 상호작용. Player는 Ground/OneWay/Wall과 충돌.

## 3. 좌표·단위·부호 규칙 (px → Unity 변환)

웹 프로토타입은 **+y 아래(down)**, 픽셀 단위. 유니티는 **+y 위(up)**, 월드 단위.

- **스케일:** **PPU = 100** → **1 Unity 유닛 = 100 px**. (모든 px 값 ÷ 100)
- **부호:** 수직 성분은 부호 반전. (웹 점프 `-910` → 유니티 `+9.10`, 웹 중력 `+2600` → 유니티 `-26`)
- **원점:** 맵 좌표는 **좌하단 (0,0)**, +x 오른쪽, +y 위, 단위=유닛.

> 아래 §4 표는 **이미 변환 완료된 Unity 값**이다. 그대로 쓰면 된다.

## 5. 캐릭터 컨트롤러 명세 (이동)

`FixedUpdate`(DT=1/120)에서:
1. **수평:** 입력 방향으로 `accel`(지상) / `accel×airControl`(공중) 가속, 최대 `runSpeed`. 입력 없으면 `friction`으로 감속. 지상/공중 분리.
2. **중력:** `vy += gravity × DT`, `vy`를 `maxFall`로 클램프.
3. **점프:**
   - 지상 또는 **코요테(0.10s)** 내면 점프 가능. `vy = jumpV`.
   - **점프버퍼(0.12s):** 착지 직전 눌러도 착지 시 발동.
   - **가변점프:** 상승 중 점프키 떼면 `vy > 0`일 때 `vy *= jumpCut(0.42)`.
4. **한방향(one-way) 플랫폼:** 위에서 착지 가능, 아래에서 통과. **↓ + 점프 = 발판 아래로 드롭**(0.22s 동안 one-way 충돌 무시).
5. **렛지스냅:** 진행 방향 앞의 턱 높이 ≤ `ledgeSnap(0.08u)`이면 자동 승월(멈춤 방지).
6. **충돌:** 축분리(수평→수직) 스윕. 벽/천장/바닥 각각 처리. 착지 시 `vy=0`, 접지 플래그 set.

## 6. 이동기 명세

### 6.1 대시 (Shift)
- 발동 시 `dashTime(0.16s)` 동안 현재 바라보는 방향으로 **수평속도 = dashSpeed(7.80)** 고정, 중력 무시(수평 대시).
- 대시 중 **짧은 무적**(dashTime 동안 hurtbox off).
- `dashCd(0.72s)` 쿨다운. 지상/공중 모두 가능(공중 1회 제한).
- **필 포인트:** 대시 시작에 잔상(afterimage) 3~4장, 종료 시 수평속도를 `runSpeed`로 부드럽게 감쇠.

### 6.2 이단 강림 / 이중점프 (공중 Space)
- 공중에서 1회. `vy = airJumpV(+8.20)`.
- **필 포인트:** 발동 지점에 **빛의 링 파티클(라이트 스텝)** + 살짝의 상승 스쿼시.

### 6.3 벽슬라이드 / 벽점프
- 벽 접촉 + 공중 + 벽 방향 입력 → **벽슬라이드**: 낙하속도를 `wallSlideMax(-2.40)`로 클램프.
- 벽슬라이드 중 점프 → **벽점프**: `vx = 반대방향 × wallJumpVX(4.30)`, `vy = wallJumpVY(+8.60)`.
  - 벽점프 직후 **0.12s간 수평입력 잠금**(벽으로 되붙는 것 방지).
- **필 포인트:** 슬라이드 중 벽면 마찰 먼지 파티클, 벽점프 순간 작은 셰이크.

### 6.4 창대 도약 (Pole Vault) — 시그니처 이동기 ★
> 창을 지면/벽에 꽂고 도약해 **높은 곳으로 튀어오르는** 창 컨셉 고유 이동기. 슬라이스에서 반드시 검증.
- **입력:** 지상/공중에서 도약 지정 지점(vault point) 근처 + 도약키(또는 아래+점프 홀드). 초기엔 **지정 발판/난간에서만** 발동(단순화), 후에 임의 지형 확장.
- **동작:** 창을 축으로 **포물선 도약** — 정점 높이 약 **3.4 u**(단일 1.59·이단 ≈2.88보다 확연히 높음 → 독립 게이트 성립), 수평 이동 약 1.5 u. 도약 중 짧은 준비모션(0.12s) 후 발사.
- **쿨다운:** 0.4s. 도약 정점에서 다른 이동기(대시/이단강림)로 캔슬 연계 가능.
- **필 포인트:** 창 꽂는 "탁" 순간 미세 정지(6프레임) + 빛 번짐, 튀어오를 때 잔상·바람 파티클. **성물 회수로 해금되는 능력**이므로 획득 시 연출도 크게.

### 6.5 (선택 스트레치 — 시간 남으면) 원거리·해제 신성기
| 신성기 | Unity 값 / 역할 |
|---|---|
| 빛의 창 투척 | 투사체 속도 15.0 u/s, 관통, cd 0.9s — 원거리 딜·원격 스위치 |
| 정화의 빛 | 자힐 + 어둠 장막 해제(게이트), 신성력 소모 |
| 빛의 대시(무적 질주) | 대시 강화형 — 거리 2.10 u, 위험지대 통과, cd 1.1s |

## 7. 공격 명세 — 창술 3타 콤보 (근접)

> **창(槍)의 리치와 간격**이 정체성. 찌르기(포킹) ↔ 파고들어 쓸기의 리듬. 근접 콤보가 타격감 검증에 최적.

**콤보 구성:**
| 타 | 이름 | 히트박스(캐릭터 앞) | 특성 |
|---|---|---|---|
| 1타 | **찌르기(Thrust)** | `1.1 × 0.30` u (긴 리치, 얇음) | 빠른 견제·포킹 |
| 2타 | **올려베기(Rising)** | `0.8 × 0.7` u (앞·위) | 적 살짝 **띄움**(공중 콤보 연결) |
| 3타 | **회전 쓸기(Sweep)** | `1.0 × 0.8` u (넓게, 전진 0.3u) | 광역·강넉백·마무리 |

- **입력:** 공격키(§12) 연타 → 1→2→3 콤보.
- **타이밍(각 타):** windup **0.06s** → active(히트박스 on) **0.10s** → recovery **0.14s**.
- **콤보 입력창:** recovery 시작 후 **0.35s** 내 재입력 시 다음 타로 연결. 놓치면 리셋.
- **차지 찌르기(홀드):** 0.4s 홀드 시 **관통 찌르기**(리치 1.6u, 관통·경직↑).
- **내려찍기(공중+↓+공격):** 급강하 → 착지 충격파(광역 소량). 바닥 게이트(균열) 파괴 훅.
- **데미지:** 1타 100% · 2타 110% · 3타 150%. 크리 시 ×`CRIT_MUL(1.5)`.
- **넉백:** 1·2타 약, 3타 강(§8.3).
- **이동:** 지상 공격 중 수평이동 감속(0.4배), 3타는 살짝 전진. 공중 콤보 허용.

**창 강화 모드(신성력):** 신성 강화키 → 신성력 소모, **3초간** 창이 빛으로 감싸임 → 리치 ×1.25, 데미지 ×1.3, 타격 시 추가 빛 파티클·히트스톱 1단계↑. **슬라이스의 "한 방" 쾌감 자원.**

- **필 포인트:** 각 타 서로 다른 창격 궤적(arc), 찌르기는 직선 잔상, 쓸기는 부채꼴 궤적. 강화 모드는 금빛 발광.

## 8. 타격감 / Juice 명세 ★ (이 슬라이스의 심장)

> **권장 시작값. 유니티에서 미세튜닝.** 이 표가 "타격감 좋게 60%"의 핵심이다.
> 원칙: **타격은 "충돌 프레임의 사건"이 아니라 "정지·흔들림·튐·번쩍임·터짐의 합주"** 다.

### 8.1 히트스톱 (Hit-stop / freeze frame)
피격 순간 **공격자와 피격자 둘 다** 잠깐 정지(`Time.timeScale` 대신 로컬 프리즈 권장 — 대상만 멈춤).
| 상황 | 정지 시간 |
|---|---|
| 약타(1·2타) | **60 ms** |
| 강타(3타) | **110 ms** |
| 크리티컬 | **140 ms** |

### 8.2 화면 흔들림 (Screen shake) — trauma 기반 감쇠
| 상황 | 진폭 | 지속 |
|---|---|---|
| 약타 | 0.03 u (3px) | 0.08 s |
| 강타 | 0.06 u (6px) | 0.14 s |
| 크리 | 0.08 u (8px) | 0.18 s |
- trauma 값 누적 후 `trauma²`로 오프셋, 시간에 따라 선형 감쇠. 방향 랜덤(index/시드로 변주).

### 8.3 넉백 (Knockback)
- 몹: 약타 **2.2 u/s**, 강타 **4.0 u/s**(피격 방향), **0.15s**간 감쇠.
- 플레이어 자기 반동: 3타 시 아주 약간(0.5 u/s) 뒤로.

### 8.4 히트플래시 (Hit flash)
- 피격 스프라이트를 **흰색 0.06s** 번쩍(머티리얼 `_FlashAmount` 1→0). 크리는 노랑빛.

### 8.5 파티클
- 접촉점에 **히트 스파크 8~12개**(부채꼴로 튐, 0.25s 소멸). 기본은 흰/은빛, **창 강화 시 금빛**.
- 창격 궤적(slash arc) 스프라이트를 타별로 표시(찌르기=직선, 쓸기=부채꼴).
- 3타/크리/강화타: 추가 링 임팩트 + 빛 잔염.

### 8.6 데미지 넘버
- 접촉점에서 팝 → **0.5s간 0.4u 상승** → 마지막 0.2s 페이드.
- 크리: 크게 + 색 다르게 + 약간의 스케일 펀치.

### 8.7 사운드 훅 (지금은 빈 훅)
- `SFX_swing`(스윙), `SFX_hit_light`, `SFX_hit_heavy`, `SFX_crit` 이벤트만 발생시키고 클립은 후속.

## 9. 카메라 명세

> **필의 절반은 카메라다.** 절대 캐릭터에 하드 고정하지 말 것.

- **팔로우:** `SmoothDamp`로 추적. smoothTime **수평 0.12s / 수직 0.18s**.
- **룩어헤드:** 진행/바라보는 방향으로 최대 **0.6 u** 미리 이동(0.25s 이징). 정지하면 복귀.
- **데드존:** 중앙 **0.4 × 0.3 u** 박스 — 소폭 이동엔 카메라 안 움직임(지터 방지).
- **수직:** 접지 시 빠르게 따라붙고, 공중에선 느슨하게. 착지 시 지면 라인에 스냅.
- **셰이크:** §8.2를 카메라 오프셋에 가산(팔로우 위에 덧씌움).
- **(선택) 히트펀치 줌:** 크리/강타에 FOV/ortho size를 순간 -2% 후 복귀(0.1s).
- **Pixel Perfect Camera:** PPU 100, 정수 배율 스냅(옵션) — 픽셀아트 흔들림 방지.

## 15. 합격 기준 (필 검증 체크)

### 15.1 이동 (2단계 후)
- [ ] 점프 최고 높이 ≈ **1.59 u**(±0.05). 좌우 반응 즉각적, 미끄러짐 자연스러움.
- [ ] 코요테: 발판 끝 벗어난 뒤 **0.10s 내** 점프 성공.
- [ ] 버퍼: 착지 **0.12s 전** 입력이 착지 시 발동.
- [ ] 가변점프: 짧게 누르면 낮게, 길게 누르면 높게.
- [ ] **"조작이 착 붙는다"** 는 주관적 느낌 — 안 나면 여기서 멈추고 튜닝.

### 15.2 맵/이동기 (3~4단계 후)
- [ ] 구덩이(3u)를 **달리기 점프론 못 넘고**, 대시점프/이단강림으로 넘긴다.
- [ ] 도약 전용 발판(y=3.2)을 **창대 도약으로만** 도달 — 단일·이단으론 안 닿는다.
- [ ] 고지대(y=6.6)를 **벽점프 등반으로 도달** 가능.
- [ ] **창대 도약이 시원하고 "창잡이답다"** 는 느낌 — 꽂고 튀는 리듬이 답답하지 않다.
- [ ] 한방향 발판 착지/드롭 정상.

### 15.3 타격감 (7단계 후)
- [ ] 창술 3타(찌르기→올려베기→쓸기) 리듬이 **경쾌**하고 입력창이 답답하지 않다.
- [ ] **창의 리치·간격 싸움**이 느껴진다(찌르기 포킹 ↔ 파고들어 쓸기).
- [ ] 올려베기로 띄운 적을 **공중 콤보**로 이을 수 있다.
- [ ] 타격 시 **정지·흔들림·튐·번쩍임·터짐**이 동시에 느껴진다.
- [ ] **창 강화 모드(신성력)** 의 한 방이 **확연히** 더 묵직하다.
- [ ] 크리티컬이 확연히 더 강하다(스톱140/셰이크0.08/줌펀치).
- [ ] **"창으로 때리는 맛이 있다"** 는 주관적 느낌 확보.

### 최종 (슬라이스 완료 판정)
- [ ] 위 셋 통과 + **"이거 유니티에서 할나/산나비 느낌 난다"** 확신 → **필 패리티 검증 성공.** 본 제작 진행.

## 부록. 튜닝 노트

- 필의 마지막 10%는 **수치가 아니라 조합·타이밍**에서 나온다. 히트스톱↔셰이크↔넉백의 **합**을 함께 조정.
- 값 하나씩 인스펙터에서 만지며 A/B. 확정된 값은 이 문서 §4·§8에 **역기입**(유니티가 진실원이 되면 갱신).
- 웹 프로토타입 대비 유니티는 입력 지연·렌더 파이프라인이 달라 **체감이 미세하게 다를 수 있음** → 수치보다 "느낌"을 최종 기준으로.
- 이 슬라이스가 통과하면, 이후 존·스킬·퀘스트는 웹의 `exportGameData()` JSON + `strategy.md` 스펙을 **데이터로 임포트**해 양산.
